# 《既往》归容角色说明书

> **全剧透，供扮演归容的玩家准备和逐幕查阅。** 包含角色本之外的主持流程。现场台词以 DM 发放的大卡为准；本文重点说明你此刻是谁、为什么这样做，以及小黑屋、演绎与道具怎样衔接。

## 怎么使用

先读“人物底稿”和“全程速查”，每幕再看相应的剧情与行动步骤。你是全本里需要多次转换外在立场、配合多段输出的角色：**预先知道真相，不代表可以提前公开任务或跳过假戏。** 特别留意第三幕、六至八幕和第十幕。

标记含义：**【小黑屋】**是与 NPC 的角色内私戏；**【心建】**是 DM 场外讲解／排练；**【大卡】**是行动卡输出，不一定都发生在舞台；**【小剧场】**是多人短场景；**【文本】**是书中事件，未必需要现实演出；**【领物／换本】**是道具与本册交接。演员戴墨镜时按 DM 身份理解，不把场外讲解算作 NPC 的剧情行为。

匕首、点符、点封、夺取物品等都按现场 DM 指定的道具和走位完成，不照小说描述自行实施。说明书中的“表演建议”是整理者建议，不是原本硬性要求。

## 人物底稿：淮夜的过去，归容的选择

你原本是**淮夜**，淮朝的兄长；后来以**归容**的身份活在小苍山，成为云谦的大徒弟。柳沐瑶是“小柳儿”，也是你最明确、最持续的选择：你想给她一个能活下去、有师父、有自己的家。

你的两层表现很重要。外在可以是顾全师门、尊敬师父、兄友弟恭的大师兄；内在却会为了小柳儿算计别人、执行秘密任务、借用游戏规则。两者并非每时每刻都是纯假话：你确实受过云谦救命之恩，也并非完全不知道淮朝的爱。角色的锋利之处在于，**理解别人对自己的感情，仍可能决定牺牲对方。**

| 对象 | 关系与行动原则 |
| --- | --- |
| 柳沐瑶 | 最终同盟与爱情核心。公开吵架可以是戏，不代表真实分手；很多行动必须与她对好口令。 |
| 云谦 | 救过你的师父。你会利用他、封锁他的记忆，但师徒恩情不是因此全部作废。第九幕的宗主与酒葫芦要接住。 |
| 淮朝 | 兄弟旧怨、对他爱的重新认识，以及你亲手推动他的赴死。不是单线的“误会解除，从此和好”。 |
| 金簪 | 最初接触的游戏引导者／掌权者。你先领任务，后来发现承诺与权限可以被利用；不提前把其话当作客观真理。 |
| 乌笠 | 提供另一套解释与资源的人。你与柳沐瑶最终利用两边，不能演成对乌笠无条件效忠。 |
| 江寒／云妄／风清砚 | 第六幕合作者。你帮他恢复儿子的故事位置和给风清雁换本；共同利益不等于长久互信。 |

**表演建议：** 对小柳儿保持前后一致的认真，对外界则允许轻松、体面、算计乃至冷酷之间的切换。第六幕的“反水”和第八幕的爱情兑现必须让人看出不同目的，第十幕则是主动取得控制权，不是终于救全桌逃离游戏。

| 二 | 金簪揭示游戏与任务；试探淮朝、公开表达爱 | 开头小黑屋 A 见金簪；读完后心建；留后台等淮朝，一起上台小剧场；再接柳沐瑶相关表演 |

| 四 | 师父救命之恩；与柳沐瑶设计淮朝 | 开头小黑屋 B 见云谦，领酒葫芦；主房间小剧场接剑与劝换珠；之后领 B 本 |

## 第一幕：先把“大师兄只管小柳儿”立起来

**剧情与心态。** 你以小苍山大师兄的身份与众人相处，背后有淮夜的旧事、对淮朝的复杂情绪。对柳沐瑶的偏爱应当具体可见：维护她、关注她需要什么，而不是只等到后面的大卡才突然说爱。

**现场行动。**

1. 【主房间／小剧场】根据本中互动维护小柳儿，接住与江寒等人的短场景。
2. 【小黑屋 B】读到“去见师父”等提示后见云谦，接师徒私谈。按提示回来继续阅读剩余内容，不能把“出门”理解为全幕已经结束。
3. 【秘密任务】按角色本要求，**对每一个人至少说过一次“小柳儿是我最重要的人”**。可以融入对话，不公开自己在完成任务面板。
4. 本幕没有独立上台大卡，但师徒私谈与秘密任务都影响后续理解，不能只读书而漏掉。

来源：归 A 第 3–36 页，重点第 31–34 页；主持第 11、30–31 页。

## 第二幕：认识金簪，并用一场表演试探淮朝

**剧情与心态。** 金簪告诉你与被写定的故事、任务有关的信息。你需要试探淮朝，并通过公开表达对柳沐瑶的爱推进她参与其中。当前你还在规则内部接任务，不能把第十幕的反制立场提前说出来。

**现场行动分三段，别把两次出门合成一次。**

1. 【开头小黑屋 A】见金簪，按剧情称呼“金簪大人”，领会当前任务。回来不公开这次会面的全部秘密。
2. 【幕末心建】读完后再次出门。云谦演员戴墨镜交给你与淮朝的小剧场卡并核对动作。**讲完后留在后台，等待淮朝来配合，不直接回座。**
3. 【上台小剧场】在大家聚齐、幕帘开启后，与淮朝完成指定短演绎。场景可以带有暧昧借位和喜剧感，但你的角色目的包括试探兄弟关系，不能只顾搞笑漏掉信息。
4. 【回座与再次互动】接柳沐瑶的吃醋／情绪，回应她。随后云笙要求音乐、引导相关表演时，再与小柳儿配合，完成公开表达爱意的任务。具体二次上台点按本场提示。

**表演建议：** 对淮朝的亲近有试探成分，对小柳儿的安抚则要真诚；两段的差别让后续身份揭露更容易成立。

来源：归 A 第 37–54 页；主持第 43、45–51 页。

## 第三幕：两人共谋，把“淮夜”和“归容”说清

**剧情与心态。** 你与柳沐瑶共同接触金簪，取得杀淮朝、换取双人通关的任务。**“双人通关”此时是金簪的承诺，不是全局已证实的结局。** 同时，你把淮夜与归容两重人生接起来，告诉小柳儿她在你选择活下去这件事里的位置。

柳沐瑶在此前私下已经获得相关身份信息；本幕公开输出不应写成“她第一次听见你就是淮夜”。公开身份还会影响淮朝对你的信任。

**现场行动。**

- 【中段小黑屋 A】与柳沐瑶一起见金簪，接当前任务及关于她不同版本人生的信息。不可回房直接把 RPG／BOSS 信息分享全桌。
- 【幕末心建】由云谦演员戴墨镜讲解爱情输出，准备月球／月兔灯等本场指定礼物。
- 【上台大卡：第三组 CP】依序在萧然、许尽欢相关输出之后、江寒之前。讲清身份，再落在“归容只管小柳儿”的情感承诺上。
- 【灯光信号】到“你看——”时按排练拍手或打响指，等灯光／礼物效果接上，再说“小柳儿，欢迎回家！”不要把信号与收束句连读到不给 DM 反应时间。
- 【去留讨论】你主张留在榕城、顾及师父；实际后续会去莲心城，按剧情争论后继续，不自行另开路线。

来源：归 A 第 55–69 页；主持第 63–66、72–74 页。

## 第四幕：师父的酒葫芦，与对弟弟的算计

**剧情与心态。** 云谦救你并不后悔，师徒关系在这里有真实的情感重量。另一面，你与小柳儿利用争执、主枝与假守诚符相关安排设计淮朝。这两条线并存：接受恩情，并不阻止你后来做出伤害师父或弟弟的选择。

**现场行动。**

1. 【开头小黑屋 B】见云谦，接师徒私谈，取得**酒葫芦**。保管好，后面第九幕会再次使用。
2. 【文本】你与柳沐瑶的假争执、诱导淮朝与主枝转移等内容，首先是本中发生的计划；除非 DM 另发卡，不自行把每段书内动作搬到台上重演。
3. 【主房间小剧场】莲心城冲突中，按卡衔接“师父接剑”等台词，并推动风清雁救江寒／换珠相关情节。不要把别人的受伤和誓言段变成你的独立输出。
4. 【换本】中场后领归容 B 本，从第五幕继续。本幕没有另列独立归容大卡。

来源：归 A 第 70–84 页；主持第 82–91 页。

## 第五幕：真正想要的婚礼，被别人的选择打断

**剧情与心态。** 你与小柳儿迎来婚礼，想要的家似乎近在眼前；但云笙在仪式中遇害，阿蒲出现。乌笠的警告又让金簪先前承诺的可靠性开始动摇。不要用预知结局的态度草草走完婚礼：对角色来说，这仍是一场认真想完成的婚礼。

**【婚礼上台】**

1. 等柳沐瑶完成关于命数、阵法等的相应输出，随流程与她上台。
2. 接云笙的嘱托，回应自己会照顾小柳儿。你与柳沐瑶在台上，云笙、萧然按各自高堂／司仪位置配合。
3. 到“二拜高堂”发生突变，萧然杀云笙。让该演绎按设计发生，不因玩家提前知道而临时阻拦、改变结局。
4. 随现场提示离开舞台，为随后阿蒲的出场与身份信息留出空间。

本幕没有归容专属 NPC 小黑屋；柳沐瑶的私人场景不等于你需要一起进去。乌笠的警告是后续接触的铺垫，不是此刻就立刻公开挑明两位 BOSS。

来源：归 B 第 5–12 页；主持第 94–102 页。

## 第六幕：封住师父，演一场分手，再助清砚换本

**剧情与心态。** 乌笠指出金簪在欺骗你们，并引入违规与权限的规则。你和柳沐瑶开始进一步利用这场游戏；公开的分手、对阿蒲表忠不等于真正拆散两人。

你帮助风清砚改变云谦的记忆、加快因果变化。你认为这不等同于取师父性命，师父还是师父，但这种自我解释不抹去封锁记忆的伤害。此时关于符的来源按当幕认知说，**不要提前讲第十幕才公开的金簪越权证据链**。

**出门顺序。**

1. 【小黑屋 B】读完后与柳沐瑶一起见乌笠，获得新信息。
2. 【假争吵排练】核对两人的冲突话术。柳沐瑶先回，归容留下接受更详细的动作心建；有些场次会让你与云妄共同核对。
3. 【墨镜心建】淮朝演员交代符纸与换本路线，交给你风清雁的 **B-2 新本**。藏好，不提前让她看见。

**主房间连锁行动。**

| 顺序 | 触发点 | 你的动作／话术重点 |
| --- | --- | --- |
| 1 | 许尽欢指认云妄，云谦问你的看法 | 表现成谁也不能轻信、很担心师父；以守诚之名提出点符。 |
| 2 | 云谦按流程点燃指定符纸 | 问关键句：“对你而言最重要的人是谁？” |
| 3 | 云谦回答认儿子 | 让云谦离开。不要忘记退 NPC，否则后续揭露会卡住。 |
| 4 | 云谦离场 | 揭露相应安排、向阿蒲表忠，并与柳沐瑶完成假争吵；这也是云妄拿走风清雁旧本的时间窗口。 |
| 5 | 假争吵结束 | 大声问：“清砚师弟，我这个大师兄，当得如何啊？”让云妄从装无辜切换为真实输出。 |
| 6 | 云妄：“大师兄，快拿给她看看。” | 把保管的新 B-2 **交给云妄**，让他完成展示和换本，不自己抢讲他的整段新人生。 |

**排练重点：** 假吵架的起手与收尾、符纸何时交出、云谦何时离开、你何时递新本。不要只记自己的大段台词而漏掉这些衔接。

来源：归 B 第 13–23 页；主持第 104–115 页。

## 第七幕：当你知道爱仍然选择下手

**剧情与心态。** 你对淮朝的认识已经不再是最初单纯的仇恨，但仍然要执行杀他的选择。你曾经给予的兄友弟恭、符与安排在这一场被揭开；淮朝最终以余命破阵赴死。不能把自己写成“完全不知道弟弟爱我，所以误杀”，也不能把淮朝的自愿承担理解为你无需承担选择。

**【幕末心建，而非另一次 NPC 小黑屋】**

- 按 B 本第 33 页提示出门，由云笙演员戴墨镜核对上台路线，领取**道具匕首和大卡**。
- 提前明确刺击的舞台动作、灯光变红的位置、自己回座时机。

**【上台大卡】**

1. 等阿蒲点名“我的大男主”等相应指令，再进入你的段落。
2. 开始可以保留表面上的兄长／正义姿态；按卡进行道具刺击与反转，揭露假符及虚假的兄弟和好。
3. 推动淮朝交出剩余生命破阵，并将这场戏与许尽欢的编写联系起来。
4. 完成自己的输出后**回座**，让淮朝继续告别与死亡段。不要因为情绪上来临场加“救回弟弟”动作，盖掉他的最终选择。

来源：归 B 第 24–33 页；主持第 118–124 页。

## 第八幕：两边取资源，为小柳儿兑现一个家

**剧情与心态。** 你们不再单纯相信某一位 BOSS，而是分头获得资源与权限。你去稳住乌笠，柳沐瑶走她的路线；对外的姿态服务于共同目标。柳沐瑶杀阿蒲后，你们要复活云笙，把小柳儿的师父还给她。

**本幕两次出门，领到的卡用途不同。**

1. 【中段小黑屋 B】按文本提示去见乌笠。前文即使出现与金簪相关的召唤信息，也不要跳过后面的转折、走错房间。这里有照心线提示卡与取资源的任务，不是最后的爱情大卡。
2. 你稳定乌笠、索取与万生寂、云笙魂魄有关的资源；柳沐瑶另行取得她的权限和复活所需资源。详细私人对白仍需另附 NPC 手册。
3. 回来继续读完本。到幕末提示，再出去由云谦演员戴墨镜讲解**归容爱情大卡**，核对与柳沐瑶解封的动作。

**主房间输出分前后两段，不要混在一起。**

**前段：柳沐瑶揭露计划。** 等她完成攻击阿蒲及相关输出，在她叫你配合时回应。对锁师父的原因，接“为了小柳儿”；对共谋者，接“我们两人”等卡上对应答案。按她的口令参与，不抢走她的整段揭露。

**后段：复活仪式与爱情大卡。**

1. 阿蒲告别后，云谦问云笙是否还能回来。让柳沐瑶先拿出复活币、说完她的卡。
2. 云谦转向你，提示还有话对小柳儿说，开始准备仪式。你进入自己的爱情大卡。
3. 核心是：当年她让你别死，你以归容活下来；过去的每一次照顾，都是对她的回答。这次你陪她迎回师父。
4. 按卡邀请柳沐瑶**一起上台**，手持指定法器完成解封。到“你看”给出衔接信号。
5. 等特效燃起，再喊“小柳儿，欢迎回家！只有归容和云笙的家！”让幕后云笙的回归接上。具体特效由 DM 操作。
6. 云笙回来后会追问你为何封锁师兄，随后破符。接住必要的问答，让她继续处理，不另开长篇辩论中断归来场。

**表演建议：** 这段回扣第三幕“欢迎回家”，可以使用相近的语气与停顿。你的感情是真实的，同时它建立在你们已作出的复杂选择之上。

来源：归 B 第 34–42 页；主持第 129–143 页，爱情大卡第 141 页。

## 第九幕：没有个人大卡，但有必须接住的师徒托付

**剧情与心态。** 围攻小苍山时，你与小柳儿被力量压制。关门阵是**被敌方阵法师压缩**到堪堪护住你们，不是你们主动缩阵只顾自己。云谦独自抵挡修士，最终以生命完成镇渊相关收束。你想护住小柳儿的未来，也不得不面对师父确实为你付出的事实。

**【酒葫芦与宗主交接】**

- 云谦演绎中与你互动时，按提示把第四幕取得的酒葫芦拿出来／递过去。
- 接他说宗主之位早已给你等相关托付，以及再次提起十年前救你无悔的师徒表达。
- 按现场动作接回酒葫芦，完成拥抱或耳语等排练过的互动。
- 到师父催你离开、把你推开或喊“走啊”等节点，让出表演空间，别一直拦在他身边阻挡后续。

**后续观看。** 本幕未单列归容独立小黑屋或独立大卡，但不能因此整幕完全旁观。完成师徒节点后，让风清雁、云妄各自完成终局输出，不替他们作选择。

来源：归 B 第 43–51 页；主持第 146–160 页，师徒交接重点第 150 页。

## 第十幕：你们赢得控制权，但没有让游戏结束

**剧情与心态。** 你和柳沐瑶利用两位旧 BOSS 的违规与资源授予，让他们失去相应地位；你们保留下来的爱与权限成为接管游戏的基础。结局的关键不是全员逃出生天，而是**你们成为新的控制者，决定其他人下一场如何活**。

**【联合心建】** 读完本后，等柳沐瑶也读完，两人一起出门。云谦演员戴墨镜核对两张卡，重点包括接话、夺取烟斗／斗笠、坐上台位、对风清雁不同回答的处理、召淮朝与最后合声。斗笠、座位等具体动作分配按本场大卡，不自行凭说明书猜。

**结算双人输出顺序。**

| 阶段 | 触发点 | 归容要做什么 |
| --- | --- | --- |
| 1：质疑金簪 | 萧然召出金簪、金簪询问如何处置等结算节点之后 | 按卡提出规则与锁灵符等越权证据，把金簪从裁判位置拉下来。不要开场就跳到最终夺位。 |
| 2：转向乌笠 | 乌笠以为你们站在自己一边、作出回应 | 用“你说对吧，小柳儿”等衔接把话交给柳沐瑶，让她揭露乌笠也给过违规资源。 |
| 3：接掌规则 | 柳沐瑶说明爱与权限的保留／共享 | 按卡取得**烟斗**，宣布新的规则与主导权；配合她取得另一道具、台位等动作。 |
| 4：处置其他人 | 你向柳沐瑶询问如何处置 | 让她完成对风清雁等人的安排。本段存在不同回答的衔接，结果要求对方继续留在游戏，不把它误演成自由离场投票。 |
| 5：召回淮朝 | 柳沐瑶提到还少一个玩家 | 大声给出“不信，你听——”等召唤信号，等淮朝敲门、入场，不急着抢读下一段。 |
| 6：宣布下一局 | 淮朝和许尽欢的相应互动完成 | 宣布新主题“侯府少爷狠狠爱！”，让两人当下一局男女主。题目与召唤句必须让后台听见。 |
| 7：合声落幕 | 所有前置段落完成、音乐推进 | 与柳沐瑶同时说最后两句，按排练统一停顿和收尾。 |

最后的合声是：

> 既往千山埋旧恨，此身不肯拜天恩。
>
> 诸位，既往的故事，现在，正式开始！

金簪的身份解释、旧 BOSS 与个别角色的私下交流，以及之后是否进入墨镜谢幕，有本场分支；你只需按自己的卡留出他们的时间，不预设每场完全相同。

来源：归 B 第 52–58 页及第 59–61 页角色复盘；主持第 163–173 页。
