# 《既往》剧本复盘

## 目标成果

把六个角色、14 份角色本及主持人资料中的信息拼成一份可以持续修订的完整故事，保留人物的认知差异、关键反转及可回查的依据。

## 阅读入口

- [既往江寒全气口输出攻略](既往江寒全气口输出攻略.md)：v1.9 整合演绎稿，包含十幕开口点、第三／六／九幕精简口语稿及第九幕登场诗、第五幕质问、以委屈与关系错位为重心的第七幕私戏（含流程、条件接话与上场速记）及可选场后信。
- [故事总览](故事总览.md)：先读这一份。按照事件因果重述故事，包含人物身份、六版改稿、十幕主线和结局。
- [时间线与证据](时间线与证据.md)：幕次对照、来源索引、关键证据、待补问题与修订记录。
- [主持人手册分析](主持人手册分析.md)：v0.2 新增，解释手册带来的关键修正、结局分支与现场叙事结构。
- [江寒角色说明书](江寒角色说明书.md)：v0.2 全剧透玩家准备稿，含完整输出索引，详解第三、六、九幕大卡的剧情背景、逐段内容、动作与收尾，并保留十幕流程。
- [归容角色说明书](归容角色说明书.md)：全剧透玩家准备稿，重点包含与柳沐瑶、江寒的配合、道具交接和结算演绎。

## 范围

当前版本为 **v0.2，全剧透工作稿**。依据已转换的 14 份角色本、各 B 本自带的“角色复盘”和 173 页《完整主持人手册》交叉整理。原始资料位于 `20_Sources/Files/PDFs/既往剧本杀/`。

目前已纳入主房间演绎、手册内的行动卡和引导；另附 NPC 小黑屋手册、金簪／乌笠小传、完整视频及实际场次的分支选择尚未取得。转换文本仍有 OCR 错字、表格混排风险；页码统一指原 PDF 的物理页码。手册第 114 页此前已目视核对为无可见正文的粉色区域。

## 迭代方式

后续可以直接指定人物、事件或问题编号，例如“细读风清雁到底有没有爱过云妄”“核对 Q05 许尽欢结局分支”。每次修订同步更新故事正文、相关证据和修订记录；原始转换稿保留不动。
