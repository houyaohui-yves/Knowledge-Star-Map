江寒 · 第六幕提词稿

【B1｜接棒，重释云妄】

【归容发言期间取得风清雁旧本；等他说“清砚师弟，我这个大师兄，当得如何啊？”后起身】
多谢大师兄，办得漂亮。 //

【看向许尽欢，让众人听清】
云谦给我起名云妄。 /他说，往事如烟，皆为虚妄。 //
他倒宽宏大量，替我忘了个干净。 //
云妄，那便是说我注定翻云覆雨、胆大妄为。 //
剧本说，淮朝和云妄要杀他。 /原来这个名字，是他亲手起给自己索命鬼的。 //
云谦既然给了我这个名字， /(重读)就别指望我又按他的意思活。 //

【B2｜说清身世，仍不被认】

【转向风清雁】
那天站在台上，我把身世都说了。 /我以为，他知道我是谁，就肯认我了。 //
我不敢逼他，叫我徒弟，我也应。 /可说完以后，你还是他的女儿，我还是江寒。 //
(重读)这一次，他明明知道，却还是不要我。 //

【B3｜纪叔给的第二个家】

【看向许尽欢】
十年前，你两句话就拿走了我的名字。 /我才九岁，反抗不了。 //

【声音放缓】
是我的师父，枪仙纪泽苍，把我养大的。 //
云谦不要我，是纪叔给我住处，照顾我，陪我长大。 /
我不用先证明自己是谁，他也肯管我、疼我。 //
(重读)他是我的师父，也像我的父亲。 /我以为，有他在，我就不算没家。 //

【B4｜又被夺走的家】

纪叔死了，死于剑伤。 /杀他的人，是云谦。 //

【压住声音】
他不肯给我的家，纪叔给了。 /(重读)他为什么连这个家，也要毁掉？ //
一个拿走我的名字，一个夺走我的家。 /他们凭什么，一次又一次拿走我的一切？ //

【B5｜不再求，自己争】

【看向风清雁，站稳】
我说过原谅你，那是真心的。 /可原谅你，不代表我就该把自己的一辈子让出去。 //
我不会再求他了。 /
不能每一次，你们用一句话、一把剑拿走我的一切，而我只能等、只能求。 //
(重读)想要的东西，我会自己去争。 /今天，我是来拿回自己的人生的。 //

【B6｜换珠与失认】

风清雁，你换给我的，不只是莲心珠，还有你的因果和亲缘。 /
我早就发现了，只是没告诉你。 //
大师兄那张符，不过是让这一切快一点。 //
你还记得他怎样疼过你。 /可现在，他连你是谁都不认了。 //
(重读)你明明还是你，对不对？ //
我当年也没有变。 /还是那个孩子，还是想靠近他。 /可他看着我，就像从来没见过。 //

【B7｜独不照我的明月与旧本】

【看着风清雁，声音慢下来】
风清雁，他答应你的事，总肯替你做到。 /你掉一滴眼泪，他就舍不得。 //
他也能疼归容这个徒弟，把他放在心上。 /这些，我都看见过。 //
(重读)可我这个儿子，等了他那么久，他却怎么都不肯多看一眼。 //
我没有想过，要他只疼我一个。 /我只求那明月，能分一缕余光给我。 //

【停一下，压住声音，把恨说清】
可云谦连这一缕余光，都不肯施舍给我。 //
(重读)所以我恨他。 /(重读)我恨明月高悬，独不照我。 //

【停一下，举起已经取到的旧本】
你的名字、父亲、过去，都在这里。 //
我九岁那年，本也被拿走了。 /我说拿错了，我有名字、有爹娘，可没人理我。 //

【按现场约定处置旧本】
现在，你也没有了。 //

【B8｜新本、十世与威胁】

二十岁生辰，我替你写了一份新人生。 //

【向归容伸手】
(重读)大师兄，快拿给她看看。 //

【等归容接词交本，翻到第五、六幕】
跟父亲有关的，都划了。 /他写给你的信，我看过了，也撕了。 //
写得真好。 /(重读)可那么多话，没有一句是写给我的。 //

【翻到爱情部分，像在展示礼物】
你看，十生十世，每一世都有我们。 //
你觉得不够，我还可以写。 /(重读)可这一次，别再翻过我的名字，去找别人了。 //

【把本递给她，语气转冷】
不想读？ /你没有因果，我伤不了你。 //
(重读)可云谦有。 /我的莲心珠能降祸，你真觉得我舍不得他那条命？ //
这本书，你看，还是不看？ //

【B9｜展示大礼】

【转向幕帘】
对了，我还给你准备了一份大礼。 //
(重读)来！ / 看啊！ / 看看你喜欢吗！ //

【交出展示口令，接主持后续，不再追加输出】
