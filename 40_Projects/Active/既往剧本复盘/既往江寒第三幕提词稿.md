# 江寒 · 第三幕提词稿

> `/` 短停；`//` 长停、换气或转情绪。加粗处重读；【】内提示不读出声。

**【看着风清雁，带一点笑】**  
风清雁。 /  
之前写信和你吵架，我什么都敢说。 / 真要当面说心里话，倒是胆小了。 //  

**北地笨猪，我喜欢你。** //  

问心阵里，看见你害怕，我就想陪着你。 /  
雾林里，你没有推开我，我真的很开心。 //  

我也想过，往后的日子，能不能一直这样陪你走。 //  

不用每次靠近，都先算会不会受伤。 /  
也不用明明舍不得，还非要装得不在乎。 //  

平时我总跟你争输赢。 /  
可这件事，我不想再嘴硬了。 //  

**【拿出木箱】**  
闭上眼。 /  
一，二，三。 //  

十岁到十九岁，每一年的生辰礼，都在这里。 //  

我知道，你不是不想有人陪。 /  
你是怕莲心珠伤了靠近你的人，才总把人推开。 //  

那十年，我补不回来。 / 可欠下的生辰礼，我想一份一份补给你。 //  

我知道，礼物补齐了，也不能让从前的你少难过一天。 /  
可往后过生辰，我想陪在你身边。 //  

你可以盼一盼那一天。 /  
有人记着，也有人等着给你过。 //  

你不能做的事，我替你做。 /  
你看着，也算我们一起做过。 //  

风清雁，若我不是羽幽城祭司了，我们还能像现在这样吗？ /  
你在雾林里说的话，还作数吗？ //  

**【稍停，接她的反应，再转向云谦】**  
**师父，带雁雁回座位吧，我有些事想和大家说。** //  

**【等她回座，独自留台】**  
各位，对不起。 /  
我之前骗 / 了你们。 //  

我不是羽幽城祭司江寒。 / 那些关于羽幽城的故事，都是我编的。 //  

因为只有借着这个身份，我才能来到小苍山。 /  
我想见我想见的人，我更想拿回属于我的名字。 //  

今天，我想把一切讲给你们听。 //  

**【名字说清，放慢一点】**  
**我也叫风清砚。** //  

我的母亲，是莲心城大祭司风怜。 /  
“秋透书台笔砚清”，娘从这句诗里给我起了名字。 //  

我的砚，是砚台的砚。 //  

她从不叫我少祭司。 /  
她只会叫 / 我阿砚。 //  

后来我换过名字，借过身份。 /  
可我一直记得，娘叫这一声的时候，叫的就是我。 //  

我也曾有 / 过父亲。 /  
**【看向云谦】**  
叫云谦。 //  

九岁以前，我和风清雁，有一样的人生。 /  
我也曾有一颗能赐福、降祸的莲心珠。 //  

可如今，它也和我一样，成为一颗废珠了。 //  

我听到有人说， /  
父子线没有市场，要把父子线改成父女线。 //  

于是，少祭司成了小圣女。 //  

只是改了几个字，我便失去了一切。 //  

**【稳，停一下再说】**  
**可我却没有死。** /  
我不知道这是好运还是悲剧。 //  

我还记得阿娘，记得云谦，也记得莲心城的一草一木。 //  

只是他们不再记得我了。 /  
我的名字、身份、亲缘和因果，全都属于另一个人。 //  

我明明还活着，别人却像我从没来过。 /  
我的存在就这么简单的被替换掉了。 //  

对写故事的人来说，旧稿换掉了，只需继续往下写。 //  

可我还留 / 在这儿。 /  
我记得的每一件事，都没有人承认。 //  

我想说一句，“这也是我的家”，都像在争抢别人的东西。 //  

**【看向云谦，轻一些】**  
师父，您叫我江寒，我会答应。 /  
您叫我徒弟，我也高兴。 //  

因为这样，我就能离您近一点。 //  

我知道，师父和爹，不是一回事。 /  
可我还是想，也许相处久一些，您会再多看我一眼。 //  

不用我借谁的名字，也不用我先证明自己有用。 //  

我今天不是来逼您认我的。 /  
我只是想让您知道，站在这里的人，也曾经是您的孩子。 //  

**【转向风清雁，先说旧恨，再慢慢放轻】**  
风清雁，我恨过你。 /  
在我眼里，你就是偷走我人生的人。 //  

我知道，改故事的是编剧，不是你。 /  
可名字、身份、父亲，最后都落在了你身上。 //  

你过着我被拿走的日子，我却连认回自己的名字都难。 /  
你让我怎么不恨？ //  

可你又偏偏像另一个我。 /  
看见你，我就会想，要是我没有被删掉，会不会也能这样活着。 //  

后来，你花十两银子买我的馒头，陪我斗嘴，拉着我走进雾林。 /  
我越来越舍不得你。 //  

本来是想找回自己的人生。 /  
到后来，却开始盼着，我的人生里能有你。 //  

**【看着她，认真，不像施舍】**  
**所以，风清雁，我愿意原谅你。** //  

不是那些年不疼了，也不是失去的东西不重要了。 /  
是我喜欢你，不想以后每次看见你，都只想着自己丢了什么。 //  

我不想再把这笔账算在你身上。 /  
我想和你有一个以后。 //  

从前的事，你已经知道了。 /  
往后的路，你还愿不愿意陪我走？ //  

江寒这个名字是假的。 /  
可相处是真的，心疼是真的，喜欢你，也是真的。 //  

所以这一次，我不想再借别人的名字说了。 //  

**【看着她，不上前逼近】**  
**我叫风清砚。** /  
**我喜欢你。** //  

你还愿意接受这样的我吗？ //
