# 江寒 · 第六幕提词稿

> `/` 短停；`//` 长停、换气或转情绪。加粗处重读；【】内提示不读出声。

**【归容说“清砚师弟，我这个大师兄，当得如何啊？”后开始】**

**【归容叫“清砚师弟”后起身，笑一下】**  
多谢大师兄。 /  
办得漂亮。 //  

许尽欢，别急着拿云妄这个名字替我定罪。 //  

**【仍看着许尽欢，让众人听清】**  
云谦给我取名云妄。 /  
他说，往事如烟，皆为虚妄。 //  

他倒宽宏大量，替我忘了个干净。 //  

要换我来说：**云，是翻卷残云，祸乱天罡。** /  
**妄，是胆大妄为，逆命伐圣。** //  

你的剧本里说，淮朝和云妄要杀他。 /  
那他倒亲手给自己的索命鬼起了名字。 //  

**【看回众人，站稳】**  
可我本来就有名字。 //  

**我是莲心城少祭司，我叫风清砚。** //  

**【转向风清雁，再看向众人】**  
那天站在台上，我把什么都说了。 /  
我以为，只要他知道我是谁，知道这些年我是怎么过来的，就会认我。 //  

我甚至不敢逼他。 /  
他叫我徒弟，我就应；能离他近一点，我就觉得，还有机会。 //  

**我那时候，是真的想认回这个家。** //  

可说完了呢？ /  
你还是他的女儿，我还是江寒。 //  

他听见了我的名字，也知道了我的身世。 /  
可他还是不要风清砚这个儿子。 //  

我以前不是这样想的。 /  
他答应的时候，我是真的高兴。 //  

后来没等到，我也没敢怪他。 /  
我想，他那么忙，再等等吧。 //  

可等到后来，我都不好意思再问了。 /  
好像一开口，就是我不懂事。 //  

**我只是想问一句，还算不算数。** /  
**怎么连这句话，都不敢说了？** //  

**【看向许尽欢，把旧事说清】**  
十年前，你两句话，就拿走了我的名字，改掉了我的人生。 //  

那时候我才九岁。 /  
我连自己的名字都保不住，更别说反抗你。 //  

可我还是活下来了。 //  

**【声音放缓，提起真正养大自己的人】**  
是我的师父，枪仙纪泽苍，把我养大的。 //  

云谦不要我，是他给我住处，照顾我，陪着我长大。 /  
我丢了一个家，可我又有了一个家。 //  

在云谦那里，我求一声儿子都求不来。 /  
可在纪叔那里，我不用先证明自己是谁，他也会管我。 //  

**他是我的师父。** /  
**也像我的父亲。** //  

**【停一下，压住声音】**  
可他死了。 /  
死于剑伤。 //  

**杀他的人，是云谦。** //  

**【看向风清雁】**  
他不肯认我，我认了。 /  
可连那个肯养我、肯疼我的人，他也要杀？ //  

我去找他认亲，不是因为我从来没被人疼过。 /  
是我还盼着，亲生父亲也能认我一次。 //  

可他不肯给我的家，纪叔给了我。 /  
最后，他连我这个家也毁了。 //  

十年前，许尽欢拿走我的名字。 /  
十年后，云谦又杀了养大我的人。 //  

**我好不容易又有的家，他凭什么夺走？** //  

他凭什么不要我， /  
还不许别人疼我？ //  

**【站稳，收掉诉求的语气】**  
我不会再求他了。 /  
我也不会再让你们用一句话、一把剑，就拿走我的一切。 //  

**求，是求不来的。** /  
**想要什么，就得靠我自己的手去争。** //  

我说过原谅你，那是真心的。 /  
可我愿意原谅，不代表我就该把自己的一辈子让出去。 //  

我想要身份，想要亲人，想要一个能留下来的地方。 /  
凭什么都得等别人点头？ //  

**不给，我就自己拿。** /  
**没有我的位置，我就自己争。** //  

今天，我不是来问你们肯不肯的。 /  
我是来拿回我的人生。 //  

风清雁，刚才他问你是谁，你听见了。 /  
当年，他也这样问过我。 //  

你换给我的，不只是莲心珠，还有你的因果和亲缘。 /  
我早就发现了，只是没告诉你。 //  

大师兄那张符，不过是让这一切快一点。 //  

你看，珠子换了，因果换了，他认的人也换了。 //  

你记得他说过什么，替你做过什么。 /  
可现在，他连你是谁都不知道。 //  

**你明明没有变，对不对？** /  
**我当年也没有变。** //  

还是那个孩子，还是一样想靠近他。 /  
可他看着我，眼里就是没有我。 //  

我把身世讲得再清楚，他也不认。 /  
换了珠子，再加一张符，他倒肯叫儿子了。 //  

原来，等他回心转意没有用。 /  
把因果握在手里，才有用。 //  

**他肯不肯认，已经由不得他了。** //  

我知道，你舍不得你爹。 /  
可你能不能也明白，我为什么舍不得我娘？ //  

她到死，也没等到他。 /  
我不能替她说一句，算了。 //  

你可以原谅他。 /  
可我和娘的那些日子，不能跟着一起被算了。 //  

他答应过什么，我听得够多了。 /  
我要的是他做到，是我娘活着等到他。 //  

**【看着风清雁，放慢，念完两句再问】**  
**明月高悬，独不照我。** //  

**明月高悬，曾独照我。** //  

**风清雁，你说，哪个更痛？** //  

**【留一拍；她若回应，先听完】**  

你至少知道，被他放在心上是什么滋味。 /  
我没有。 //  

我看着他疼你，才知道，他不是不会疼孩子。 //  

有人掉一滴眼泪，就有人替她摆平一切。 /  
有人哭哑了嗓子，等的人也不会来。 //  

如今轮到你了。 /  
你还觉得，一句忘了，就能让人等下去吗？ //  

**【举起已取到的旧本】**  
你还有这个。 /  
名字、父亲、过去，全写在里面。 //  

我九岁那年，本也被拿走了。 /  
我说拿错了，我有名字，有爹娘。 / 没人理我。 //  

**【按排练处置旧本】**  
现在，你也没有了。 //  

你知道自己是谁，也记得他怎样疼你。 //  

**可你记得，有什么用？** //  

你说得再清楚，他也只当你认错了人。 /  
你越着急，越像是在胡闹。 //  

风清雁，我当年就是这样。 /  
我们连委屈，都得先证明自己有资格。 //  

**【稍停，语气放柔】**  
当年，他们把我扔下，什么都没留。 //  

**可我给你留了我。** //  

你从前是谁，和我经历过什么，我都记得。 /  
别人不认，你来问我。 //  

二十岁生辰，我替你写了份新人生。 //  

**【向归容伸手】**  
**大师兄，快拿给她看看。** //  

**【等归容接词，接新本，翻到第五、六幕】**  
跟爹有关的，都划了。 /  
他给你的信，我也撕了。 //  

信写得真好。 / 可写给我的，一封都没有。 //  

**【提，只重这一句】**  
信也好，爱也好。 /  
**这爹线，我可以不要，但我不能没有！** //  

认不认他，是我的事。 /  
轮不到你们先拿走，再劝我大度。 //  

**【翻到爱情部分，像展示自己认真准备的礼物】**  
往后看，十生十世，全是我们。 //  

往后，你的故事里都有我。 //  

**你也别再把我留在故事外面。** //  

以前我等别人给我一个以后。 /  
现在，我自己写。 //  

每一世，都有我的名字，也都有你。 //  

你觉得不够，我还能写。 /  
可你别翻过我的名字，又去找别人。 //  

**【把本递给她；从期待转为威胁】**  
不想读？ /  
你没有因果，我伤不了你。 //  

**可云谦有。** //  

我的莲心珠能降祸。 /  
你真觉得，我舍不得他那条命？ //  

这本书，你看，还是不看？ //  

**【转向幕帘，重新轻快起来】**  
对了，我还给你准备了一份大礼。 //  

**来！ / 看啊！ / 看看你喜欢吗！** //
