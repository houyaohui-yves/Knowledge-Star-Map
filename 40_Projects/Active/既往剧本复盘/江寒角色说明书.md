# 《既往》江寒角色说明书

> **全剧透，供扮演江寒的玩家准备和逐幕查阅。** 包含角色本之外的主持流程，不适合在未获其他玩家同意时分享给全桌。现场实际台词以 DM 发放的大卡为准；本文提供剧情理解、行动顺序和接话提示，不代替原卡。

## 怎么使用

开场前先看“人物底稿”和“你到底有哪些输出”；准备演绎时重点读第三、六、九幕的“输出内容拆解”。这些拆解是对原卡的内容概括，不是新增台词。**玩家预先知道的后续真相，不等于角色此刻可以说出来。** 不提前揭穿反转，也不因为看过全本跳过 DM 的行动讲解。

本文用以下标记区分流程：

- **【小黑屋】**：离场与 NPC 发生角色内剧情。
- **【心建】**：DM 以场外身份解释信息或排练动作。戴墨镜的演员不是正在以其 NPC 身份告诉你秘密。
- **【大卡】**：根据行动卡输出；可能在主房间，也可能上台，不把两者混为一谈。
- **【小剧场】**：多人按提示接话的短场景。
- **【文本】**：角色本中发生的事件，不代表玩家必须在现实中演一次。
- **【领物／换本】**：信件、行动卡、角色本等现场交接。

所有身体接触、攻击、撕纸和碎珠动作都使用本场 DM 指定的道具与排练方式；小说里的动作不要自行照做。

## 人物底稿：你究竟是谁

你以“江寒”进入众人的生活，但你并不是真正的羽幽城祭司江寒。你的核心身份是**风清砚**：云谦与风怜原先故事中的儿子。改稿删去了你原本的人生，新的女儿风清雁占据了父亲的记忆与故事位置。第四幕，云谦又为你取名**云妄**。因此，“江寒”“风清砚”“云妄”不是三个由你轮流扮演的独立人物，而是同一个人的伪装、旧名和后来所得之名。

你的核心欲望是：**让被删去的自己被看见，让别人承认你也曾有家、有父母、有完整的人生。** 母亲风怜的四封信是这条线的支点。你对云谦既渴求又怨恨；对风清雁既有爱情，也有“为什么你能得到我失去的一切”的愤怒。不能把角色简化成纯粹恋爱脑，也不能把一切伤害解释成“都是为了她好”。

| 对象 | 你与对方的关系，以及演绎抓手 |
| --- | --- |
| 云谦 | 想被他认回，又无法接受他的爱能被改写、被符咒切换。前期试探和讨好，后期主动索取、质问与报复。 |
| 风清雁 | 你爱她，也把她当作自己被替代的证明。第六幕不是普通表白，而是强行让她经历“人生被收走、被改写”。 |
| 风怜 | 母亲与回家的方向。春夏秋冬四信形成贯穿十幕的私人线。 |
| 归容 | 阶段性合作者。第六幕共同利用锁灵符，但你不因此把他视作可靠、无私的兄长。 |
| 阿蒲／许尽欢 | 与改稿、操纵人生有关。你必须按幕获得信息，不能第一幕就把后续全部责任说透。 |
| 纪泽苍 | 母亲和旧日生活的重要关联。第四幕得知其死讯，不等于此刻已知云谦是凶手。 |

**推荐的情绪节奏属于本文的表演建议：** 前期用轻松和亲近掩盖委屈；第三、四幕短暂接近“终于被认回”；第六幕夺回叙述权；第九幕让伤害、爱和不甘同时落地。具体音量与风格可按个人习惯调整，不必全程激烈。

## 你到底有哪些输出

## 第一幕：从“江寒”走向风清砚

**剧情与心态。** 按 A-1 的阅读顺序进入角色，不要开场就主动报风清砚。觉醒后，你发现自己的真实人生被改写，而那个本该是父亲的人不认识你。表面可以继续亲近、打趣，内里是确认自己是否还存在于别人的记忆中。

**现场行动。**

1. 【领本】从《江寒 A-1》开始。读到“带上你全部的记忆，离开这里”的提示再离场。
2. 【心建】淮朝演员戴墨镜核对身份时，按觉醒后的真实身份回答：**风清砚**。这不代表你已向主房间所有人公开。
3. 【小黑屋 A】先接阿蒲的觉醒剧情，取得觉醒卡与风怜的**春信**。云谦随后按流程进入；你呼唤父亲，却遭遇他的不认得。
4. 【换本】领《江寒 A-2》，继续它的**第一幕**。A-1、A-2 是第一阶段的接续，不是“一本一幕”。
5. 【主房间】按角色本参与分享和互动。把“认爹”的渴望留在适合的场景里，不自行把整套废稿真相一次讲完。

**此幕要保留的差异：** 你知道自己是谁，云谦并不因此同步恢复记忆。小黑屋具体对话另有 NPC 手册，现有材料不足以复写完整台词。

来源：江 A-1 第 4–15 页；江 A-2 第 3–24 页；主持第 11、30–31 页。

## 第二幕：母亲的信，与仍需维持的身份

**剧情与心态。** 问心阵牵出“思”与母亲。你仍要维持江寒的外在身份、靠近风清雁与云谦；内心有了旧人生的坐标，却暂时拿不回它。收到信后的情绪可以收住，回主房间仍继续角色当前的社交目标。

**现场行动。**

- 【领物／心建】按指示离场，由云笙演员以墨镜 DM 身份交接母亲的**夏信**并讲解。**这一趟不等同于新增一场与云笙的角色内小黑屋。**
- 【主房间】观看归容、淮朝的小剧场，参与师门与 CP 互动；按本中任务向柳沐瑶问起地灵符等相关信息，继续贴近父女。
- 本幕未见独立安排给你的上台大卡。不要因为别人有演绎就自行加入一段身份爆料。

来源：江 A-2 第 25–46 页；主持第 43、45–51 页。

## 第三幕：先把爱送出去，再把自己说出来

### 上台前，故事走到了哪里

地点是**榕夕城的祈缘节爱情场**。此前你与风清雁喝酒、翻墙，答应带她去羽幽城，却根本不认路——因为你的羽幽祭司身份是假的。在雾林里，你试探她：“如果我不是羽幽城祭司，我们还能像现在这样吗？”她没有因这个假设推开你，你们随后接吻，最后被云谦找到并带回。

这一夜使你对她的算计中混入了真实心动。与此同时，云谦托你替他补送女儿十至十九岁的生辰礼，并要求别告诉她是父亲的意思：原先备下的木剑、灵药等被认为不合适，于是由你置办礼物、他出钱。**你上台送礼既借用了父亲的安排，也借它推进自己的爱情。**

更紧迫的是，云谦告诉你：他已给羽幽城写信，那边回信说祭司江寒一直在城里。你的假身份随时会被揭穿。于是你决定抢先坦白，把“一个处心积虑的骗子”改呈现为“一个被删掉人生、不得不抓住假身份的可怜人”，争取信任与同情。**所以本场不是单纯情到浓处才自报身世，而是爱情、委屈和危机下的主动自保同时发生。**（江 A-2 第 54–62 页。）

现场前面几组 CP 已完成表达，归柳刚下台；云谦以父亲身份警告你照心镜阵里不能说谎，然后叫你和风清雁上台。**你此刻面对的是“证明真心”的场面**，并不知道他们全部的幕后盘算。手册给风清雁的私下信息是阵法只罩住你；这属于玩家可知的流程背景，不是让江寒当场揭穿的知识。

### 你要输出什么：同一场的前后两段

以下按原大卡顺序概括，可用来理解每一段为什么说；正式演出仍读本场原卡。

| 段落 | 说给谁、说什么 | 本段想达到什么效果／动作 |
| --- | --- | --- |
| A1：借阵说真心 | 对风清雁：沿用“北地笨猪”的称呼，承接喝酒后反而胆小的共同记忆，表示想借照心镜阵勇敢一次 | 从你们熟悉的相处方式进入，不突然像在对陌生人念情书。 |
| A2：补十年生辰 | 你想过她如何独自走过十至十九岁，因此要补上这些年的礼物 | 请她闭眼、数到三，拿出小木箱，给礼物被看见的时间。 |
| A3：表白与试探接受 | 你愿替她做那些她不能做的事，愿意陪她；明确说喜欢，再问“不做羽幽祭司，还能不能像现在这样” | 回扣雾林问答，为马上揭穿身份铺路；此时还没对全桌解释废稿。 |
| 转场 | “师父，带风清雁回座吧，我有些事想告诉大家。” | 等她回座，你独自留在台上，把对象从爱人扩展到全桌。 |
| B1：重新自我介绍 | 承认不是羽幽祭司江寒，报出风清砚，砚台的砚；说明九岁前与风清雁有相同经历，父母也是云谦、风怜 | 名字、父母、前九年是必须听清的信息，不只抽象说“我也很惨”。 |
| B2：解释莲心珠与废稿 | 你的珠子原可赐福也可降祸，如今已废；因“父子线没有市场”被改成父女线，你被删除，却仍活着，失去身份、父母和因果 | 让其他玩家真正理解：废稿不是死亡，而是活着却被世界抹掉。 |
| B3：承认伪装与曾经的恨 | 承认恨过她占有自己的人生；截下她与羽幽城的信，冒用江寒通信，羽幽城相关讲述也是编的 | 主动交代造假，把可能被揭穿的事先拿到自己手里解释。 |
| B4：把话收回爱情 | 相处、心疼和部分真心并非全假；你理解她被莲心珠困住的委屈，因为有共同起点；问她还愿不愿接受你 | 以“我们不是同一人，但我能理解你”收尾，让她看见值得被爱的风清砚。 |

**角色此刻的内外两层：** 对外可以承认“曾经恨过”，但要表现如今愿意真诚亲近他们；内心仍有恨、算计和利用，不把所有真实意图都说完。原本要求的是真假掺半，不是表白后真的放下一切，也不是站上去就揭露后续复仇计划。

**现场行动：第四组 CP 输出。**

1. 【心建】读到幕末离场提示，由云谦演员戴墨镜核对礼物和大卡。准备覆盖十至十九岁的生日礼物。
2. 【上台大卡】等前面的萧然、许尽欢、归容相关输出结束，轮到你与风清雁。
3. 先完成爱情表达与赠礼。礼物创意与云谦有关，但他不希望被点明；你在这场里借此推进自己与风清雁的关系。
4. 按大卡请云谦把风清雁带回座位，**你继续独自在台上输出**，不要跟着下台。
5. 讲清假江寒／风清砚身份，以及对应的信件、经历包装与降祸信息。身份硬信息要说清，不因即兴抒情漏掉反转。
6. 随后的去留争论，你推动去莲心城；归容倾向留在榕城。角色间可争辩，但不要把剧本既定转场变成现实投票卡住流程。

### 说完后会发生什么

你说完下台，阿蒲会向众人解释“废稿”，再问九岁以后是谁照顾你，带出**纪泽苍**。云谦承认曾把那个失去父母的孩子托付给纪泽苍，却拒绝接纳“你是他的儿子”这一层意义，坚持自己只有女儿，并仍叫你江寒。

因此，**这场公开坦白让全桌知道你是谁，却没有让你获得想要的父子承认。** 这是第六幕你不再满足于解释、转而让符咒和换本替你“证明”的情绪前因。演员应接住这种落差，不把第三幕演完当作已全员和解。

来源：江 A-2 第 47–62 页；主持第 65–66、74–79 页。

## 第四幕：挡掌、换珠，以及“云妄”这个名字

**剧情与心态。** 莲心城事件将你与风清雁、云谦绑得更深。你与淮朝的交易使“挡掌”有事先安排的成分；在众人面前，你是**替云谦挡掌受伤**，随后又担心风清雁承担换珠风险。你最终得到云谦赐名“云妄”，靠近了梦寐以求的父子位置，但旧日风清砚的伤并未因此消失。此幕听见纪泽苍死讯，**还不要提前把云谦指认为凶手**。

**现场行动。**

- 【小剧场】按 A-2 第 80 页提示，在 DM 引导时翻到后面的短场景；不要读到就自行起身攻击或倒地。
- 在“挡掌—受伤—换珠”的接话中，先体现放弃／不愿对方冒险，再进入接受换珠的状态。哪些动作需要实体演出由 DM 指定。
- 【共同誓句】与风清雁按提示衔接“为莲心城永存”“为荣耀不灭”“为万民之福”。
- 【命名】接住云谦赐名云妄的剧情。这是本次人物关系的重要兑现，不是恢复成真正的羽幽江寒。
- 【换本】中场之后领《江寒 B 本》，从第五幕继续。本幕没有另行安排你的独立小黑屋或独立上台大卡。

来源：江 A-2 第 63–82 页；主持第 82–91 页。

## 第五幕：旁观婚礼崩塌，保留自己的算盘

**剧情与心态。** 归容与柳沐瑶的婚礼转为云笙遇害、阿蒲掌控身体的重大反转，编写故事的人与角色之间的关系进一步暴露。你的利益判断仍围绕自己、风清雁和云谦：角色任务对“谁能成为杀淮朝的人”有排除条件，不是让你主动去接这次杀人任务。

你知道的自身因果线——包括父亲唤“阿砚”等所引起的变化——不要为了帮大家推理而无条件交代。此刻既有被父亲承认的期待，也有对这一切可靠性的怀疑。

**现场行动。**

- 【主房间】观看归柳婚礼、萧然行动及阿蒲出现，根据当幕知识回应。
- 按本中任务推动局面，但不抢归柳婚礼的仪式位，也不替别人提前揭露阿蒲／许尽欢线。
- 【质问窗口】阿蒲揭露许尽欢是编剧后，会把删稿与众人苦难指向她，并留出争吵时间。你可以质问删掉风清砚、安排风清雁苦难的责任；阿蒲控场时收住。这不是个人上台大卡，却是需要主动参与的输出。示范见[全气口输出攻略](既往江寒全气口输出攻略.md)第五幕。
- 手册未安排本幕江寒专属小黑屋或独立大卡；若 DM 临时带走核对信息，以现场安排为准。

来源：江 B 第 5–13 页；主持第 94–102 页。

## 第六幕：夺回父亲，亲手改写她的人生

**剧情与心态。** 许尽欢想把“反派”责任指向云妄。你与归容合作，通过锁灵符让云谦认回儿子、忘记女儿，再把风清雁的人生本收走，交给她由你写定的新人生。你要她亲身经历“旧人生被删去”，但这同时也是你对她的伤害与控制。

你的真实目标包含摆脱云妄的反派位置、做回风清砚；不能把这一连串行为只演成恶作剧，也不能仅以“爱她”替它开脱。

### 站起来之前，为什么局面会变成这样

第三幕你已经把废稿身份讲出来，却没有被父亲认回。第四幕你替云谦挡掌，风清雁把有效的莲心珠换给你；随后云谦给你取名“云妄”。**换珠同时推动因果转移**，但此时父亲尚未自然、完整地只认你。

这一幕，许尽欢召集众人，想通过指认“云妄才是反派”救淮朝。你若接受云妄这个位置，就可能成为别人牺牲的对象。因此你先否认、装作被冤枉，与归容配合把话题引向“保护云谦”。归容拿锁灵符冒充守诚阵，骗云谦点燃，压制其灵台，使换珠带来的因果盖过原先意识。

**等到你的正式输出开始，关键的事已经发生了：云谦亲口说最重要的是儿子风清砚，并且不认识风清雁；归容已经让他离开。** 归容随后对阿蒲表忠、与柳沐瑶假争吵。你利用这段时间拿到风清雁的旧本，直到归容点名，才撕掉“不知情”的伪装。

所以这一场的地位与第三幕相反：第三幕你请求别人相信自己的叙述；第六幕你把父亲、身份和书册的变化摆在面前，宣布别人必须接受你的安排。

### 你的大卡到底说什么

| 段落 | 输出内容 | 这句话背后的目的／动作 |
| --- | --- | --- |
| 1：否定云妄，宣布风清砚 | 感谢大师兄办得漂亮；宣告世上没有云妄，只有莲心城祭司风清砚 | 同时回应许尽欢的指控、宣布夺回身份，不能只顾对风清雁嘲讽而漏掉这一层。 |
| 2：解释换珠的代价 | 告诉她换来的不仅是珠子，还有因果；即使没有归容加速，父亲遗忘她也只是时间问题 | 把她当初救你的选择反过来作为如今剥夺她的理由。这是角色的说辞，不是公平裁决。 |
| 3：交换你我处境 | 现在父亲和人生归你，她成了无名之人；你当初只剩自己，而她至少“还有你” | 逼她承认你受过的痛，并用“你还有我”包装控制。 |
| 4：送二十岁生辰礼 | 介绍亲手写的“完美人生”，叫归容拿出新 B-2；展示父亲线被划掉，后面只剩你安排的十生十世爱情 | **第三幕补十岁到十九岁，第六幕送二十岁**，同样是生日礼物，性质已经反转。 |
| 5：毁掉旧父女联系 | 告诉她旧本里那封父亲的信你看过，并已撕掉，因为那是你的爹 | 让她看见旧人生不只是被解释掉，而是被你直接处置。具体道具动作按心建。 |
| 6：逼她接受新本 | 强调你们不是同一个人，你会用莲心珠降祸；现在伤害不了无因果的她，却能伤害云谦，以此迫她读 | 这一段是逼迫，不要软化成“我送你一本书，随你看不看”。现实只演指定台词与道具。 |
| 7：展示更大的礼物 | 说“来！看啊！看看你喜欢吗！” | 让 DM 打开幕帘、展示婚照易拉宝。先留出反应，再由 NPC 接下去。 |

**你当场的自我理解是“终于轮到我决定人生，而且我还给了她爱情”。** 玩家可以理解其中的伤害，但不要因此把大卡改读成愧疚道歉；原场景要求的是主动宣告、得意与施压。读前仍要完成装无辜的铺垫，两种状态的转换才是反转。

**【幕末心建】** 读完本按提示离场。淮朝演员戴墨镜向你核对行动卡，展示风清雁 B-2。务必记住下列顺序；**新本先由归容保管**。

| 顺序 | 听到／看到的信号 | 你的行动 |
| --- | --- | --- |
| 1 | 许尽欢指认你是反派 | 装无辜、否认，表现成她为救爱人而迁怒你。 |
| 2 | 归容让云谦点符，问最重要的人 | 继续装作不知内情。父亲认儿子后，可依卡呼唤父亲，同时安抚风清雁、假装不知归容干了什么。 |
| 3 | 云谦离场；归容表忠、与柳沐瑶争吵 | 利用这段输出，按预先排练的方法取得风清雁的旧 B 本。不要还没开始就明抢暴露计划。 |
| 4 | 归容：“清砚师弟，我这个大师兄，当得如何啊？” | 停止伪装，站起进入自己的大卡输出，明确“我是风清砚”。 |
| 5 | 你：“大师兄，快拿给她看看。” | 接过归容保管的新 B-2，完成换本，并向风清雁展示被划去的父亲线与后续十生十世爱情。 |
| 6 | 你：“来！看啊！看看你喜欢吗！” | 给 DM 展示婚照等惊喜的信号，留出展示时间，不把台词一口气读过去。 |

**这场是主房间的连锁输出，具体站位按本场 DM。** 旧本的丢弃／处置使用演出用本。不要处理其他玩家私人物品。

**结束时的认知：** 符咒确实改变了父亲的表现，但这并不证明你终于获得不可改写的爱；这正是后面继续撕裂你的问题。与归容的合作也是各取所需。

**场景怎样收尾：** 展示婚照后，阿蒲会夸赞你写的爱情、强调“侯府少爷狠狠爱”等内容，再宣布如今只剩杀淮朝这一件事，推进第七幕。你不用在展示后另外追加一段和解表白。紧接着的第七幕小黑屋，才会把“父亲只认你”落到你、云谦和风清雁三人面对面的冲突中。

来源：江 B 第 14–25 页；主持第 104–115 页。

## 第七幕：让她看见“只认你”的父亲

**剧情与心态。** 主房间发生归容刺杀淮朝、淮朝选择破阵赴死的事件。你的私人线则是向风清雁展示：父亲现在认你、不认她。你想证明原来由她获得的亲情也能被夺走，但这种胜利不能让母亲回来，也不能真正补回自己的人生。

**【小黑屋 A：云谦＋风清雁＋你】**

1. 风清雁先进入。**你等待阿蒲带入，不自行提前冲进小黑屋。**
2. 按场景以“爹”等呼唤切入，让“云谦认谁”成为当场可以看见的冲突。
3. 与云谦有关的信／纸条有指定处理动作；只使用 DM 准备的道具。撕纸会影响后续拼合，不要随意增加撕毁其他物件的动作。
4. 文本或 NPC 演绎中涉及伤害自己的行为，由 DM 安排舞台表现，不由玩家临场实施。

本幕没有安排你的独立主房间大卡。小黑屋的详细对白在另附 NPC 手册，现阶段只能确定入场顺序、冲突目的与关键道具。

来源：江 B 第 26–31 页；主持第 117–118 页及相关流程索引。

## 第八幕：秋信、碎珠规则，与父亲记忆的变局

**剧情与心态。** 照心镜相关内容带来母亲和旧人生的信息。你收到“极致的爱与恨”与碎珠有关的提示；那个声音虽像阿蒲，却存在差异，当前证据不足以在说明书里直接替它钉死身份。

主房间里，柳沐瑶杀阿蒲，归柳复活云笙。云笙破除锁灵符，云谦却仍在表面上认你为儿子。**此时不要直接把玩家已知的“云谦记忆恢复”演成你已经彻底识破；下一幕才有进一步确认。**

**现场行动。**

- 【领物／心建】读到照心镜阵破碎、出门捡取相关内容的提示后，按 DM 安排取得母亲的**秋信**。此节点由阿蒲负责交接／心建，不把它擅自扩展成另一场完整 NPC 私戏。
- 【文本】碎珠方法是你此幕获取的信息，不是立刻打断复活仪式、现场毁珠的行动提示。
- 【主房间】观看柳沐瑶、归容的输出与云笙归来，接住云谦叫你“阿砚”的互动；随后让云笙对锁灵符的追问与破符流程继续。

来源：江 B 第 32–42 页；主持第 129–143 页。

## 第九幕：把爱、恨与报复推到尽头

**剧情与心态。** 你进一步确认云谦的旧案与如今的伪装，将证据交给无上宗，引出围山。你既不接受父亲以过去的选择解释伤害，也不满足于在新的身份里苟且继续。你要父亲先于自己死去，并把风清雁留在自己设计的后果中。

终局不是“两颗莲心珠都消失、所有人获救”：你毁去的是有效的那一颗，留下废珠与反噬的后果。这一点不能被浪漫化的临终表白盖过。

### 上台前的完整因果：你已经不再求他们接受你

第八幕云笙破了锁灵符，第九幕你察觉云谦其实恢复了记忆，却仍装作慈父对你叫阿砚。你明白彼此都在演，也看到云笙去找被你关住的风清雁；你判断他们在谋划杀你、救她。与此同时，你不断伤害与控制风清雁，她反过来否定你对“爱”的理解。（江 B 第 48–53 页。）

你曾试着拿回名字、父亲、人生，又试着让风清雁爱你或恨你，但这些都没有让你有真正的归处。你想到母亲风怜，想到莲心珠与献祭夺走了她，于是把毁掉珠子当作临死前最后要做的事。你已经知道极致的爱与恨可以使它破碎，并主动向无上宗递交证据：**你允许自己死，但要让云谦死在前面，让风清雁对你的恨达到极点。** 这是本中已发生的计划，不是要求玩家现场再演一次报信。

随后，舞台上连续发生三件事，才轮到你：

1. **云谦战死。** 他承认旧案，杀敌补阵后以自己的生命补足缺口，把最后的爱与安排留给风清雁。
2. **云笙说明父女计划。** 云谦早已清醒，一直暗中帮助女儿；镇渊卷轴已暂时取出两颗莲心珠，下一步是让两珠相撞、使她自由。云谦无法亲手杀你，因此让风清雁动手。
3. **风清雁当众攻击你。** 她否认爱情，称父女一直在利用你，攻击你的废稿身份，并以与父亲相关的剑招杀你。说明书记录的是她此刻大卡的说法，不据此倒推“此前每一处心动必然全假”。

你要先听完，再等云笙拿着你的本请你上台，告诉你人生到此为止、有最后的话就说。**此刻你是在死亡结局里作最后一次申辩和反击，并非普通分手后挽回爱人。**

### 终局大卡的七段内容

| 段落 | 你在反驳什么／要说什么 | 情绪与衔接依据 |
| --- | --- | --- |
| 1：我会死，但你爹已经先死了 | 回应她称你恶心、废稿、垃圾：你确实把她最重视的父亲拖进死亡；要她继续恨你 | 接她刚才的话，从反击开场，不从柔声道别开场。 |
| 2：为什么失去一切的必须是我 | 父亲原本也是你的；凭什么两个人之间总由你让步、牺牲 | 从争父亲转向争取作为一个人的位置。 |
| 3：你有父亲，我也有母亲 | 风怜死了；云谦的理由、苦衷与对女儿的道歉，都没有还给你母亲，也没有补偿你们母子 | 母亲不是临时煽情的插话，是你拒绝原谅云谦的中心。 |
| 4：我求过解释和承认，但没有用 | 自己成为废稿无人帮助；向作者、编剧发怒也改不回人生；第三幕讲出了真相，仍被轻视、利用、谋划牺牲 | 回扣全剧经历，解释为什么你从“告诉别人我是谁”走到“自己改”。 |
| 5：我有自己的名字 | 拒绝江寒、云妄这些被放在身上的名字，再次喊出风清砚；没人教你爱、给你爱，你便自己写 | 与第三、六幕形成回扣；这一段原卡是“我有什么错”的自辩，**不是悔罪承认一切错误**。 |
| 6：破坏两珠对撞的解脱方案 | 明知她要让两珠相撞，你偏只毁自己换得的有效珠，把原先属于你的废珠留给她，让她继续灼痛、记住你 | 毁珠既指向使母亲与自己受苦的东西，也保留对风清雁的报复；不是舍身替她解除全部诅咒。 |
| 7：真假与爱恨收尾 | 特效后宣布要占据她余生的美梦和噩梦；最后否定那些许诺，再落在恨与爱都是真的 | 从胜负／报复落到无法消解的爱恨，不额外加原谅、祝福或复合。 |

最后一组原卡收束句为：

> 不后悔，是假的。  
> 对不起，是假的。  
> 陪你一起，是假的。  
> 十生十世，是假的。  
> 但我恨你，是真的！  
> 我爱你，也是真的！

**表演建议：** 台词可以愤怒、委屈、疲惫交替，不需要从头到尾一个音量。先反击她，再替母亲与自己申辩，最后执行毁珠、以爱恨结束。理解角色造成的伤害，不等于必须把他的临终大卡改成道歉；这一点上一版没有分清。

**【幕末心建】** 读完后出门，由云谦演员戴墨镜核对大卡、碎珠信号、灯光停顿与退场路线。

**上台前必须等完两段。**

1. 云谦终战与死亡演绎。围山中其他人受制，关门阵被敌方阵法师压缩；不是你方自行决定把所有人丢在阵外。
2. 风清雁的终局输出。即使她否认此前的爱，也先让她完整说完，不当场抢话改写她的卡。剧情上，她以与父亲相关的剑招杀你，你进入临终输出；实际是否有实体刺击动作，按现场排练，不自行补动作。

**【你的终局大卡】**

- 等云笙引导你说最后的话，再上台。
- 核心内容是被夺去的身份、母亲之死无人弥补、对云谦解释的拒绝，以及你决定自己改写人生的辩解。**按角色此刻“我不接受你们对我的判决”的立场输出**，不自行把原卡变成承认伤害、请求原谅的忏悔稿。
- 到毁珠节点，按排练给出**拍手或响指**信号；等音乐／灯光变化后，再说最后一组真假与爱恨的收束句。
- 最后的“恨你”“爱你”都是真实存在的情绪，不把其中一个演成临时谎言。也不要在特效尚未接上时提前读完最后几句。
- 输出结束后幕帘关闭，由云笙带你去**小黑屋 A**。这是通向尾声阅读的退场，不能自行留在台上继续争辩。

来源：江 B 第 43–55 页，另参第 56–59 页的尾声衔接；主持第 146–160 页。

## 第十幕：先读冬信，再回家

**剧情与心态。** 尾声把你带回童年、母亲与家。它给风清砚的失落提供情感上的收束，但现有资料不足以把这段确定为“你已在同一现实世界复活，之前的后果全部撤销”。保留它作为个人归家尾声的意义。

**现场行动。**

1. 【独处阅读】在小黑屋 A，**先读风怜的冬信，再读第十幕**。这里虽沿用黑屋空间，却不等于又开启一场完整 NPC 对话。
2. B 本第十幕开头含有终局相关的回顾／衔接，不要因此把第九幕已经完成的上台动作重新演一遍。
3. 阅读完按 DM 引导回主房间。外层游戏结算继续，由归容、柳沐瑶等完成相应输出；你没有被单列一份第十幕个人大卡。
4. 部分结局与墨镜谢幕由本场选择，不预设每场必演同一版本，也不抢先告诉其他玩家结算答案。

来源：江 B 第 56–65 页及第 66–67 页角色复盘；主持第 160–173 页。
