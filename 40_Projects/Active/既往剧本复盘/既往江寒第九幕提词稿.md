# 江寒 · 第九幕提词稿

> `/` 短停；`//` 长停、换气或转情绪。加粗处重读；【】内提示不读出声。

**【云笙请上台后，走到指定位置；看向她，声音带着压不住的委屈】**  
**大家好啊，我是云妄。** /  
**这是云谦给我起的名字，我是阿蒲笔下最大的反派。** //  

可云笙，你们给我定下这个名字以前， /  
我只是一个想回家的孩子。 //  

十年前，一句父子线没市场，我就没了名字。 //  

我还记得自己的娘，记得家在哪里。 /  
可我说了，没有人认。 //  

我才九岁。 /  
我不知道故事为什么能改，也不知道自己为什么就不能留下。 //  

**我连错都没来得及犯，怎么就先被扔掉了？** //  

**【看向众人；哽住可以停，缓过来再说】**  
后来，我借着别人的名字，终于又走到他面前。 /  
他叫我徒弟，我也答应。 //  

我把自己的事一点一点告诉他，生怕说急了，连站在旁边的机会都没有。 //  

我没想过一定要比谁重要。 /  
我只是想，他能不能也看看我？ //  

**我也在这里。** /  
**我也等了他那么久。** //  

云谦给我起了新名字，阿蒲给我写了新人生。 /  
我以为，总算有人肯给我留个位置。 //  

可云谦需要的，只是一个能帮他救女儿的耗材。 /  
而阿蒲需要的，是最后死掉、让故事圆满的反派。 //  

我还以为他们看见我了。 /  
原来，你们只是用得上我了。 //  

**【看回云笙，先难过，再带一点苦笑】**  
你说，我的人生到此为止了。 /  
可哪一次，有人真正问过我想怎么活？ //  

活着，我要给市场让路。 /  
死了，还得替你们收场。 //  

**我活着不值钱，死了倒有用了？** //  

可我不是几个字。 /  
你们改掉的那些日子，我是一天一天过来的。 //  

**【缓一口气，声音逐渐站稳】**  
后来那些事，是我做的。 /  
我夺了她的身份，也让她尝了不被认得的苦。 //  

你们恨我，我认。 /  
可九岁那年，我还没有做过这些。 //  

**不能因为今天的我变成这样，** /  
**就说当年那个孩子，也不值得被疼。** //  

现在，你们又想要我听话。 / 照着你们写好的结局走。 //
我不愿意。 //  

**云妄，胆大妄为。** /  
**那这一次我就要自己选。** //  

我的命，不能到最后，还只是拿来成全别人。 //  

你们要的大团圆，我给不了。 /  
哪怕最后鱼死网破，这最后一页，我也要自己写。 //  

**【转向风清雁，声音放低】**  
**我是江寒。** /  
**那个爱上了你，想和你有个家的人。** //  

起初，我恨你。 /  
你像另一个没被删掉的我，占着我失去的人生。 //  

我知道动笔的不是你。 /  
可得到这一切的，是你。 //  

后来，我偏偏爱上了你。 /  
那天站在台上，我说原谅你，是真的。 //  

我想，云谦若肯认我，你若肯陪我， /  
我是不是也能有个以后？ //  

我想得太好了。 //  

以前他答应我什么，我都记着。 /  
一直等，一直替他想，是不是还有什么难处。 //  

我甚至想过，也许大人都是这样。 /  
答应的时候是真心，后来忙起来，就顾不上了。 //  

后来看见他对你，我才知道，原来那些事，他是做得到的。 //  

原来不用一直等，不用反复提醒。 /  
原来一个孩子，也可以放心地相信自己的父亲。 //  

我不怪你被他疼爱。 /  
我只是看着你，才知道自己从来没有过什么。 //  

**他不是不会疼孩子。** /  
**他只是不疼我。** //  

我爱你，可我也会难受。 /  
我不能因为喜欢你，就假装自己没有过那些年。 //  

我想和你过一辈子， /  
又忘不掉我娘，忘不掉纪叔。 //  

我想留住你， /  
又恨不得亲手杀了你爹。 //  

你爹一句“滚”，就能喝退那些长老。 /  
可我娘等到死，都没等到他。 //  

**她叫风怜。** /  
别到了最后，只记得云谦死了，却忘了她也死了。 //  

是纪泽苍把我养大，让我重新有了家。 /  
可他也死在云谦手里。 //  

他不肯认我，还杀了那个像父亲一样疼我的人。 //  

风清雁，你想护着你爹，我明白。 /  
他疼过你，你当然舍不得他。 //  

可我娘、纪叔，也真的疼过我。 /  
我不能因为他们已经不在了，就只顾着留下来的人。 //  

你不必替我恨他。 /  
可也别要我替他们原谅。 //  

**【把选择说清，不向云谦退场处喊】**  
如果我说，都算了，我们以后好好过。 /  
那我娘等不到他的那些年，算什么？ //  

那个九岁的孩子呢？ /  
他已经被丢下一次，我还要为了留住你，再把他丢下一次吗？ //  

**我可以爱你。** /  
**可我不能连自己也不要了。** //  

所以，我选择报仇。 //  

为了我娘，也为了纪叔。 /  
云谦必须死。 //  

无上宗，是我引来的。 /  
我就是要看到他死在我前面。 //  

**【停一拍，看着她】**  
我不是没想过，你会有多恨我。 /  
我杀的是仇人，但也是你爹。 //  

我甚至想过，我这辈子，是不是再也还不清你了。 //  

现在，你告诉我，你的爱都是骗我的。 //  

**【停一下，不笑，也不急着反问】**  
原来，你们早就知道自己在做什么。 /  
只有我，还以为终于有人愿意留下。 //  

难受是真的。 /  
可有些事，我也终于不用再替你们找理由了。 //  

我爱过你，这件事不丢人。 /  
我想有个家，也没有错。 //  

我不能因为最后没等到，就把自己的真心也说成笑话。 //  

你恨我害死你爹，我知道。 /  
可为我娘、为纪叔讨这笔账，我不后悔。 //  

我不会拿他们的命，换你一句原谅。 //  

**【稍停，像想起剧本替自己安排好的告别；不要逐句喊成谢幕】**  
剧本连我最后该说什么，都写好了。 //  

要我说，不后悔是假的，对不起是假的， /  
陪你一起、十生十世，也都是假的。 //  

最后再告诉你， /  
恨你是真的，爱你也是真的。 //  

**【看着她，声音慢下来】**  
**可这六句话，我不想照着说了。** //  

你恨我，我不逼你原谅。 /  
我做过的事，也不用几句真假替我遮掩。 //  

但报仇这件事，我不道歉。 /  
更不想先说对不起，再告诉你那是假的。 //  

至于陪你一起，十生十世—— /  
我想过，也认真盼过。 //  

如今走不下去了，也不代表当时的真心是假的。 //  

爱你，恨你，我自己知道。 /  
不必临死前，再照着他们写好的词，向你交代一遍。 //  

**你已经说完你的了。** /  
**剩下的结局，我自己说了才算。** //  

**【面向全场，缓一口气，报自己的名字】**  
**我是风清砚。** /  
**莲心城少祭司，风怜的儿子。** //  

云妄，是他给的。 /  
江寒，是我借的。 //  

风清砚，才是我自己的名字。 //  

**【看向风清雁，接住她刚才的指控】**  
你刚才说，我是小偷。 /  
偷来的人生，终究要还。 //  

那你听清楚。 //  

**“秋透书台笔砚清。”** /  
**风清砚，是我娘风怜给我起的名字。** //  

我有名字，有母亲，也做过莲心城的少祭司。 /  
这些在你出现以前，就已经是我的。 //  

我借过江寒的名字。 /  
可风清砚的人生，我从来没偷过。 //  

倒是你，风清雁。 /  
你的名字，又是从哪里来的？ //  

**先有风清砚，才有风清雁。** //  

他们把我的故事改成了你的，把我的位置给了你。 /  
你站在那里，却要我把人生还回来？ //  

**还给谁？** /  
**把我原本的人生，还给后来顶替我的人？** //  

我说这些，是想把自己的名字说清楚。 /  
不是一定要等你认输。 //  

**【停一下，收回追问的语气】**  
你认不认，风清砚都活过。 /  
这件事，不需要谁再准许了。 //  

**【转向归容，像最后一次交底】**  
大师兄，我一直追着问的事，如今都有答案了。 //  

他早就想起女儿了。 /  
他肯为她想办法，肯为她把这场戏演下去。 //  

他也能疼你这个徒弟，能把人放在心上。 /  
我看见过。 //  

**他不是没有爱人的能力。** /  
**只是那个人，从来不是我。** //  

以前我总想，是不是我再懂事一点，再听话一点，他就肯认我了。 //  

现在不用想了。 /  
我做得再多，也换不来他愿意。 //  

**【慢一点，说给自己听】**  
**他没有爱我，不是因为我不配。** //  

我娘爱过我，纪叔也疼过我。 /  
我不是生来就不值得被人放在心上的。 //  

只是如今，这世上还活着的人里，已经没有爱我的人了。 //  

我终于认了。 //  

我坦白过，等过，也争过。 /  
名字拿回来了，那声阿砚也听见了，可我想要的爱，还是没有。 //  

以前我总觉得，还得再做点什么。 /  
现在我知道，有些事，不是我再努力一点就能换来的。 //  

**我可以想要。** /  
**可得不到，也不用一直为难自己。** //  

我不再等他了，也不再怪自己。 //  

仇已经报了。 /  
那个没等到父亲的孩子，我也不用再逼他等下去了。 //  

**【看柳沐瑶一眼，再看回归容】**  
你和小柳儿，或许还有别的打算。 /  
不必告诉我。 //  

你帮过我，我记着。 /  
可要是下一步还计算着我，那就把我划掉。 //  

最后这一幕，我只想自己走。 //  

**【声音放轻，像说给自己听】**  
最近这段日子，我总像听见娘在叫我。 /  
还有纪叔。 //  

好像我只要回过头，就又有人等我回家了。 //  

该报的仇，我已经报了。 /  
想等的人，我不打算等了。 //  

我不想再为谁留下，也不打算再追着谁讨一份爱。 //  

**【重新看向风清雁，平静地说清最后的选择】**  
风清雁，你们想让两颗莲心珠对撞，一起毁掉。 /  
然后，你就自由了。 //  

可镇渊卷轴，只能暂时把珠子取出来。 //  

**现在属于我的这一颗，我会亲手毁掉。** //  

当初换给你的那颗废珠，会留在你身上。 /  
它还会烧，还会疼。 //  

这是我留下的伤害，我认。 /  
你不必因此理解我，更不必原谅我。 //  

我以前想，得不到你的爱，至少也要让你恨我。 /  
总觉得只要你还记着，我就不算白来一场。 //  

可如今，我不想再等着你的爱或恨，证明自己活过了。 //  

**我来过。** /  
**我自己记得。** //  

**【看向手中道具，暂不击掌】**  
阿蒲告诉我，毁掉莲心珠，要有极致的爱，也要有极致的恨。 //  

我曾经有多想和你走下去， /  
现在就有多恨你让我信了这一切。 //  

你可以说自己的爱是假的。 /  
可你做不到连我的真心，也一起抹掉。 //  

**曾经我爱你的那颗心，是真的。** //  

**【抬眼，看着她，说稳】**  
那就用它，和我此刻的恨， /  
结束这一切。 //  

风清雁，我不等你回头了。 /  
以后你怎么看我，我也不再追问。 //  

**【把目光从她身上收回来，声音放轻】**  
我一直盼着，有个人能看见风清砚。 /  
今天，我自己看见了。 //  

他想被父亲疼一下，不算贪心。 /  
答应他的事没有做到，他难过，也不算不懂事。 //  

**那个孩子没有做错什么。** /  
**我不该跟着别人，一起怪他。** //  

我不是不要他了。 /  
是终于肯让他不用再等，不用再证明自己值得。 //  

阿砚，你已经做得够多了。 //  

娘，纪叔。 /  
我想你们了。 //  

**【用力击掌，触发碎珠；站稳，接住特效与音乐。此处不闭幕】**  
**【特效落定，面向全场，轻轻一笑】**  
话本里的主角退场，总要留几句台词。 //  

这一回，我也给自己备了一首诗。 //  

**【稍停，开始诵诗，四字、三字分节】**  
一笔删名 / 十载寒，  
借来名姓 / 立人间。 //  

明月高悬 / 偏负我，  
换得亲缘 / 未得怜。 //  

曾书十世 / 求相守，  
碎珠留恨 / 伴君眠。 //  

**此去不求 / 苍天恕，**  
**我以我血 / 定终篇。** //  

**【末字落下，抬头看全场；不再击掌】**  
**这是我——莲心城、少祭司、风清砚，写给自己的结局。** //  

**一份鱼死网破的胜利。** //  

**【鞠躬，按排练闭幕、退场；不再追加台词】**
