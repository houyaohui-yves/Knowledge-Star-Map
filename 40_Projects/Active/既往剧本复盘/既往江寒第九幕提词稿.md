# 江寒 · 第九幕提词稿

> `/` 短停；`//` 长停、换气或转情绪。加粗处重读；【】内提示不读出声。段落编号不朗读，A1／B1／C1 对应编排表 A01／B01／C01，以此类推。

> C12 的条件接词只读符合现场回应的一句。若现场已判定死亡或取珠成功，按实际结果接戏，不继续硬念预设。

## C1｜云妄：今天说自己的话

**【云笙请上台后，走到指定位置，看向她】**  
**我是云妄。** /云谦给了我这个名字，阿蒲把我写成了最大的反派。 //  
这一天，终于来了。 //  

**【拿起输出大卡，扬一扬手】**  
你们连我的告别都写好了。 /要我说相守是假的，再按你们的意思交代爱恨。 //  
可曾经想陪她走下去，不是假的。 /我自己的爱恨，也不需要别人替我写。 //  
**今天，我想说些自己的话。** //  

## C2｜反派之前，先是个孩子

江寒的名字，我借来的。云妄的人生，别人写的。 /  
可在这些名字以前，我只是一个想回家的孩子。 //  
后来，我夺了她的身份，让她尝了不被认得的苦。 /你们恨我，我认。 //  
**可被丢掉的那一年，我才九岁，还没有做过这些。** /  
你们可以怪今天的我，可当年那个孩子，究竟做错了什么？ //  

## C3｜生死都只看好不好用

云谦给我名字，阿蒲给我人生，我以为终于有了位置。 /  
可一个要拿我救女儿，一个要用我的死成全大团圆。 //  
**我以为他们终于看见我了，原来只是用得上我了。** //  

**【看向云笙，带一点苦笑】**  
你说，我的人生到此为止了。 /可哪一次，你们问过我想怎么活？ //  
活着，要我给市场让步。 /快死了，还要我给结局铺路。 //  
**原来在你们眼里，我是死是活，只在于好不好用。** //  

## C4｜江寒：院墙外的我

**【转向风清雁】**  
**我是江寒。** /那个爱上你，想和你有个家的人。 //  
风清雁，那十年，我经常趴在院墙外的树上，看你和云谦相处。 //  
他会像个泼皮无赖一样，想办法逗你开心。 /我就这么一遍又一遍地看着。 //  
**原来他做父亲的时候，是这个样子。** /我真的很羡慕你。 //  

## C5｜我真的想留下

你说接受我，说你爹也是我爹。 /这句话，我当真了。 //  
**我那时候想，要是以后能这样三个人一起过下去，该多好。** //  

## C6｜我也有舍不得的人

可你爹一句“滚”，就能喝退那些长老。 /我娘却等到死，都没等到他。 //  
她叫风怜。 /别只记得云谦死了，却忘了她也不在了。 //  
还有纪叔，是他把我养大，像父亲一样疼我。 //  
你舍不得你爹，我明白。 /可我也有放在心里的人。 //  
如果我说，都算了，我们以后好好过， /那个九岁的孩子怎么办？ //  
**他已经被丢下一次，我还要为了留住你，再把他丢下一次吗？** //  

## C7｜报仇与亏欠

无上宗，是我引来的。 /我就是要云谦死在我前面。 //  
可我也知道，他是我的仇人，也是你爹。 //  

**【看着她，停一拍】**  
所以我曾经想，对你的亏欠， /是不是一辈子都还不清了？ //  

## C8｜骗局不能抹掉我的真心

云谦早就想起你了，苏醒后却还装得若无其事。 /现在，你又告诉我，你的爱都是骗我的。 //  

**【停一下，不急着笑】**  
原来你们一直知道自己在做什么。 /只有我，还以为终于有人肯留下我。 //  
云谦算计来算计去，反害了自己的命。 //  
**难受是真的，可我终于不用再替你们找理由了。** //  
你可以说你骗了我。 /可你不能说，我对你也没有真心。 //  

## C9｜风清砚：谁才是小偷

**【面向全场】**  
**我是风清砚，莲心城少祭司，风怜的儿子。** //  

**【看向风清雁】**  
你说我是小偷，说偷来的人生终究要还。 /可这个名字，是我娘给的。 //  
我借过江寒的名字，但风清砚的人生，我从来没偷过。 /先有风清砚，才有被改出来的风清雁。 //  
**他们把我的人生给了你，你却要我归还。** /**还给谁？** //  

**【停一下，收回追问的语气】**  
我只是想把名字说清楚，不用你认输。 /你认不认，风清砚都活过。 //  

## C10｜不再拿他的偏心怪自己

**【转向归容】**  
大师兄，我坦白过，等过，也争过。 /  
名字拿回来了，那声阿砚也听见了，可我想要的爱，还是没有。 //  
可娘爱过我，纪叔也疼过我。 /他不肯爱我，不是因为我不值得。 //  
我不该一直拿他的偏心，来怪自己。 //  
我还是不知道为什么云谦不肯爱我， /但我已经不需要知道了。 //  

## C11｜这最后一幕，我自己走

**【仍看着归容，声音放轻】**  
大师兄，我不想再等了。 /这些年，我已经尽力了。 //  
该报的仇，我已经报了。 /最近，我总像听见娘在叫我，还有纪叔。 //  

**【目光慢慢移开】**  
好像只要回过头，就又有人等我回家了。 //  

**【看柳沐瑶一眼，再看回归容】**  
大师兄，你和小柳儿，或许还有别的打算。 /不用告诉我。 //  
你帮过我，我记着。 /但如果下一步还算着我，就把我划掉吧。 //  

**【转向云笙】**  
我的命，不能到最后都只用来成全别人。 /这最后一页，要由我自己写。 //  

## C12｜毁珠前：把机会交给你，再收回来

**【看向风清雁】**  
你们想用镇渊卷轴取出珠子，让两颗莲心珠对撞，一起毁掉。 /  
可镇渊只能暂时取珠，而我只会毁掉现在属于我的这一颗。 //  

**【毁珠前，直视风清雁】**  
我今天，一定会死在这里。 //  
风清雁，我给你一个机会。 /**站起来，亲手杀了我！** //  

**【停下来，等她回应；若她尚未回应，再说下一句】**  
站起来啊！ //  
别说我不给你机会。 /等我自杀，你体内那颗莲心珠，就再也取不出来了。 //  

**【等她完成回应；若她行动，先接现场演绎，不抢着往下念】**  

**【轻笑；下面两句按她的实际回应只选一句】**  
**【她明确要杀江寒】** 原来你真想杀我。 / 在让我失望这件事上，你还真是从不让我失望。 //  
**【她拒绝、犹豫，或只是想救人】** 到了这时候，我们想要的，还是不一样。 //  

**【以下为共同接词】**  
骗你的，风清雁。 /我没有打算把自己的结局，交给你选。 //  
我要动手了。 //  

**【声音放轻】**  
明天太阳升起，就不会再有人叫你笨猪了。 /也不会再有人，像我这样惦记你的名字。 //  
云谦想让你自由，能放心去拥抱想亲近的人。 /那你便带着我那颗废珠走吧。 //  
它不会伤害你身边的人，**只会随着你的每一次心跳，灼烧着你。** //  
**这是我对你欺骗我感情的报复。** //  

**【用力击掌，触发约定的碎珠信号；不闭幕，接 C13】**  

## C13｜碎珠后：爱、恨与诅咒

**【击掌碎珠后，等碎珠信号落定，再开口】**  
这颗毁了我一生的珠子，终于碎了。 //  
摧毁莲心珠，需要极致的爱，也需要极致的恨。 //  

**【看向风清雁】**  
现在，我相信你也足够恨我了。 /**那你猜猜，那份极致的爱，又是哪来的？** //  

**【不等她回答；看着风清雁】**  
风清雁，我诅咒你。 //  
**诅咒你长命百岁，福寿绵长。** /**诅咒你亲朋断尽，无依无靠。** //  
**你此生再无一人，像我这般真心爱你。** //  

**【停住，不再追问她的反应；收回目光，接 C14】**  

## C14｜本名、退场诗与结局

**【诅咒说完，停一下；收回目光，转向全场】**  
你们听着，我叫风清砚，砚台的砚。 //  
**我的一生，痛过、恨过、爱过，我不后悔。** //  
如果问，我这一生有什么意义—— //  

**【稍停，开始诵诗，四字、三字分节】**  
一笔删名 / 十载寒，借来名姓 / 立人间。 //  
明月高悬 / 偏负我，换得亲缘 / 未得怜。 //  
曾书十世 / 求相守，碎珠留恨 / 伴君眠。 //  
**此去不求 / 苍天恕，****我以我血 / 定终篇。** //  

**【“我以我血定终篇”念完，抬头看向全场】**  
**这是我，莲心城少祭司风清砚，写给自己的结局。** //  

**【鞠躬，按现场约定闭幕、退场；不再追加台词】**
