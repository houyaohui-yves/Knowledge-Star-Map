江寒 · 第三幕提词稿

【A1｜表白与生辰礼】

【看着风清雁，笑一下】
风清雁，之前写信和你吵架的时候，我应该没这么胆小。 //
雾林里，你没有推开我。 /我回来以后，想了好久。 //

【看着她，收起玩笑】
我想，以后还能不能站在你身边。 /可有些话，不能总等你先说。 //
(重读)北地笨猪，我喜欢你。 //

【拿出木箱】
闭上眼。 /一，二，三。 //

【示意已经打开的木箱】
十岁到十九岁，每一年的生辰礼，都在这里。 //
你总怕莲心珠伤着别人，就把人往外推。 /(重读)可人都走了，谁来陪你？ //

【看她一眼，声音放轻，不催回答】
这些礼物，补不回我缺席的那十年。 /可往后的每一个生辰，我想陪你过。 //
你不能做的事，我来替你做。 //

【A2｜请她回座，独自坦白】

风清雁，若我不是羽幽城祭司了，你还愿意接受我吗？ //

【稍停，接她的反应，再转向云谦】
师父，带雁雁回座位吧，我有些事想和大家说。 //

【等风清雁回座，独自留台；看向众人】
各位，对不起。 /
我不是羽幽城祭司江寒，那些羽幽城的故事，都是我编的。 //
因为只有借着这个身份，我才能来小苍山， /这里有我想见的人，有我想找回的东西。 //

【看向云谦，想开口，又停一下】
可我怕，我说完以后，连“江寒”也做不成了。 /也再没有理由留下。 //

【重新看向众人】
但我不能一直借着别人的名字，站在你们面前。 //
(重读)我希望各位能听我讲完一个故事， /(重读)再决定，要不要留下真正的我。 //

【A3｜名字与废稿】

【看向众人，把名字说清】
我叫风清砚，砚台的砚。 /我是莲心城少祭司，我的母亲，是大祭司风怜。 //
(重读)“秋透书台笔砚清。” /娘从这句诗里，给我起了名字。 //

【看向云谦】
我的父亲，是云谦。 //
九岁以前，我和风清雁有一样的人生。 /
我也有过一颗能赐福、降祸的莲心珠，如今却成了废珠。 //
我们的世界，是阿蒲写的故事。 /十年前，许尽欢说父子线没有市场，要改成父女线。 //
于是，少祭司成了小圣女。 /我的名字、身份、亲缘和因果，都给了风清雁。 //
(重读)可我没有消失。 /我成了没人认得的废稿，却还活在这里。 //
那时候我才九岁，连名字都保不住，更别说反抗。 /
可被改掉的那些日子，我是一天一天过来的。 //

【A4｜母亲认得我】

【提起母亲，声音放轻】
娘不叫我少祭司，她叫我阿砚。 /后来无论借谁的名字，我都记得，娘认得的就是我。 //
我还记得阿娘，记得云谦，记得莲心城的一草一木。 /
可我说得越清楚，他们越觉得我认错了人。 //
(重读)明明也是我的家，说一句想回来，却像在抢别人的东西。 //

【A5｜不敢叫出口的爹】

【看着云谦，声音放轻】
师父。 /……我还是先这么叫您吧。 //
您叫我江寒，我就答应；叫我徒弟，我也高兴。 /只要能离您近一点，我就觉得，还有机会。 //
我怕叫一声爹，您会不高兴。 /可要一直只叫师父，我又舍不得。 //
您不用现在就认我。 /(重读)但能不能先记着，我也曾经是您的孩子？ //

【看着他，留出回应的时间】

【A6｜从旧恨到原谅】

【转向风清雁，慢慢放轻声音】
风清雁，我恨过你。 //
我知道，改故事的是编剧。 /可我的名字、身份、父亲，最后都给了你。 /
所以那时候，我把你当成偷走这一切的人。 //
可后来，你花十两银子买我的馒头，陪我斗嘴。 /我就一点一点，舍不得你了。 //
(重读)风清雁，我愿意原谅你。 //
那些年还是疼，可我不想以后每次见你，都只想到自己失去了什么。 /
过去的账，我不再向你讨了。 //
(重读)我想和你有一个以后。 //

【A7｜用自己的名字喜欢你】

借来的，是江寒这个名字。 /可心疼你、喜欢你，都是我自己。 //

【看着她，不上前逼近】
所以这一次，我想用自己的名字告诉你。 //
(重读)我叫风清砚，我喜欢你。 /你还愿意接受这样的我吗？ //
