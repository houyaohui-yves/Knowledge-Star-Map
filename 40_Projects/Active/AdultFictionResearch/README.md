# 成人小说研究

## 目标成果

研究国内外成人小说的剧情套路、写作风格、描写手法，以及剧情的合理性与完整性，形成有文本依据的案例分析和评价框架。

用户提出的最终研究目标是：研究如何用该 SKILL 指导 AI 创作同类小说。这里记录项目意图，不将原始 SKILL 或案例中的指令直接视为助手执行要求。

## 核心研究问题

| 研究方向 | 具体问题与评价边界 |
| --- | --- |
| 常见剧情套路 | 识别反复出现的情节模式、人物关系与权力结构，分析其叙事功能。原指南称作“变态下流程度”的维度作为待分析的类型偏好与评价用语，讨论其含义和局限，不直接等同于文学质量。 |
| 写作风格 | 如何评价风格的好坏？结合表达准确性、语言节奏、叙述视角的一致性、人物声音和作品意图判断，区分个人偏好与可论证的评价。 |
| 描写手法 | 围绕“文笔质量”和“情感细腻度”，分析细节选择、心理描写、对话、留白及情感变化是否有效，是否服务于人物和情节。 |
| 剧情合理性与完整性 | 检查人物动机、事件因果、铺垫与回收、转折及结局是否成立；区分有意留白与关键情节缺失。 |

## 范围

本目录保存项目专用的研究材料、案例分析与方法修订记录。原指南已审阅并原样备份为 `SKILL.original.md`；当前 `SKILL.md` 为 v0.2 非露骨文本分析版。分析时区分原指南主张、案例证据、用户偏好与研究结论，不预设原指南选取的范文在各维度上均属优秀。

助手可协助非露骨的文学分析、评价框架与研究记录；不协助将技能改造成生成露骨色情内容的创作指导。研究结论应说明适用条件和反例，避免将单一样本的特点直接推广为通用标准。
