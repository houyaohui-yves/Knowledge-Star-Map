# 价差型资产考核标准（讨论稿）

**价差型资产应以可验证的每股价值增长或价值释放为依据，买入价格还须补偿等待与失败风险。** 林奇六类均可能成为候选，但不能共用一套增长、估值和退出参数。这里提出“共同准入条件＋A～F 专项考核＋按原论点退出”的个人适配草案。

> 草案日期：2026-11-04｜尚未采用为正式纪律，未用于重新决定现有持仓去留。当前已采用规则见 [[个人投资原则与交易纪律]]。分类解释见 [[公司股票分类：林奇六类公司与分析方法]]；以下门槛设计、研究优先级和执行流程为助手建议，不是林奇原书的逐条买卖规则。

## 1. 哪些公司可以作为价差型资产

价差的依据有两条：**公司未来每股价值增加**，或**已有价值的折价有理由收窄／资产得到兑现**。它们可以同时存在，也可以与分红重叠。估值提升不是必需条件；只靠“以后有人愿意出更高倍数”不足以形成研究结论。

| 主类型 | 价差从哪里来 | 拟议研究优先级与边界 |
| --- | --- | --- |
| A 成熟低增长型 | 已有盈利／资产被低估，经营确认、资本配置改善等使折价收窄 | 特定低估机会；不把所有成熟低 PE 公司列入。若没有可论证的折价与实现路径，优先按现金流标准研究 |
| B 稳健成长型 | 每股盈利和现金长期增加，合理买入时不必依赖 PE 上升 | 优先研究经营基础清楚、增长和现金能验证的公司；不因“白马”免除价格检查 |
| C 快速增长／扩张型 | 已验证的赚钱模式继续扩张，增加每股价值 | 选择性研究；当前先聚焦盈利模式已验证者，尚需证明能赚钱的早期项目暂留观察 |
| D 周期驱动型 | 供需改善使低谷盈利恢复，或当前价格低于可支持的跨周期价值 | 重点学习方向，但优先现金和成本竞争力能承受低谷者；不保证恢复旧高点 |
| E 困境修复型 | 可解释的经营／财务障碍被解决，正常盈利和股东价值恢复 | 当前先限于经营受挫但资金链可承受的情况；生存依赖未落实救助、重组或大额融资者暂不作为买入对象 |
| F 资产价值型 | 可核验资产的折价缩小，通过出售、分拆、分配等实现 | 有专项核验能力再考虑；个人准入建议要求可信的价值释放路径，账面便宜而长期无法触达股东者只观察 |

优先级依据用户希望低频维护、先深研再耐心持有的偏好，不是类型风险排名。D/E 是用户原有兴趣，建议加入 B 作为比较；没有要求配置齐全，也没有选定比例。

A～F 与现金流／价差两个角色交叉使用。一个 B 类公司可以同时分红与成长；一项仓位只指定一个主角色。行业整体低谷的 D 与公司自身障碍的 E 可以重叠，分别核验，不能因全行业好转就认为该公司一定得救。纯估值修复可发生于任何类型，不另造第七类。

## 2. 所有价差候选共同通过六项考核

每项记录“通过／不通过／待核＋证据与日期＋反证”。**不能用总分抵消生存、治理或证据可信度的重大缺陷。** 资料不足可以留观察池，但不能直接升级买入；现有持仓资料不全先复核，不能据此直接断言应卖。

| 考核 | 买入前必须给出的结果 | 暂不买入的情形 |
| --- | --- | --- |
| ① 解释价差来源 | 写明主类型、主机制、市场主要担忧，以及哪些可核事实支持自己的不同判断 | 只有跌幅大、过去高价、热门行业或“总会涨回来” |
| ② 证明能等到兑现 | 预测到主要观察节点及延迟情景的现金收支、必要投资、债务到期、已落实融资与稀释 | 生存依赖尚未落实的融资、救助或资产高价处置；公司活下来但旧股东权益可能严重受损 |
| ③ 建立正常价值区间 | 按本类方法列基准、延迟／不利、失败情景；明确普通股可得价值、股数及关键假设 | 只使用最好一年利润、行业最高倍数或未扣负债的账面资产 |
| ④ 解释当前价格为何值得承担风险 | 从现价计算同一期限内的股价与股息总回报，计费税；与实际可选现金流资产或等待现金比较 | 只有乐观情景有吸引力，或需要增长和估值同时达到激进假设才能成立 |
| ⑤ 设定可检查的进展与期限 | 写出指标、当前值、期待方向／范围、下个披露或事件节点、延迟如何处理 | 只能等待股价，无法说明什么经营／资产事实证明论点在兑现或失败 |
| ⑥ 将失败纳入组合 | 估计失败时每股价值与损失贡献，核关联行业／因素和流动性，再给计划规模 | 想赚多少就买多少；只看单股，不看多个持仓同时受冲击 |

不是证明“市场一定错了”才能开始，而是要解释自己的假设和证据，并承认估值区间可能错。对市场担忧不能用“情绪不好”一笔带过；同样，不把管理层计划、券商预测和已实现数据视为相同强度证据。

## 3. 六类分别怎样买、怎样跟踪、怎样退出

2026-11-04：A～E 的完整研究已独立成学习笔记；本节只保留个人适配摘要。以下新增条件与研究优先级仍待评审，F 保留初步考核，尚无独立研究。

### A：买可解释的低估，避免买入持续衰退

完整研究见 [[公司股票分类研究（一）：A类成熟低增长型]]。核现有业务、必要投入后的现金及折价原因，说明价值怎样到达股东；历史 PE 均值不保证恢复。

**买入与退出：** 正常价值可维持、折价可解释且现价回报合适才进入买入研究；主业衰退、价值下修或折价消失时重核去留。改为收息持有须重新通过现金流考核，不能临时换标签。

### B：买每股价值的持续增长，避免为优质付出过高价格

2026-11-04 按用户确定的分工，完整研究转入 [[公司股票分类研究（二）：B类稳健成长型]]；这里保留适配摘要，后续细节仅在知识笔记维护。

**买入与持有：** 验证优势、增长所需投入、现金及每股归属，以合理期末估值核现价回报；按关键业务指标持续验证。**退出：** 增长机制或资本配置使原论点失效，或现价透支可支持的增长时评估减仓／退出；单季偏离、上涨或达到旧目标价先复核，不机械卖出。以上仍是待评审建议。

### C：买已验证且可复制的增长，重点防增长失速和稀释

完整研究见 [[公司股票分类研究（三）：C类快速增长与扩张型]]。核已验证且可复制的单位盈利、可实现空间、扩张资金与融资后每股价值；负现金流需拆原因，不能一票判坏或无条件豁免。

**买入与退出：** 同时检验增长、利润率和估值下降；模型被证伪、新投入持续无效或融资稀释破坏原回报时评估退出。健康降速可以转 B 后重估，不能只按增速或 PEG 交易。

### D：买有生存能力的周期机会，避免拿峰值利润估值

完整研究见 [[公司股票分类研究（四）：D类周期驱动型]]。核需求、供给、库存、单位价差与低谷资金，用正常化盈利及长期趋势变化建模，不能拿峰值利润算便宜。

**买入与退出：** 首次实践仍建议优先等待可核的供需／经营改善，并检查价格已反映多少复苏；提前布局需要更强的现金与行业证据。复苏已较充分计价、长期盈利下修或低谷超出资源承受力时重审，不必等报表利润见顶。

### E：先证实能活下来，再研究修复给旧股东留下多少

完整研究见 [[公司股票分类研究（五）：E类困境修复型]]。核困境原因、已实施措施、等待及延迟资金、融资后原股东权益，不能把账面扭亏当修复完成。

**买入与退出：** 当前仍建议优先资金链尚稳的经营性修复，暂避依赖未落实救助或大额融资的生存赌注。核心措施失败、资金路径破裂或稀释破坏原回报时减险；修复完成且价格已反映正常价值时重新论证持有，不能无限延期。

### F：买普通股东可获得的资产价值，避免账面数字陷阱

**买入证据：** 资产真实、权属清楚，估值依据可核；扣负债、税费、少数股东、处置成本及等待期消耗后，普通股价值仍有吸引力。核查是否抵押、可否出售、谁有权决定、所得资金如何使用。个人准入建议要求有可信的释放路径；这比“资产价值型”的分类定义更严格。

**跟踪：** 处置或分拆进展、交易对手资金能力、审批条件、实际成交价、现金到账及分配用途。无法取得相关资产资料、只凭低 PB 或现金大于市值，不认定通过。

**退出：** 资产兑现后折价已消失；处置取消、关键审批失败、隐性负债或资产减值使价值下修；资金长期被低效占用且失去可信释放路径。出售资产所得现金与售出资产本身不能重复计入价值，普通股股东可得金额也不能等同于公司账面总资产。

资产估值需要区别持续经营和处置场景，急售可能有折价；公司价值还须扣除非普通股权益。[Damodaran：估值导论](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/background/valintro.htm)支持这些区别；个人释放路径条件由本稿提出。

## 4. 如何核定价格、回报与仓位

不再为六类统一设 8%～12% 门槛，也不假定“价差型”必须收益更高。做法是先按证据估算现实回报，再结合不确定性与可靠替代机会设定本股的要求；承担更多失败风险却没有足够补偿，可以放弃，不靠拔高预测解决。

| 必填项目 | 记录要求 |
| --- | --- |
| 估值日期与现价 | 同一时点；说明价格和财务数据是否有时间差 |
| 价值依据 | 正常化盈利／现金、资产可得金额、期末合理估值及股数；区分本身增长与折价收窄 |
| 回报情景 | 基准、延迟／不利、失败分别列等待期、期末股价、期间股息及费税。无可靠概率时不编造加权“期望收益” |
| 买入价格上限 | 在可支持的情景下，达到为本股设定的回报要求，并留出估值误差余地；明确是条件价格，不是保证能等到或唯一内在价值 |
| 不依赖修复的情景 | 假设估值不上升、事件延迟或周期趋势改变时会怎样；纯折价投资可以依赖修复，但必须承认失败时未必有足够分红或增长补偿 |
| 仓位与共同风险 | 先列失败损失，再解释计划规模；不因 D／E 标签机械给某个跌幅系数 |

**同样的上涨空间，等待时间会改变吸引力。** 自拟例子：20 元买入，最终 28 元卖出，无分红、不计费税，涨幅为 40%；三年兑现的复合年化为 `(28/20)^(1/3)-1≈11.87%`，五年兑现则约 6.96%。若失败后只值 12 元，损失为 40%。28 元与 12 元均为假设，不是任何实际公司的目标或下限。

这不是“有 40% 空间就买”的规则：还须比较三种情况的证据、等待现金需求及可靠替代机会。分红存在时按具体时间核现金流收益；不得在股价已含留存利润增长的模型里额外重复加入同一增长。

用于控制规模的简化关系是：**本股的组合损失贡献≈本股权重×本股失败情景损失比例。** 例如权重 5%、失败损失 40%，对应约 2% 的组合损失贡献，假定同一基数且其余资产不变。情景可能被突破、多个持仓可能一起失败，所以它不是损失保证，也不是自动采用 5% 仓位。原全组合 10%／单股 5% 损失预算的基数与执行仍待讨论。

## 5. 跟踪与清退的共同流程

买入前为主要论点选少量真正关键的观察指标，每项写“基准值—预计变化—披露／事件节点—失效证据”。建议随定期报告复核，重大事项及时重审；不是强制每季度交易，也不设置统一“两季不增长就卖出”。正式频率仍待采用。

| 状态 | 拟议动作 |
| --- | --- |
| 逻辑在兑现，价格没有透支，仓位合适 | 继续持有；加仓需从新价格重新过考核，不能只因浮亏或有闲钱 |
| 到节点未达预期，但仍有解释与可核证据 | 暂停新增，核原因、延迟现金成本和新估值；延长期限需写新证据，保存原承诺 |
| 论点兑现且剩余回报不足，或被明显更合适的机会替代 | 考虑减仓／退出，比较税费；达到旧目标价只触发重估，不自动要求卖光 |
| 关键论点被证伪、生存风险不可接受或治理可信度破坏 | 启动减险／退出，不等回本或所有细节最终确认；不以改类名保留失效逻辑 |
| 仅价格下跌，客观证据与现价回报仍成立 | 复核后可持有，不机械止损；但价格异动也可能提示漏掉信息，应查原因 |
| 经营类型自然迁移，或原角色完成 | 按新类型重新分析；原判断与结果保留，不自动视作失败或自动继续持有 |

研究清退、用户决定及实际成交分开记录。即使已经判断应退出，实际交易还受停牌、流动性等约束，计划卖出不能当成损失已锁定。

## 6. 每家公司最终应交付什么

未来沿现有三份公司／模型／持仓文档维护，在研究页给出下列简短结论，并链接证据，不另造一份重复的持仓表：

1. **类型与价差论点：** A～F 主类、重叠类；主要靠什么增长或修复赚钱？
2. **买入结论：** 通过／观察／排除；六项共同条件及本类专项条件的缺口是什么？
3. **价格与期限：** 现价、条件买入区间、基准与失败情景、预计检查节点。
4. **持有与退出：** 哪些事实支持继续持有，哪些触发复核，哪些使论点失效？
5. **规模与采用状态：** 计划仓位与共同风险、助手建议、用户决定、实际执行分别记录。

当前待讨论：是否采用上述研究优先级及 E/F 更严格的准入边界；是否接受六项共同考核；再用一家公司试填，检验指标是否可获取、买卖条件是否清楚。尚未选定价差部分比例、每类收益率下限、固定折价或统一止盈止损数值。
