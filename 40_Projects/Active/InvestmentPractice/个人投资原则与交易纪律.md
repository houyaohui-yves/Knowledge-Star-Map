# 个人投资原则与交易纪律

**我的投资方式是：买入前严格研究，持有后持续检验；以可持续分红和复投为核心，以有证据的价值修复机会为补充。** 我愿意承担股票波动，以长期资产增长和投资能力积累为目的。

本页是个人投资决策的统一参考。买入、加仓、继续持有、减仓或退出前，先查本页，再查公司研究与当前账户。实际决定、成交与结果记录在对应持仓／决策文件，不在这里记流水。

> 版本：v4｜股息归属口径纠正：2026-11-05；其他共识沿用 11-04｜第 1～3 节为当前原则与约定；第 4.2 节现金流资产标准经讨论后获用户认可。第 4.1、4.3、4.4 节的完整执行条款仍为待评审草案，第 5 节列出未定规则。认可标准不代表策略已验证、现有持仓已通过考核或已产生交易指令。

## 1. 我的投资理念

> 更新：2026-11-04｜在理念或承受条件变化时复核。

- **审慎落实在研究中。** 理解业务如何赚钱、护城河能否维持、财务与治理是否健康，并评估买入价格、预期回报和失败损失；不因题材、下跌或高股息就买入。
- **耐心以证据为基础。** 投资逻辑和从当前价格出发的回报仍成立时，愿意承受账面波动。价格下跌本身不构成卖出理由；降低成本也不单独构成加仓理由。
- **持有期间继续检验。** 研究不能证明不存在重大风险。新证据推翻原判断、经营出现实质变化、估值使未来回报不足或仓位过度集中时重新评估，不必等到重大变故才复核。复核不等于交易。
- **以持续回报积累财富。** 现金流资产为主，分红复投；价差资产为辅，不把每年成功抓住反转机会作为组合成立的必要条件。复投仍要比较价格与风险，不机械买回原股。
- **低频决策，允许等待。** 追求长期资产增长并训练研究能力；现金较多只说明资金可用，不能证明存在好机会。无法解释收益来源或关键证据不足时，先观察。

本页反映当前意愿，不据此推断已经具备成熟选股能力或经过实盘压力检验。用户自述 1999 年生、在 2026 年为 27 岁；年龄不能代替具体账户的资金期限与损失承受分析。

## 2. 资金边界、目标与风险约定

> 最近对齐：2026-11-04｜资金用途、目标或承受条件变化时复核。

| 项目 | 当前约定 | 使用边界 |
| --- | --- | --- |
| 资金范围 | 纳入本次证券投资账户的全部资产与现金；账户外生活储备不纳入 | 最新金额及有无负债查 [[投资组合长期跟踪（测试版）]] |
| 资金期限 | 整个组合至少 3～5 年不动用，亦作为探索方法的试验周期 | 不自动变成到期清仓，也不擅自延长评价期直到盈利 |
| 总回报目标 | 长期复合年化争取 5%～8%，计入分红复投 | 属目标，须由经营、价格、配置及税费检验；不承诺每年或期末最低收益 |
| 组合股息目标 | 全账户股息率 3.5%，分母含现金与价差持仓 | 采用下方利润归属年度口径，不等同于实际税后到账率 |
| 现金流个股买入门槛 | 普通现金股息率至少 3.5%，且派息有可持续依据 | 个人准入标准；按公司风险与增长可能要求更高，不直接作为持有后的自动卖出线 |
| 现金流部分研究标准 | 按市值加权的平均股息率约 5% | 用户认为较可行，仍需验证持续性与分散配置；不要求每股都达到 5% |
| 波动态度 | 投资逻辑与预期回报成立时，愿意耐心承受较大账面波动 | 不把波动自动视为永久损失，也不假定所有下跌都会恢复 |
| 历史损失预算 | 全组合期末损失希望不超过 10%；单股判断错误损失预算为组合 5%，含在整体内 | 保留原约定；如何与长期持有原则衔接、基数与触发措施尚待明确，非自动止损线或保本承诺 |
| 投资工具 | 当前渠道为 A 股、境内相关基金及部分港股；保留机会现金 | 本组合不考虑以约 2% 以下预期收益为目的的低收益债基等防守配置；期货、比特币等用户明确排除。此为个人边界，不是对所有工具的通用评价 |
| 生活储备与追加 | 账户外已有独立生活储备；潜在追加资金未到账前不纳入 | 不把未来可追加资金当作现有仓位的风险缓冲或投资收益 |

### 股息如何衡量

**2026-11-05 用户明确：研究股息率按财报／分红公告标明的利润归属年度统计，不按实际支付年份。** 此前助手将“年度分红”细化为“按支付日归年”，不符合用户本意，本版本予以纠正；实际到账记录仍按到账日期维护。

- 上年度股息率＝归属于上一财务年度的全年每股普通现金分红合计÷当前股价。包括当年各次中期／季度分红和次年支付的该年度末期分红；公告若给全年合计，不再重复加已包含的中期金额。
- 本年度估算股息率＝预计归属于本财务年度的全年每股普通现金分红合计÷当前股价。已公告部分、尚未公告的估算及依据分别列示；只有中期等部分金额时，标“已公告部分，全年待定”，不冒称完整年度股息率，也不直接乘二／乘四。
- 组合配置股息率＝Σ（当前持仓数量×同一归属年度每股普通现金分红）÷同日账户净资产。采用一致的年度与估算状态，不拼接不同归属年的分红凑目标。

以公告明确的所属期间为准，不能凭公告日、股东会日、登记日或支付日推断归属。拟议、已批准、已实施分别注明；年度末期尚待批准时，整年总数应标为方案口径，不称已落实。特别分红单列，未明确归属的项目单独待核，不擅自归入正常年度。跨币种先统一到所研究证券的币种，中国移动 A 股采用各期实施公告的人民币每股金额。

上述股息率主展示税前值，用于当前价格的静态比较，不等于个人当年到账、未来保证或新买入还能领取的股息。个人税后收息和现金流水按实际到账日期另核，不能因归属年度改变而移动历史现金记录；利息另列，基金不重复加计底层分红。分红复投已计入总财富，不再额外加一次“复利收益”。

买入判断并列上年度全年与本年度估算／已知部分，标明归属年度、方案阶段、报价日期和估算可信度，不挑较高的一年过线。未来现金流折现仍使用预计实际支付时点，不能因统计归属改变而把现金流提前一年。

## 3. 候选池与资金配置原则

> 更新：2026-11-04｜经营类型、回报来源或配置选择改变时复核；具体比例尚未采用。

### 先分类，再判断收益来源

研究每家公司先写 **A～F 主类型＋依据**，再列重叠类型、期望收益来源及合理性。编号用于检索，不是风险评级；资料不足可以暂定。详细方法见 [[公司股票分类：林奇六类公司与分析方法]]。

| 编号 | 公司主类型 | 初步候选方向与必须验证的重点 |
| --- | --- | --- |
| A | 成熟低增长型 | 重点研究现金回报；验证必要投入、派息覆盖、债务和衰退风险，成熟不等于稳定高息 |
| B | 稳健成长型 | 重点研究已验证的经营及再投资；验证新增投入回报、现金转化、增长空间和价格 |
| C | 快速增长／扩张型 | 有条件纳入；验证增长质量、现金消耗、融资稀释和放缓情景，未验证盈利机制者不作为主要方向 |
| D | 周期驱动型 | 理解供需、跨周期盈利与低谷生存能力后考虑；不能把高峰利润或高分红当常态 |
| E | 困境修复型 | 现阶段不作为主要方向；先验证生存、修复路径和失败损失，不把跌幅当反转证据 |
| F | 资产价值型 | 能核验资产、权属、负债与兑现条件时考虑；低 PB 或账面现金多不代表股东能得到 |

六类是研究框架，不是必须买齐的清单。上表是研究重点，不表示某类或现有持仓自动通过准入，也不按类型统一指定损失系数。

### 两类用途：现金流资产与价差型资产

2026-11-04 用户提出取消独立的“均衡类”，当前按两类持仓用途维护。**收益来源可以重叠，仓位核算只指定一个主角色，另记次要来源。** 至少一种收益逻辑须有证据并通过相应考核，不能仅因“会分红／可能上涨”就归为合格资产；现有持仓须复核，未完成不自动清仓或强行贴标签。

| 主角色 | 核心持有理由 | 辅助属性如何记录 |
| --- | --- | --- |
| 现金流资产 | 即使不依赖估值上调，持续派息及合理的经营趋势仍能使持有有吸引力 | 可同时具有增长、低估或修复空间；仍检查本金损失风险 |
| 价差型资产 | 主要依靠有证据的每股价值增长、周期／困境修复或资产兑现，在合理期限内带来资本利得 | 可以同时分红；股息进入总回报，但不能掩盖价差论点失败 |

原“均衡类”转为“兼有分红与增长”的说明，不再单列预算。判别时问：**如果预期估值修复不发生，单靠可持续分红与经营趋势，我还愿意持有吗？** 回答需结合价格与风险，不是只看派不派息。两类也不等于两种风险等级；共同受行业、利率或经济环境影响的持仓仍可能一起受损。机会现金是账户配置项目，不是第三类股票。

两类用途与 A～F 经营类型交叉使用，不能用二分法替代公司研究。周期和困境修复仍是价差部分的主要关注方向，但价值增长也可能来自持续经营增长，不强行把成长公司归入反转。

具体配比需由可靠候选、当前价格和共同风险共同决定。**70% 现金流资产×5% 平均股息率＝全账户 3.5%** 只是其他资产零股息条件下的算例，尚不是采用的仓位。约 3% 回报及 30／65／5 防守方案未获接受，原 50／30／10／10 草案也未采用；推导保留在 [[2026-11-04 投资组合预期收益：风险优先的初步测算]] 与 [[2026-10-31 投资组合配置：三类资产的讨论方案]]。

## 4. 两类资产的买入考核与退出标准

> 更新：2026-11-04｜现金流标准见已认可的第 4.2 节；其余草案逐项讨论后采用。股息门槛是必要条件之一，不能替代经营、价格和风险判断。

### 4.1 两类共同的前置条件（草案）

每项写“通过／不通过／待核”、证据日期及反证。**不采用总分抵消重大缺陷：关键项待核先留观察池，不通过则不新增持仓。** 对已经持有的股票，按失败原因复核和处理，不把资料尚缺直接等同于已证实应清仓。

| 前置条件 | 买入前必须形成的判断 |
| --- | --- |
| 业务与证据可信 | 说清谁付钱、利润和现金从何而来；审计、治理、关联交易及资金占用没有尚无法评估的重大疑点 |
| 有能力等到收益兑现 | 核现金可用性、债务到期、必要投入、融资与稀释；悲观情景下不能只靠未落实的再融资或资产高价出售维持生存 |
| 价格与回报匹配 | 用当前价格、可解释的盈利／现金及估值区间计算回报，区分事实与假设；不把历史高价、成本价或统一的组合目标当作价值依据 |
| 组合承受得起判断错误 | 列单股、关联持仓和共同冲击的损失贡献；买前写清计划规模及依据，未定仓位上限不能伪造“已通过” |

### 4.2 现金流资产：能否持续向股东支付现金

> 采用日期：2026-11-04｜本节是现金流股票的现行考核标准；公司专属参数须结合证据填写。更新触发：分红政策、经营／资本开支、财务与治理或价格显著变化。

**定义：买入时，按约定利润归属年度口径计算的普通现金股息率至少为 3.5%，并且有证据支持派息能力持续。** 收益可以同时来自经营增长，但不能只靠一次高分红或未来估值上涨支撑现金流角色。3.5% 是个人入场门槛，低于它不代表公司没有价值，也不意味着符合另一类考核。

| 买入考核 | 需要的证据和通过条件 | 不通过的典型情况 |
| --- | --- | --- |
| ① 股息达到门槛 | 同日价格展示上年实际、本年估算，普通与特别股息分列；普通股息率至少 3.5%，不存在已知派息下滑使历史数字失真的情况 | 只靠特别股息过线，或以旧年高分红掩盖本年明显下降 |
| ② 派息意愿稳定 | 核多年的每股普通分红、派息比例和低迷期表现；有明确政策更好，但需核有效期、条件、履行记录及变更可能 | 仅有口头意愿或一次高分红；把分红比例承诺误当作每股金额保底 |
| ③ 盈利与经营优势可持续 | 跨正常波动周期检查盈利、竞争优势、监管约束及增长来源；区分经营改善、收购扩张和低基数恢复，关注每股而非只看总量 | 只外推景气高点，或把国企、垄断、大规模直接当作股东回报保证 |
| ④ 现金能支持派息 | 非金融企业以多年正常化现金流核必要投资、偿债与实际可分配现金，总额和每股口径匹配；单期不足需解释原因和恢复证据 | 结构性依赖新增债务、出售核心资产或消耗经营所需现金维持普通分红 |
| ⑤ 财务与治理可接受 | 核债务规模和到期、受限资金、少数股东权益、关联交易及资金占用；检查低回报扩张与融资稀释 | 有无法合理评估的重大偿债或治理疑点，仅用更高股息率作为补偿 |
| ⑥ 价格与组合风险合适 | 用可持续分红、经营增长和合理估值判断现价；测分红下调、估值压缩及关联持仓共同受损，写明可接受价格和仓位依据 | 高股息来自长期盈利衰退，或潜在本金损失足以吞噬现金收益；未核组合承受能力就放大仓位 |

银行、保险等另按资本充足、资产质量、监管及可分配利润分析，不能机械套普通工商企业自由现金流。基金须另核底层资产及分配机制，不能仅把基金派发现金的比例当作底层可持续股息率；本节不自动构成基金准入细则。

**为每家公司设定所需股息率，而不是让所有公司只过 3.5% 就合格：**

- 派息可靠、增长有证据的公司，可以研究接近 3.5% 下限的价格；可靠但低增长的公司，更依赖当前现金回报，应要求更高股息补偿。
- 盈利或派息波动较大的公司，需更高补偿并重审是否适合现金流核心；无法评估的偿债、治理风险应排除，不能用高股息抵消。
- 买入前记录所需股息率、增长假设与反证，不为迁就看中的股票倒改门槛。具体数值未统一设定，整体仍检验现金流部分按市值加权平均约 5% 的目标。

增长可以提高长期总回报，但不能补足眼前缺少的现金分红。例如现金流部分按市值各半配置 3.5% 与 6.5% 股息率，才平均达到 5%；不是其中一股有增长，就自动达到平均 5%。按 100 元买入、初始年分红 3.5 元、此后每年增长 5% 的纯假设，经过五次增长后年分红约 4.47 元；这是对原成本的收息率，不是未来市价股息率，也不含股价回报或复投。

长江电力可以作为研究参照，但不能作为“EPS 每年增长、股息率固定 3.5%”的依据。已核材料显示盈利与每股分红并非年年上升；其分红比例政策也不等于每股金额或本金保底。应核多年派息能力、来水、投入及每股增长，事实与口径见 [[现金流资产标准：长江电力参照与分红口径核验]]。国有背景与行业地位只能作为经营优势的证据之一，不能保证股价、分红或股东回报。

**现金流角色的复核与退出：**

| 观察到的情况 | 处理原则 |
| --- | --- |
| 一次派息减少、单期现金下降或特别股息结束 | 触发复核，区分经营恶化、支付时点和有回报的投入；关键派息能力未核清前暂停加仓，不机械清仓 |
| 经核实持续派息能力或意愿发生结构性下降，更新后的现金回报已不符合原持有理由 | 退出现金流角色；原则上启动减仓／退出评估，不等待回本。保留须有新的、通过考核的理由 |
| 盈利／现金或治理可信度受到重大破坏，无法合理估算回报与损失 | 暂停新增并及时评估减险；重大可信反证成立时优先退出，不用“仍在分红”保留原判断 |
| 因股价上涨而股息率下降 | 重算现价未来总回报，结合可持续分红、增长、估值和替代机会，扣除换仓税费；仅跌破原买入门槛不自动卖出，回报不足或替代明显更合适时考虑减仓／退出 |

**买入门槛、复核线与退出条件分开记录。** 对单个公司预先写清什么变化要求重审、什么证据使原论点失效；不设统一的股息率自动止盈线。合理价格能改善收益风险关系，但不能消除大幅回撤；低频持有也不能免除跟踪经营与派息能力的责任。

### 4.3 价差型资产：价值怎样形成并得到体现（草案）

> 2026-11-04 接续：已按用户要求研究 A～F 分类标准，详见 [[价差型资产考核标准（讨论稿）]]。该稿展开各类买入、跟踪、退出及价格／期限考核；本节保留简要框架，尚未升级为已采用纪律。

**分类提炼观点（研究参考，新增交易条件待评审）：** 详细证据、公式与算例在各学习笔记维护；不设各类统一增长、PE、收益或仓位参数。A 类若承担现金流角色，仍执行已认可的第 4.2 节。

| 类型与完整研究 | 买入重点与失效／兑现判断 |
| --- | --- |
| [[公司股票分类研究（一）：A类成熟低增长型|A · 成熟低增长]] | 核维持经营后的可分现金；折价须可解释。主业衰退或折价兑现后重核持有理由，历史高股息不构成保障 |
| [[公司股票分类研究（二）：B类稳健成长型|B · 稳健成长]] | 核优势、有效投入和每股增长；机制失效、资本配置恶化或价格透支时评估退出，旧目标价不是自动卖出线 |
| [[公司股票分类研究（三）：C类快速增长与扩张型|C · 快速增长与扩张]] | 核可复制盈利、扩张现金及稀释；模型失效或资金条件破坏原回报时减险，健康降速需重分类而非机械退出 |
| [[公司股票分类研究（四）：D类周期驱动型|D · 周期驱动]] | 核供需、低谷生存与正常化盈利；复苏已计价、趋势改变或等待超出资源承受力时重审，不以峰值低 PE 买入 |
| [[公司股票分类研究（五）：E类困境修复型|E · 困境修复]] | 核修复措施、资金节点及融资后旧股东所得；路径失败及时减险，修复兑现后重估，不无限延期 |

| 买入考核 | 需要的证据和通过条件 | 不通过的典型情况 |
| --- | --- | --- |
| 价差来源明确 | 写清盈利增长、周期回升、困境修复、资产兑现或估值折价收窄的具体机制，解释市场担忧及自己的不同判断 | 只有“跌多了”“曾经很贵”“迟早回归” |
| 正常价值有依据 | 周期股用跨周期或正常化盈利，资产股扣债务、税费及兑现限制；给出基准、不利及失败情景的价值区间 | 把周期顶峰盈利、历史最高估值或资产账面值直接作为目标 |
| 有可观察的进展与期限 | 增长看客户、利润与现金兑现；周期看供需、库存、价格与成本；修复看业务措施及融资安排。买前写阶段指标、预计等待期及延误后处理 | 只有故事，无法说明什么事实证明进展或失败；无理由无限延长期限 |
| 能撑到兑现且回报足够 | 把等待期间烧钱、债务和潜在稀释计入普通股价值；按分红、期末价值、持有时间及费税核回报与损失 | 即使修复成功，股东回报也被新增融资／稀释消耗，或现价已提前反映成功 |

不能要求催化事件一定按时发生；要求的是假设可检验、失败可识别。经营增长与估值恢复分开建模，不为了凑 5%～8% 组合目标拔高每股预期，也不靠增加高风险价差仓位机械补足收益缺口。

**价差角色的复核与退出：**

| 观察到的情况 | 拟议处理 |
| --- | --- |
| 价格达到原目标区间 | 更新价值和现价剩余回报；修复已兑现、价差不足时减仓／退出，不必等待股价见顶；价值也增长时可重新论证持有 |
| 关键修复假设被证伪，或原研究遗漏被证实 | 启动退出，不用短期反弹、成本价或少量分红保留失败论点 |
| 到达预设检查点却缺乏进展 | 暂停加仓并重估；有新证据才调整期限，记录原期限与新理由；无充分依据继续等待则减仓／退出 |
| 偿债、融资或稀释风险超过原评估，普通股潜在收益显著受损 | 及时重新评估减险／退出，不能仅因股价更低而认为更便宜 |

### 4.4 怎样严格执行而不机械交易（草案）

买前为每只股写清：主角色、辅助收益来源、关键证据、最强反例、基准／不利回报、拟占仓位、观察指标及检查时点、失效和退出条件。具体数值由公司与行业证据决定；空白不表示通过，参数修改保留日期和依据。检查结果记录在个股持仓／决策页并引用本页版本，不重复抄整份清单。

“清退”分为移出候选池、移出某一角色和实际卖出。**主角色失效后不能自动改标签继续持有**：若同时具备另一类属性，须重新通过另一类考核并确认组合仍适合；原错误与迁移理由保留。两类均不能通过时，不以耐心或等待回本作为继续持有依据。研究提出退出不等于用户已下单或已成交。

股票下跌而经营与回报证据未变，不自动清退；不同类别同时受损的风险仍需聚合检查。重大疑点不能拖到所有事实最终坐实才考虑减险。加仓、复投与新买入适用同样的证据要求；具体执行应考虑流动性与费税，尚未设置自动买卖。

本节由助手结合个人策略起草；现金流标准已在讨论后获认可，其他草案的采用状态见节首。外部资料只支持分析方法，不替本组合规定阈值：[CFA Institute 的分红分析摘要](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/analysis-of-dividends-and-share-repurchases)支持结合盈利、现金和派息覆盖；[Fidelity 的分红股说明](https://www.fidelity.com/learning-center/smart-money/dividend-stocks)支持核历史派息及派息比例；[McKinsey 的周期公司估值文章](https://www.mckinsey.com/capabilities/strategy-and-corporate-finance/our-insights/how-to-value-cyclical-companies)支持把周期变化纳入情景估值。上述方法来源在 v2 起草时读取了公开网页，未通读付费课程或书籍；v3 沿用前序讨论核验的长江电力官方资料，读取范围另见对应来源记录。
