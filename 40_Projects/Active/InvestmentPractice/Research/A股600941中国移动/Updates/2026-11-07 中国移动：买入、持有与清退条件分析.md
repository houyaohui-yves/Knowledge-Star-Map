## 1. 公司专属的买入、持续持有与清退条件

> 条件复核：2026-11-07｜参考 CM-20261029-v2 条件模型及本次经营／现金核验｜不新增个人交易阈值｜下次：盈利、投入、派息及关键证据变化。

### 1.1 买入考核：先证明可持续，再判断价格

本研究引用 [[个人投资原则与交易纪律]] v4 的普通现金股息率 3.5% 作为所选筛选基线，并非市场通用定律。中国移动的专属要求还须覆盖成熟业务承压、资本开支与增长不确定；目前没有充分依据确认一个更高的精确门槛，也不直接把现金流组合的平均要求套给它。

| 考核项 | 中国移动需要满足的条件 | 现有证据与结果 |
| --- | --- | --- |
| 股息水平 | 按利润归属年度列上年度全年和本年度估算／已公告部分，普通股息过基线；未来可持续性不能仅靠旧支付金额证明 | 2025 年度全年约 4.65%，**历史全年金额达到基线**；2026 仅核到中期 2.51 元，全年与未来能力待核 |
| 派息意愿 | 有持续现金回报记录及政策支持，且每股金额与资源相容 | 2025 披露派息率 75%，半年指引为稳中有升；**有支持**，80% 及每股金额增长并非承诺 |
| 正常盈利 | 通信基本盘能够维持经济价值，新业务增长能转为归母利润与现金；不靠每年永久加回不利因素维持模型 | TTM 扣非 EPS 约 5.50 元，基准使用 5.6 元；前三季扣非 -8.1%，**承压待验证** |
| 可分现金 | 核清现金购建、租赁、必要偿债、受限及资金上划；解释正常年度分红与资金来源的关系 | 已完成年度／半年实际现金桥接、租赁分类及部分资金限制核验；**长期正常化覆盖仍待核**，不是所有数据都未知，也不是已证明长期减息 |
| 治理、资本配置与普通股权益 | 关联资金不误当多余现金；算力投入及期权稀释应与股东回报相容 | 已核关联存款负债及部分受限资金；新投入完整回报、可上划现金与后续股本仍需补证，**部分支持、未全部通过** |
| 价格与回报 | 当前价在可解释的盈利、派息和估值条件下提供合理余量；不依靠持续提高退出 PE 才有吸引力 | 101.20 元下旧参数基准五年 IRR 约 3.46%，条件价值对长期假设敏感；**尚未证明足够余量**，不据此设置唯一买价 |

当前不能只凭股息过线给出“买入考核全部通过”。降低买价能改善同一组现金流的回报，但不能补上现金覆盖和治理证据，也不能代替对模型参数的核验。

### 1.2 持续持有、预警与清退

| 情况 | 本公司需要观察的事实 | 对研究结论的影响 |
| --- | --- | --- |
| 持有论点延续 | 主营盈利趋稳，正常经营现金在必要投入后仍支持可持续派息；算力投入有回报及回款依据 | 保留现金流论点，持续按更新后的价格检验回报 |
| 预警，需要先核原因 | 收入／单位经济继续走弱；应收、在建工程或实际购建增加；派息覆盖余量收窄 | 更新输入并重算，关键证据未解决前不作新增买入的肯定判断；单季波动本身不证明清退 |
| 现金流论点失效 | 经核实，长期盈利或可分现金持续受损；维持派息依赖不可持续举债或消耗存量资金；资本配置显著破坏普通股回报 | 撤销原现金流资格，提出退出评估；不以等待下一次分红延迟研究判断 |
| 价格透支 | 用更新后的盈利、派息及风险假设计算，剩余回报已不足以补偿风险，且不能由有证据的增长解释 | 提出减持／退出的研究结论；股息略低于入场线或触及旧估值不是自动卖出指令 |
| 公司类型变化 | 新业务成为主要盈利来源，且新增资本回报被证实；或成熟业务出现结构性衰退 | 重新分类、选方法、估值和考核；不能只因类型改变就判成功或失败 |
| 到关键节点仍缺证据 | 年报或资本开支／分红新安排披露后，核心覆盖问题仍无法解释 | 保留待核或下调论点可信度，不把等待时间本身当作支持证据 |

不以固定跌幅定义研究失败；也不要求重大风险必须连续出现两个季度才处理。具体个人交易由账户记录另行判断，本页仅明确公司论点成立与失效的依据。

## 2. 当前考核结论

> 结论复核：2026-11-07｜依据本次经营归因与实际现金桥接；价格仍为 11-04 的 101.20 元｜分类不变；未新增个人交易纪律。

| 判断 | 结论及原因 |
| --- | --- |
| 公司主类型 | **A 成熟低增长型**，由成熟通信基本盘主导；新业务增长作为辅助特征 |
| 股票收益类别 | **现金流资产的研究定位，资格待关键补证**；不单独认定成长价差资格 |
| 买入条件 | **待核，尚未完整通过**：已知普通股息过基线，但可分现金覆盖、资金穿透及价格要求未充分校准 |
| 持续持有论点 | **有条件成立、需复核**：持续需求、客户规模和派息提供支持；盈利及投入压力尚未被消除 |
| 是否已触发清退结论 | **现有证据尚不足以一概认定现金流论点彻底失效**；重点监测[[2026-11-07 中国移动：买入、持有与清退条件分析#1.2 持续持有、预警与清退|持续持有、预警与清退条件]]列明的持续损害及价格透支证据 |
| 最强支持／反例 | 支持是重复收费和现金创造基础；反例是核心盈利承压、新增投入效率不明及长期派息覆盖不足的可能性 |

研究资格待核不等于已经证明必须退出；有条件保留论点也不等于买入考核通过。本轮已把税制、成本、现金结算、租赁及部分限制落实到披露与计算。下一轮应解决这些事实能否支持正常年度分红，而非重复笼统列“现金待核”。
