## 1. 公司专属的买入、持续持有与清退条件

> 条件更新／复核：2026-11-07｜依据：本篇财务、业务和 MR-20261107-v2 条件模型｜下次：业绩／发行公告、核心论点或报价显著变化。

### 1.1 买入考核

| 考核项 | 迈瑞需要满足什么、为什么 | 当前证据与结果 |
| --- | --- | --- |
| 旧生意仍有竞争力 | 主要产品能持续销售、回款；无足以摧毁核心经营的质量或合规问题 | 海外及 IVD 有增长、现金为正；竞争份额与客户证据不完整，**有支持、未完成全面核查** |
| 成长能落到每股 | 海外／耗材／新业务增长足以抵销降价及成本，归母盈利与现金随之改善；发行和少数股东影响可量化 | 归母与扣非仍下降，新增股数未定，**待验证**；不要求每季都增长，但不能只靠合并收入解释价值 |
| 资源和投入回报可承受 | 研发、维持投入、收购、分红后资金可承受；新投入应有可验证的经济回报 | 已核现金资源较充足；收购后增量回报未完成，**部分有支持** |
| 普通股息准入 | 若以现金流为主要理由，需要普通股息、持续能力与价格共同通过；不能靠特别分红补足经常性要求 | 2.38% 低于所选 3.5% 基线，**不通过现金流型准入** |
| 价格补偿风险 | 在有证据的盈利和再投资假设下，回报不主要依赖更高 PE；不利情景仍可评估 | 温和修复条件回报约 6.38%，但关键参数未校准，**不能据此确认现价有足够安全边际** |

**综合结果：尚不形成新增买入的肯定研究结论。** 缺口并不等于已证明公司没有价值；价格下降只能改善支付条件，不能自动补足盈利、治理或发行信息。

### 1.2 持有与清退

| 情况 | 可观察条件 | 研究处理 |
| --- | --- | --- |
| 保留持续持有论点 | 海外／IVD／新业务仍能取得真实收入和现金；国内价格压力没有持续吞噬全部增量；资金足以支持投入 | 可继续跟踪成长论点，同时按新价检查剩余回报；当前为“受挑战、待复核” |
| 预警，尚未失效 | 一个季度利润下降、汇兑损失、库存上升；能说明原因且没有证据表明增长机制已破坏 | 查量价、成本、账龄、收付款和归母桥接；不得将所有不利变化都解释为暂时性 |
| 验证节点 | 2026 年报先查低基数下的真实改善；2027 半年报再查国内量价、海外增长和每股盈利的持续性 | 若仍只能凭未来承诺，且正常化后盈利与现金无实质改善，撤回原温和修复作为持有依据；延长必须有新证据 |
| 成长论点失效 | 关键产品竞争力／临床准入受损，主要客户持续流失；量增无法抵销永久降价；投入增多但归母盈利及现金持续恶化 | 下修价值并提出退出评估；重大问题不等待两个报告期，也不等待回本 |
| 资本配置破坏价值 | 重大低回报收购、不可接受的稀释、资金或财报可信度问题，使原每股回报不再成立 | 立即重估／撤销资格；现金多并不能豁免资本配置审查 |
| 价值兑现或价格透支 | 更新后即使经营合理实现，现价剩余回报仍不足以补偿经营及估值风险 | 提出减持／退出研究结论；不按某个旧目标价自动触发交易 |
| 公司健康降速 | 新增机会减少，但旧业务现金和分配稳定 | 可重研 A 类／现金流资格；必须重新通过股息和价格考核，不能自动转换 |

以上是公司研究条件，实际账户采用、交易数量及执行另在 Portfolio 维护。

## 2. 当前考核结论

> 更新／复核：2026-11-07｜条件与模型：[[2026-11-07 迈瑞医疗：买入、持有与清退条件分析|买入、持有与清退条件]]／MR-20261107-v2｜下一验证：新公告、2026 年报，再至 2027 半年报。

**主类 B；主要收益为经营成长价差；现金流准入不通过；新增买入考核未通过；持续持有论点受挑战、待复核。**

支持跟踪的证据是海外和新业务真实增长、IVD 毛利改善、经营现金及母公司资源。尚未推翻公司持续经营和成长路径，所以不能仅凭短期利润下降就宣告失败。反面证据是归母盈利继续下降、部分产线毛利承压、并购归属和未来发行约束，而现价仍要求增长兑现。

**研究层面的取舍：可以保留观察和条件持有逻辑，不宜将其当作高股息底仓，也没有充分依据仅因“白马跌过很多”而积极新增。** 若到验证节点仍无法证明每股盈利和现金的持续改善，应下修价值、撤回旧修复论点；不能用继续分红或改成 E 类来延长未经验证的期待。此结论不记录任何个人交易决定。

## 3. 需要补证与下一次研究

| 优先问题 | 已知与未知／如何补证 | 检查节点及影响 |
| --- | --- | --- |
| 盈利是否真恢复 | 已拆归母变化；仍缺税后、归母口径正常化及量价细分。继续查订单转收入、产品价格、材料成本、分部利润及单季毛利 | 2026 年报先验证；2027 半年报检查持续性，决定保留还是撤回 EPS／成长情景 |
| H 股融资与特别分红 | 已有申请和讨论，未核得最终条款；申请稿不是最终发行结果 | 新发行／分配公告即重算每股价值；未落实部分不进入基准现金流 |
| 新业务回报而非收入 | 已核惠泰权益比例、商誉和半年财务；收购对价、摊销、整合投入及多期归母回报尚未形成完整模型 | 下一轮专题先利用已公开收购／惠泰公告补算，不把可查问题一概拖到年报 |
| 现金质量与研发 | 已核半年租赁、资金限制、研发资本化和母公司现金；Q3 附注较少，库存账龄、项目转化仍需更细数据 | 年报补全年现金与库存／研发明细；明显坏账、减值、回款异常提前重审 |
| 护城河和价格校准 | 有业务机制和直接竞争者产品证据；独立份额、同口径中标价及同业估值尚未完成 | 下一轮新增买入判断前，补招标／客户及可比公司研究；缺证据不以历史 PE 代替 |
| 税负与治理 | 已知税负同比下降、控股及质押情况；最终税改影响和资本配置回报未知 | 年报、监管、关联交易及重大收购时检查；出现可信度或核心产品事件立即复核 |
