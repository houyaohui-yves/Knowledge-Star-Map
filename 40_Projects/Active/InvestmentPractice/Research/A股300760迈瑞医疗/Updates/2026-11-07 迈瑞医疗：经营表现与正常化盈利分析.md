## 1. 财报重点指标：含义、口径与关注理由

> 框架更新／复核：2026-11-07｜依据：B 类成长价差机制｜下次：业务结构、会计政策或核心论点改变。

这份财报要回答四个问题：**增长来自哪里，为什么没有变成归母利润，现金有没有支持增长，以及每股股东究竟能分到多少。**

| 重点指标 | 含义及取数／计算 | 迈瑞为什么值得看 |
| --- | --- | --- |
| 地区、产线收入与试剂使用 | 年报／中报／三季报业务披露；分别看人民币同比、当地或美元口径，不相加 | 辨别海外、耗材、新业务能否抵销国内设备压力；装机是领先线索，试剂消耗和收款才验证兑现 |
| 归母、扣非、EPS 与少数股东 | 归母是普通股东利润；扣非排除指定非经常项目；披露 EPS 为加权股数口径，研究 TTM 另用期末股数 | 合并增长可能被少数股东分走；扣非也包含不少真实持续风险，不自动等于正常盈利 |
| 毛利率、费用率、财务费用和税率 | 毛利率＝1−成本／收入；销售、管理、研发逐项看；税率＝合并所得税／税前利润 | 量价、材料、渠道和税负共同决定税后回报；必须区分经营与汇率、折算影响 |
| ROE 与新增投入 | 披露加权 ROE；新业务投入、并购对价、利润归属另核 | 历史高 ROE 不保证下一笔研发或收购有同样回报；本次未形成可靠的增量 ROIC |
| CFO、应收、库存及收付款 | 合并经营现金；结合现金流量表补充资料；年末余额变化与同比收入不是同一基期 | 防止把延迟付款、税款或回款时点改善误当永久经营提升 |
| 研发总投入／费用化／资本化 | 研发附注；资本化比例＝资本化投入／全部研发投入；同时看余额转无形资产和减值 | 费用下降可能是确认时点变化；研发必须转成后续销售、现金和每股价值 |
| 购建、租赁、现金、债务与上划 | 现金流及附注，分别看合并与母公司；股利利息混合项目单独辨别 | 衡量分红与扩张是否有资源；[[2026-11-07 迈瑞医疗：分红与现金支持能力分析\|分红与现金支持分析]]做实际现金桥接，不直接把 CFO 当归母可分现金 |
| 商誉、股数、分红与潜在稀释 | 资产负债表、收购附注、发行与分红公告 | 控制并表不等于全部经济权益；股息按利润归属年，发行按未来股数重算 |

## 3. 为什么收入增长，归母利润却下降

> 归因更新／复核：2026-11-07｜取数：三季报累计利润表、半年附注及说明会｜下次：新数据足以改变因果解释。

以下为**报表金额桥接**，不是所有项目都能视为彼此独立的经济原因。正数帮助利润，负数拖累，单位亿元；原始整数运算可严格勾稽，展示四舍五入。

| 从 2025 前三季归母 75.70 到 2026 前三季 71.84 | 同比影响 |
| --- | ---: |
| 毛利增加：收入增加扣除成本增加 | +5.32 |
| 税金附加减少；销售管理研发合计增加 | +0.23；-0.83 |
| 财务费用增加 | -8.34 |
| 其他收益、投资收益减少 | -1.25；-0.79 |
| 信用及资产减值损失减少 | +2.06 |
| 公允价值、资产处置及营业外净额变化合计 | -1.07 |
| 所得税费用减少 | +2.17 |
| 少数股东分得的利润增加 | -1.36 |
| 归母净利润净变化 | **-3.86** |

因此，**有正向毛利增量，但汇率相关财务费用、补助等减少和归属变化使归母下降；同时，减值和税费下降又托住了一部分利润。** 既不能说主业全无改善，也不能只把坏消息剔除后宣布恢复。

半年报可单独核实的汇兑损失为 5.74 亿元，上年同期为收益 1.65 亿元；半年财务费用并非全由汇率构成。公司公布的前三季剔除汇兑后净利润增长 6.29% 是**合并净利润**口径，不能直接替换归母 EPS；还缺税影响、少数股东及具体正常化调整。另有外币报表折算进入其他综合收益，不计入本表归母利润。

**为什么不删除 2025Q4 弱季度？** 年报减前三季报得到 Q4 归母约 5.66 亿元、扣非约 6.06 亿元；Q4 收入 74.48 亿元，毛利率约 54.64%，销售、管理和研发费用合计占收入约 41.05%。这些实际压力不是一个可随意剔除的非经常项目。3-31 说明会给出的“剔除财务和所得税后的增长”亦不等于股东可拿到的利润；Q4 低基数将影响 2026 同比，下一年报必须同时看绝对盈利水平和利润率。

## 4. 交给估值的正常化输入

> 更新／复核：2026-11-07｜状态：尚未完成严格正常化，保留条件情景。

TTM 归母＝2025 全年 81.3578－2025 前三季 75.7004＋2026 前三季 71.8418≈**77.4991 亿元**，按三季末股数得到研究 EPS **6.3954 元**。这与披露的加权 EPS 口径不同，且含真实弱季度。

本轮不把汇兑、研发、税率或减值随意全部加回。未来首个完整持有年 EPS **6／7／8 元**仍是旧模型的停滞、温和修复、较强改善条件，并非测得的正常化盈利区间：7 元比 TTM 高约 9.5%，8 元高约 25.1%。要支持它们，必须看到量价、成本和费用改善在扣除少数股东及潜在稀释后留下足够利润。

再投资方面，研发和现金购建有真实数据，集团及母公司资金有支撑；但维持性与增长性投入、未来并购及各项目增量回报尚未充分拆分，**未形成完整 FCFE（股权自由现金流）**。因此[[2026-11-07 迈瑞医疗：价值估算与现价评估|价值估算与现价评估]]只能研究条件与敏感性，不能将某个数值称作确定的实际价值。
