# 2026-11-12 招商银行：盈利质量与零售信贷风险分析

**收入恢复增长具有真实的利息和手续费支持，但信用损失上升吸收了大部分增量。零售贷款风险仍需跟踪，当前不能把“不良率稳定”解释为风险已经结束。**

> 核对：2026-11-12｜三年为 2023～2025 全年；最新累计为 2026 前三季，余额截至 09-30｜三季报未经审计。

## 1. 这家银行财报应先看什么

| 指标与口径 | 含义与重点关注原因 |
| --- | --- |
| 普通股 EPS、普通股 ROE | 分别是每股赚多少钱、股东资本的赚钱效率；扣除优先股股息和永续债利息，不能直接用全部归母净利代替 |
| 净息差 NIM、存款成本与贷款收益率 | 看生息资产赚取净利息的效率；把资产降息和负债降成本分开，判断改善能否持续 |
| 净手续费收入与财富管理分项 | 看非贷款业务能否补充收入；AUM 大不等于收费和利润同步增长 |
| 不良、关注、逾期贷款率及余额 | 分别观察已识别问题、风险预警和还款延迟；需同时看分类和处置，不只看一个比例 |
| 新生成不良、信用成本、拨备覆盖率 | 新增风险速度、当期计提损失强度及准备相对不良的缓冲；覆盖率不是可随意发放的现金 |
| 普通股每股净资产、CET1 与风险加权资产 | 看盈利能否积累为股东资本，以及扩张和坏账会消耗多少资本；会计净资产不等于监管资本 |
| 普通股 DPS 与派息率 | 看每股现金所得和占普通股盈利比例；派息须与资本和流动性共同检查 |

CET1 指核心一级资本充足率。新生成不良与已有不良余额不是同一指标；贷款损失准备余额与当期信用减值费用也不能混用。

## 3. 为什么收入增长多，利润增长少

前三季利息收入从 2,643.07 亿元降至 2,602.07 亿元，但利息支出从 1,042.65 亿元降至 908.28 亿元，净利息收入反而增加 93.37 亿元。日均生息资产规模增长，存款平均成本由 1.22% 降至 0.95%，抵消了贷款收益率由 3.38% 降至 3.11% 的压力。改善不能解释为贷款定价已经回升。

净手续费增加 24.12 亿元，其他非息净收入增加 16.83 亿元。财富管理手续费增长 13.71%，但银行卡手续费下降 10.34%；其他收入增长含债券及非货币基金估值变动，不能按永久增长外推。

信用减值费用为 417.75 亿元，同比 +25.26%；其中贷款减值增加 46.05 亿元，其他信用减值由净转回变为计提，影响 38.19 亿元。不能把全部上升都归到零售坏账，也不能把它作为“一次性成本”全数加回。税费减少和少数股东变化有增益，但不是收入增长的主要来源。

## 4. 不良率稳定，为什么仍要警惕零售

以下分清集团与本行，余额对比均为 2026-09-30 对 2025-12-31：

| 口径及项目 | 年初／上年末 | 最新 |
| --- | ---: | ---: |
| 集团不良贷款率 | 0.94% | 0.94% |
| 集团不良余额（亿元） | 682.06 | 700.68 |
| 集团拨备覆盖率 | 391.79% | 389.39% |
| 本行零售不良率 | 1.08% | 1.19% |

| 本行零售逾期率 | 1.71% | 1.81% |
| 本行信用卡不良率 | 1.74% | 1.93% |

| 本行房地产贷款不良率 | 4.64% | 3.89% |

信用卡逾期率下降、房地产已识别不良率下降，是有利信号；零售不良和关注率上行则是反证，不能选择性只看有利列。

本行前三季新生成不良 561.60 亿元，同比多 81.57 亿元，年化生成率 1.07%，同比升 0.11 个百分点；其中信用卡新生成 347.11 亿元。同期处置不良 534.50 亿元，含不良资产证券化 318.91 亿元、核销 132.25 亿元、现金清收 62.06 亿元等。**处置不是全部收回现金，余额稳定也可能是生成和移出同时增加。** 集团年化信用成本 0.72%，同比升 0.05 个百分点；本行口径 0.73%，不能混成同一序列。

## 5. 正常化输入与限制

2025 普通股净利润＝1,501.81−9.96（优先股）−53.11（永续债）＝1,438.74 亿元。TTM 普通股 EPS 近似为 5.70＋4.57−4.43＝**5.84 元**；这是披露 EPS 相加减，有四舍五入误差，不是 2026 全年预测，也未直接年化前三季。

归母与扣非接近，说明法定非经常损益不大，但银行周期性投资收益可能仍计入经常损益。“扣非”不等于已经消除周期。本轮保留实际损失计提，不加回信用成本，不假定准备可无限释放。估值使用 4.50／5.84／6.20 元不同盈利起点来表达盈利质量不确定性，详见 [[2026-11-12 招商银行：价值估算与现价评估]]。
