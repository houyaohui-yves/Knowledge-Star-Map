## 1. 财报重点指标：含义、口径与关注理由

> 框架更新／最近复核：2026-11-07｜依据：B 类主研究、成长价差及分红辅助｜下次：业务结构或论点变化。

鱼跃最重要的问题是：**新业务与海外增长，能否补上成熟业务压力，并在持续投入之后变为每股盈利和现金？** 因此重点看以下指标。

| 指标 | 含义与取数／计算口径 | 为什么重要 |
| --- | --- | --- |
| 分业务、内外销收入及毛利率 | 报告分部收入、毛利／收入；不是分部净利润 | 判断增长来自哪里，有没有靠低毛利市场抵销高毛利老业务下降；见 2.1、7.3 |
| 归母、扣非与每股收益 | 归母属于普通股东；扣非排除认定的非经常项，但不等于纯主营；TTM 用全年减去年同期加本期 | 分清补助基数、实际经营和股数影响，避免用异常利润峰值或前三季机械年化 |
| 销售／研发费用率、ROE | 对应费用÷收入；ROE 采用披露的加权净资产收益率 | 渠道优势需要多大维护成本；增长是否有资本效率。研发已费用化，不能再重复从现金扣一遍 |
| 经营现金、应收、存货与应付 | CFO、余额和账龄，结合销售收款、采购付款、其他经营收支 | 区分终端动销、账期与结算变化；有利润不代表马上可派现 |
| 资金、资本开支及投资承诺 | 现金等价物与存款分开；购建长期资产的现金支出、租赁和投资实际付款单列 | 判断经营维持和扩张后能分多少；买金融资产不是全部经营资本开支 |
| 普通股息、派息率、每股归属 | 按利润归属年度合计，股息／利润；核回购用途、未来激励及少数股东权益 | 验证回报归谁、分红能否重复；现金桥在[[2026-11-07 鱼跃医疗：分红与现金支持能力分析|分红与现金支持分析]] |

## 3. 变化原因与正常化判断

**第一，归母下降主要受补助和汇兑等影响，但扣非也下降，不能全部归为一次性。** 前三季度归母同比减少 3.3475 亿元，报表桥接如下，正数表示改善、负数表示拖累；这些是会计项目贡献，不是相互独立的商业原因。

| 2026 前三季相对 2025 同期 | 对归母变化的贡献，亿元 |
| --- | ---: |
| 毛利额 | +0.0181 |
| 销售费用 | -0.4638 |
| 管理、研发、税金附加合计 | -0.1280 |
| 财务费用 | -0.8909 |
| 其他收益，主要涉及补助减少 | -2.3803 |
| 投资收益 | -0.1268 |
| 信用减值、资产减值及资产处置合计 | -0.0183 |
| 营业外净收支 | +0.1101 |
| 所得税费用减少 | +0.6095 |
| 少数股东利润增加 | -0.0771 |
| 合计 | **-3.3475** |

公司解释财务费用变化主要与汇兑损失增加有关，其他收益下降主要与上年补助有关。上半年附注确认汇兑损失从约 0.13 亿元增至 0.83 亿元；前三季利息收入约 1.73 亿元，与上年同期相近。不能把财务费用的全部恶化说成存款利息减少。扣非仍包含并非医疗产品经营产生的部分资金收益，扣非也不是自动的“正常化主业利润”。

**第二，规模增长与利润增长不是同一件事。** 2025 收入增加约 3.89 亿元，但销售费用增加约 4.02 亿元。2026 上半年电商推广费约 2.78 亿元（同期 2.53）、平台服务约 0.37 亿元（0.29），说明渠道维护需要持续付费。海外占收入从 2025 全年 15.49% 升到 2026 上半年 18.03%，但毛利率低于国内，新增收入对利润的贡献不能按国内毛利率估算。

**第三，2025 年第四季度的低盈利不能随手删除。** 年报减前三季得到 Q4 归母仅 0.1575 亿元、扣非约 -0.0065 亿元、CFO 约 -0.0058 亿元。同期销售费用约 5.31 亿元，占收入约 37.65%，是低盈利的重要报表线索。尚缺足够证据把这些费用全部认定为不再发生；因此不能用“前三季×4/3”替代全年，更不能直接回到 2023 的高利润。2023 还有约 5.80 亿元非流动资产处置损益等非经常项。

**第四，Q3 现金弱于利润，已能算清方向，尚不能完全解释经济原因。**

- Q3 CFO＝前三季 11.5844－上半年 11.8216＝**-0.2372 亿元**；2025 Q3 为 +3.3664 亿元。
- 前三季销售商品收现同比增长约 **1.31 亿元**；采购付款增加约 6.28 亿元，税费付款减少约 2.59 亿元。应结合收款和付款，不能单独归咎于应收。
- Q3 单季“其他经营收到现金”约 **10.16 亿元**，“其他经营支付现金”约 **13.02 亿元**，均大幅高于上半年各自累计 1.92／8.49 亿元。季报缺构成附注，不能擅自认定为补助、日常费用、往来款或财务异常；这是一项优先补证问题。

**交给估值的输入：** 当前可确认的盈利参照是 TTM 扣非约 1.04 元／股和归母约 1.15 元／股，不把二者称为已经证明的长期正常化区间。1.30 或 1.50 元的恢复起点分别要求相对 1.04 元改善约 25%／44%，必须由产品毛利、推广效率及持续费用解释；目前属于情景假设。汇兑未来可能正负波动，但没有依据永久加回；补助也不预设回到高基数。现金能力另见[[2026-11-07 鱼跃医疗：分红与现金支持能力分析|分红与现金支持分析]]，尚不能给出无条件可持续的全年每股派息承诺。
