# System

这里保存知识库本身运行所需的内容：

- `Templates/`：不同类型笔记的基础模板，包括 AI 专用知识笔记模板。
- `Attachments/`：Obsidian 附件默认保存位置。
- `Scripts/`：用于检查、整理或自动化知识库的脚本，目前包含 PDF 转文本工具。

System 不进入默认知识图谱。

第一次了解系统时，先读 [知识库组织与工作流程说明](知识库组织与工作流程说明.md)；项目总览见 [README](../README.md)，日常知识入口见 [Home](../Home.md)。
