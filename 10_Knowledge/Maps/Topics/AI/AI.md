# AI

AI 是跨越形式科学、自然科学、社会科学、人文学科和应用科学的主题域。这张地图负责提供总入口，具体知识由六条主线组织。

主题范围涵盖传统机器学习、深度学习、表示／表征学习、推荐与偏好预测，以及相关工程、应用、产业和治理。目录结构与归档边界可直接查阅本页下方“归档与维护边界”。

## 六条知识主线

- [[AI基础理论]]：数学、统计、机器学习和深度学习基础。
- [[模型与训练]]：模型结构与预测方法、训练、对齐、推断、生成和采样，包括推荐与偏好建模。
- [[AI工程系统]]：RAG、Agent、记忆、工具、评测、部署和监控。
- [[AI应用实践]]：AI 在具体任务、行业和工作流中的使用方法。
- [[AI产业与商业]]：产品、公司、商业模式、成本、定价和产业链。
- [[AI安全、治理与影响]]：安全、伦理、版权、政策、就业和社会影响。

## 推荐学习路径

- 理解模型：[[AI基础理论]] → [[模型与训练]]
- 构建产品：[[模型与训练]] → [[AI工程系统]] → [[AI应用实践]]
- 理解行业：[[AI应用实践]] → [[AI产业与商业]] → [[AI安全、治理与影响]]

## 归档与维护边界

下列路径相对知识库根目录，均已实际存在。目录树说明各类内容放在哪里；具体笔记通过本页六条主线及专题地图查找，不在此复制全量文件清单。

```text
10_Knowledge/
├─ Maps/Topics/AI/
│  ├─ AI.md                           ← 统一入口
│  ├─ AI基础理论.md                    ← 基础主线地图
│  ├─ 模型与训练.md                    ← 模型与预测方法地图
│  ├─ AI工程系统.md                    ← 系统构建地图
│  ├─ AI应用实践.md                    ← 应用与教学案例地图
│  ├─ AI产业与商业.md                  ← 产业与商业地图
│  ├─ AI安全、治理与影响.md             ← 治理主线地图
│  └─ 提示词与RAG：学习地图.md          ← 跨主线专题阅读路径
└─ Notes/AI/
   ├─ 01_Foundations/                 ← 数学、统计与学习原理
   ├─ 02_Models/                     ← 模型、预测方法、训练与推断机制
   ├─ 03_Engineering/                ← 检索、工具、Agent、评测与系统方法
   ├─ 04_Applications/               ← 具体任务的完整应用案例
   ├─ 05_Industry/                   ← 产业与商业通用认识；目前无正文
   └─ 06_Governance/                 ← 安全治理通用认识；目前无正文

20_Sources/Notes/
├─ AI/Industry/                      ← 有日期的产品与产业来源记录
├─ Courses/                          ← 课程资料、阅读范围与学习接续（共享目录）
└─ Conversations/                    ← 对话学习证据与接续（共享目录）

80_Local/Courses/AI大模型应用课件/     ← 本机课件、代码与临时实践，不进入 Git
```

按笔记主要回答的问题归档：学习原理进入基础；模型或预测方法的机制进入模型；系统组织进入工程；完整任务流程进入应用。例如，协同过滤的预测机制属于模型主线，不要求它必须训练显式参数；酒店推荐的完整应用流程属于应用主线。

公司与产品事实先在来源记录保留日期和核验范围，从中提炼的通用认识再进入 Knowledge。产品名称不自动成为正文分类目录。具体项目成果按 [[Projects]] 的项目入口归档；本机资料的长期来源、关键结论与接续留在正式笔记，不依赖临时文件长期存在。

六条主线的 `ai_area` 依次为 `foundations`、`models`、`engineering`、`applications`、`industry`、`governance`。一篇正文有一个主要位置，可以被多张地图引用；导航范围或目录已建立，不等于其中已有完整知识。

后续结构变化同步更新本节与相关主线入口；涉及全库目录清单时同步 [[目录结构说明#跨层级归档规则：AI]]。子专题只补充自己涉及的路径与边界，不重复维护整套目录树。
