# AI应用实践

这条主线回答：AI 可以怎样解决具体任务、行业和工作流中的问题？

## 核心范围

- 编程与软件开发
- 搜索、研究与知识管理
- 写作、设计与内容创作
- 教育、医疗和企业工作流
- 行业解决方案与实践复盘

## 按任务选择入口

- [[提示词工程]] — 实践时组织模型输入的方法入口；示范选择见 [[动态Few-Shot样例选择]]，通用机制集中在工程主线。
- [[RAG完整案例：从产品手册到有依据的回答]] — 虚构产品问答演示；含完整 Prompt、引用和失败诊断，非实测结果。
- [[酒店内容推荐案例：TF-IDF、N-Gram与余弦相似度]] — 从酒店描述到 Top-K 内容推荐；保留自足的输入、完整演算、真实推荐依据及预处理边界；应用 [[N-Gram]]、[[TF-IDF]]、[[向量的 L2 归一化]] 与 [[余弦相似度]]，通用概念可直接进入对应笔记。
- [[FAISS文本检索案例：向量、ID与元数据]] — 四条课件示例文本如何经模型编码、精确近邻搜索和 ID 映射返回原文；保留输入、截图结果与失败分析，二维教学计算另作标注。

Prompt 与 RAG 的阅读主线、易混点和复习问题统一维护在 [[提示词与RAG：学习地图]]。

还可通过 [[Workflow Agent的搭建原理#一次完整的退款资格查询]] 检查订单事实、政策与规则判断如何形成答复；该例是教学演示。
