## 理念与方法

正文保存在 `10_Knowledge/Notes/Investing/02_Methods/`。目前主要是通用分析方法与助手整理的框架，不自动代表用户已采用或策略已有收益验证。

当前主线是 **“好生意 → 好数据 → 好价格 → 买入、持有或卖出”**，五篇共同回答“这只股票现在是否值得投入或继续占用我的资金”。先读 [[股票投资决策：总览与六步判断]] 掌握六步判断，再按顺序深入：

| 顺序 | 文章 | 本环节的输出 |
| --- | --- | --- |
| 一 | [[股票投资决策（一）：好生意与持续赚钱能力]] | 赚钱逻辑、竞争证据、资本配置和反例 |
| 二 | [[股票投资决策（二）：好数据与盈利质量]] | 经核对的正常化盈利、现金起点与财务风险 |
| 三 | [[股票投资决策（三）：好价格与估值]] | 未来情景、股东及每股价值、现价对应回报 |
| 四 | [[股票投资决策（四）：买入、持有与卖出]] | 行动与仓位依据、执行记录和复核条件 |

这里按决策过程组织；基础知识仍在上方按概念查找，不要求每次复核都从第一篇重读。

今后形成个人投资原则时，记录提出者、理由、适用条件和修订日期，区分待验证想法与已采用规则。已采用某次持仓处理方法的事实保存在实践项目的决策记录，不反向把整篇通用方法标成个人规则。

## 归档与维护边界

专题的组织结构如下，路径均相对知识库根目录。除标注为规划的 `Reviews/` 外，其余目录与入口已实际建立；具体笔记可从本页上方各分类直接进入。

```text
10_Knowledge/
├─ Maps/Topics/Investing/
│  ├─ 投资.md                         ← 统一入口
│  └─ 股票投资：入门与公司分析.md       ← 保留现有学习路线
│
└─ Notes/Investing/
   ├─ 01_Foundations/                 ← 概念、原理、公式
   ├─ 02_Methods/                     ← 股票投资决策系列；理念、分析方法与决策规则
   └─ 03_Cases/                       ← 可复用的教学案例

20_Sources/Notes/
├─ Investing/                         ← 财报、公告、文章与研究资料的来源及核验记录
└─ Conversations/                     ← 对话学习记录及学习接续（全库共享目录）

40_Projects/Active/InvestmentPractice/
├─ README.md                          ← 个人投资实践入口
├─ Research/                          ← 按公司持续跟踪，保存当前摘要与历史更新

└─ Reviews/                           ← 规划：首次实际复盘时创建，保存定期与专题复盘
```

Maps 负责导航；Notes 负责通用认识；Sources 负责出处和学习证据；Projects 负责真实投资的研究与行动记录。同一内容只保留一个主要位置，通过链接跨目录调用。暂不继续细分更多层级；出现稳定、独立的内容群再扩展。

公司跟踪采用一个主阅读入口：低频维护生意与护城河，按事件更新财务、分红、估值及回报；各部分分别记录内容更新时间、数据有效时点、最近复核及下一次触发。个人持仓与行动在 Portfolio 的唯一当前记录维护，通过嵌入显示在公司主文；重要变化另留按日期记录。三个模板实际保存在 `99_System/Templates/`，从本页即可进入。新公司文件只在有实际对象后建立，模板示意路径不表示已创建；持仓状态与研究中／暂停／归档的跟踪状态分别维护。

本页列出的三个知识子目录已实际建立；持仓事实与历史决策不能由新观点直接覆盖。新知识应进入相应分类并从本页直达，避免重新散落在 Notes 根目录。

后续投资专题目录或职责变化时，同步更新本节；涉及全库目录清单维护范围的变化，也同步 [[目录结构说明]]。查看本专题结构以本页为直接入口，规划目录在实际创建前始终明确标注。
