## 归档与维护边界

专题的组织结构如下，路径均相对知识库根目录。除标注为规划的 `Reviews/` 外，其余目录与入口已实际建立；具体笔记可从本页上方各分类直接进入。

```text
10_Knowledge/
├─ Maps/Topics/Investing/
│  ├─ 投资.md                         ← 统一入口
│  └─ 股票投资：入门与公司分析.md       ← 保留现有学习路线
│
└─ Notes/Investing/
   ├─ 01_Foundations/                 ← 概念、原理、公式
   ├─ 02_Methods/                     ← 理念、分析方法、决策规则
   └─ 03_Cases/                       ← 可复用的教学案例

20_Sources/Notes/
├─ Investing/                         ← 财报、公告、文章与研究资料的来源及核验记录
└─ Conversations/                     ← 对话学习记录及学习接续（全库共享目录）

40_Projects/Active/InvestmentPractice/
├─ README.md                          ← 个人投资实践入口
├─ Research/                          ← 按公司持续跟踪，保存当前摘要与历史更新
├─ Portfolio/                         ← 持仓、交易与决策记录，按实际资料维护
└─ Reviews/                           ← 规划：首次实际复盘时创建，保存定期与专题复盘
```

Maps 负责导航；Notes 负责通用认识；Sources 负责出处和学习证据；Projects 负责真实投资的研究与行动记录。同一内容只保留一个主要位置，通过链接跨目录调用。暂不继续细分更多层级；出现稳定、独立的内容群再扩展。

本页列出的三个知识子目录已实际建立；持仓事实与历史决策不能由新观点直接覆盖。新知识应进入相应分类并从本页直达，避免重新散落在 Notes 根目录。

后续投资专题目录或职责变化时，同步更新本节；涉及全库目录清单维护范围的变化，也同步 [[目录结构说明]]。查看本专题结构以本页为直接入口，规划目录在实际创建前始终明确标注。
