# 折现率：机会成本、股权成本与WACC

**折现率是把未来现金换算成今天价值时使用的要求回报率。合理与否取决于现金流的风险、币种、期限和归属；不能因为希望赚 10%，便认定某公司的资本成本是 10%。**

## 从复利倒过来看

若对一笔投资要求年回报 10%，一年后预计收到 100 元且没有其他收入，今天对应的价格为 100÷1.10≈90.91 元。要求提高到 15%，对应价格降为 100÷1.15≈86.96 元；若改为两年后收款、仍要求年回报 10%，现值为 100÷1.10²≈82.64 元。

现值 = 未来第 t 年现金流 ÷ (1+r)^t。

以上是助手自拟并用 Python 复算的教学算例。若 100 元是不确定的预期收入，支付 90.91 元也不保证取得 10%。折现率 10% 对应一年折现因子 1/1.10≈0.9091，不能直接把未来金额减去 10%。

## 三种收益率不能混同

| 概念 | 回答的问题 |
| --- | --- |
| 要求回报率 | 承担这种风险，至少要求多少回报才值得投入？ |
| 预期回报率 | 按现价和现金流预测，估计会得到多少回报？ |
| 实际回报率 | 投资结束后，实际得到了多少回报？ |

折现率用于第一项。个人可以用自己的门槛检验股东现金流对应的最高愿付价格；但市场资本成本还需参考同风险投资的机会成本。高门槛会降低愿付价格，不会让公司多赚钱，也不保证收益兑现。市盈率是价格与利润的倍数，折现率是跨期换算现金的年率，不能直接互换。

## 先确认折现的是谁的钱

| 现金流 | 相匹配的折现率 |
| --- | --- |
| 股东自由现金流 FCFE，或股息模型中的股息 | 股权资本成本 ke |
| 供股东和债权人共同享有的企业自由现金流 FCFF | 加权平均资本成本 WACC |

股东资本成本也是公司使用股东资金的经济成本；没有承诺固定分红，不表示股东资金免费。WACC 同时考虑股权和债务融资。企业价值转为股权价值还要处理非经营资产、债务及其他权益，详见 [[股票估值：情景分析与现金流折现]]。

## 怎样估计

常见起点是资本资产定价模型 CAPM：

ke = 无风险利率 Rf + 股权 Beta × 市场股权风险溢价 ERP。

- Rf：同币种、期限相适配的低风险收益基准。人民币长期现金流可从估值日人民币长期国债收益率入手，说明期限及无风险近似；不能直接套美元利率。名义现金配名义利率，实际购买力现金配实际利率。
- ERP：承担股票市场风险，相比无风险基准要求的额外回报。可以用长期历史数据或市场价格与未来现金预测反推；必须交代市场、日期、方法及误差，不能把去年指数涨幅作为未来溢价。
- Beta：股价收益对市场收益变化的统计敏感度，衡量系统性风险，不是亏损概率，也不概括所有公司风险。可比较个股历史估计与可比公司估计；业务、杠杆和持有的现金／投资资产差异都需要处理，不能只照抄行情软件一个数。

自拟假设 Rf=2%、ERP=6%、Beta=1.2，则 ke=2%+1.2×6%=9.2%。**三个数均为教学输入，不是三七互娱或当日市场实测数据。** CAPM 是有假设和局限的估计方法，公式本身不会消除输入误差。

若折现 FCFF，还需计算：

WACC = 股权权重×ke + 有息债务权重×kd×(1−T)。

权重以市场价值及可持续目标资本结构为依据；kd 是适配币种与期限的当前新增借款成本，T 是适用且实际可利用的利息税盾对应税率，不能机械套用历史平均税率。

续用纯教学假设：股权占 90%、有息债务占 10%、ke=9.2%、kd=3%、T=25%，则 WACC=90%×9.2%+10%×3%×75%=8.505%，约 8.5%。这说明股东要求回报和企业综合资本成本可以不同，不表示多借债一定降低成本；杠杆提高还可能抬升 ke 与 kd。

## 判断“合理”的实际标准

合理估计应能说明：估值日期和数据出处；现金流与利率的币种／名义口径；股权或企业口径；ERP 和 Beta 的选取依据；借款成本、资本结构、税盾；参数变化后价值是否仍稳健。结果通常应保留区间，而非声称精确到小数点后两位。

游戏新品失败、买量效率下降等经营问题应先体现在现金预测与情景中。不能在已经降低现金流后，又把同一损失不加区分地重复计入额外风险溢价。预期损失调整和系统性风险补偿可以同时存在，但需要说明各自承担什么作用。

## 三七互娱案例中的适用边界

[[2026-10-23 三七互娱分析：盈利质量与持有价格]] 上一轮使用 FCFF，因此 11% 是暂用的 WACC 假设，未完成 Rf、ERP、经营业务 Beta、资本结构、借款成本及税盾校准。它不来自用户的年化 8%～12% 目标，也不支持把基准约 12.4 元称为已核定合理价格。

保留该案例其他基准输入，仅把 r 设为 9%、11%、13%，每股条件价值约为 14.86、12.41、10.77 元。三项已用 Python 复算；它们展示敏感性，不证明 9%～13% 是该公司的合理 WACC 区间。现金流和非经营净资产仍需另外验证。
