# 公司与股票评估：从证据到持有判断

**先判断企业能否持续创造股东价值，再判断当前价格是否提供足够回报，最后判断这项风险是否适合自己的组合。三层判断缺一不可。**

## 先固定数据边界

记录证券代码、股份类别、计价币种、价格日期与时点、最新已披露财报的期间和发布日期。以公告实际披露为准，不把尚未发布的季度结果当成已知。使用最新修订报表，并排查报告期后公告。

资料优先级：监管及交易所披露、公司正式报告与附注 → 公司说明会 → 可靠第三方行情和行业数据 → 分析观点。公司对未来的说法也是待验证主张。每项重要数字保留来源和定位。

## 五步研究与对应产物

| 步骤 | 做什么 | 交付什么 |
| --- | --- | --- |
| 业务 | 分解收入、成本、产品生命周期、竞争 | 三句投资逻辑与主要反例 |
| 财务 | 看数年趋势及最新同比，解释归母与扣非、利润与现金差异 | 口径一致的财务表、差异原因 |
| 治理及风险 | 检查债务、关联事项、减值、稀释、重大公告 | 最可能损害价值的风险及证据 |
| 估值 | 使用可持续 EPS 或现金流，做情景和敏感性分析 | 条件化价值区间、当前价隐含预期 |
| 组合 | 明确期限、现有仓位、相关暴露与压力损失 | 关注／等待证据／考虑持有或调整的条件 |

## 从公司质量推导到每股价值

“好生意、好数据、好价格”是有用的提问框架，但筛选条件合格不等于完成估值。中间还需把业务证据转成现金预期：

| 推导环节 | 要回答的问题 | 对应知识 |
| --- | --- | --- |
| 收入与竞争 | 谁付钱，增长来自销量、价格还是份额，优势能维持多久？ | [[公司分析：商业模式、竞争优势与资本配置]] |
| 正常化盈利与现金 | 剔除不可外推收益后，经营能产生多少现金？ | [[财务报表入门：利润、现金与资产负债]] |
| 再投资与增长 | 为维持或扩大经营，还要投入多少；新增投入是否值得？ | [[公司分析：商业模式、竞争优势与资本配置]] |
| 情景和折现 | 未来每年的现金、持续年限与风险如何变化？ | [[股票估值：情景分析与现金流折现]]、[[折现率：机会成本、股权成本与WACC]] |
| 股东与每股口径 | 债务、非经营资产、少数权益和潜在稀释如何影响普通股股东份额？ | [[财务报表入门：利润、现金与资产负债]] |
| 价格与决策 | 现价要求什么经营结果；保守情景下的回报和损失是否可接受？ | [[投资风险：回撤、资金期限与仓位]]、[[投资执行：交易成本、记录与行为偏差]] |

以经营 FCFF 折现时，先得到经营资产价值，再处理非经营资产、债务及其他权益，最后按一致的股数口径计算每股价值；直接用股东 FCFE 时配股权成本，不能再次机械扣同一债务。完整公式在折现笔记维护。PE、PB 和历史分位可用于交叉检查，但必须比较盈利质量、增长、资本投入和风险，不能把低分位直接解释为错杀。

## 如何区分结论

“值得关注”表示业务或价格值得继续研究；“估值可能有吸引力”表示在明确假设下存在回报空间；“适合持有”还要求资金期限与组合风险匹配。可以有好公司但价格太高，也可以有价格很低但核心风险无法评估的公司。

不必强行给单一目标价。证据不足时写明缺什么、缺口如何影响判断。不要只靠历史 PE 分位或高股息下结论，也不要把未分配利润当成承诺分红的现金。

## 可直接复用的研究单

1. 数据截至何时；当前价、股数、EPS 各来自哪里。
2. 收入依赖什么；最重要业务驱动、竞争证据和反例。
3. 归母与扣非利润、经营现金、资本支出、现金及有息债务为何变化。
4. 保守／基准／乐观下的 EPS、分红、期末倍数，及其依据。
5. 从当前价出发的回报区间；与现金、分散组合等机会成本比较。
6. 哪个假设最脆弱；什么新信息会改变结论。
7. 现有仓位、共同风险、资金期限，哪些条件尚不清楚。

年报读取方向参考 [Investor.gov 如何读 10-K](https://www.investor.gov/introduction-investing/getting-started/researching-investments/how-read-10-k)，其法定格式仅适用于对应美国报告，不照搬至 A 股；本研究单为助手设计。完整教学运用见 [[股票估值教学案例：同一家公司在不同价格下的回报]]。
