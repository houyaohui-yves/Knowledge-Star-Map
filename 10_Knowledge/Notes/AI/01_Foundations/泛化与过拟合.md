# 泛化与过拟合

## 核心认识

泛化（Generalization）是模型将在训练中获得的能力用于未见过的数据，并在目标任务上保持有效表现。它首先讨论新样本上的表现，不必然指掌握新任务或识别任意新类别。

以视觉识别为例：训练时见过若干猫的图片，之后识别另一只猫的新照片，是泛化的例子。能否做到需要评估，不能由训练成绩直接推出。[Google 机器学习速成课程：过拟合](https://developers.google.com/machine-learning/crash-course/overfitting/overfitting)

## 泛化为什么可能发生

训练样本与未来样本通常存在可共享的统计规律。模型通过调整参数拟合样本，得到一个可重复应用的预测函数；如果它利用的关系在新数据中仍成立，就可能正确预测。这里的“规律”不要求是人能写出的规则，也不代表模型已经理解因果。

几个因素共同影响这一过程：

| 因素 | 对泛化的影响 |
| --- | --- |
| 数据与目标场景 | 有代表性的样本，让模型有机会接触未来任务中的变化；数量增加不能自动弥补系统性偏差 |
| 模型结构与学习偏好 | 在能拟合训练数据的多种解中，结构与训练方式偏向某些解；这种偏好称为归纳偏置（Inductive Bias） |
| 训练目标与优化 | 误差反馈推动参数学习，但只降低训练误差不能保证新数据表现 |
| 新数据中的关系 | 若关键关系保持有效，学到的能力更容易适用；环境大幅变化时可能失效 |

例如，卷积网络用相同的卷积核处理不同位置的局部区域，有助于复用局部视觉特征。这体现了结构对学习的约束，不保证对任意旋转、视角或场景都有效。[D2L：从全连接层到卷积](https://d2l.ai/chapter_convolutional-neural-networks/why-conv.html)

合适的数据增强、正则化和依据验证集表现停止训练，可以帮助控制过拟合；效果依赖任务和设置。深度网络的泛化尚不能用单一因素完整解释，参数更多也不必然意味着泛化更差。[D2L：深度学习中的泛化](https://d2l.ai/chapter_multilayer-perceptrons/generalization-deep.html)

## 泛化、过拟合与分布变化

下面是教学例子，未实际训练或测试模型：

| 情况 | 如何理解 |
| --- | --- |
| 训练图片和未见过的同类图片上都表现良好 | 有良好泛化的证据 |
| 训练图片表现很好，但具有代表性的新图片表现明显较差 | 典型的过拟合表现：对训练样本的适应未有效延伸到新样本 |
| 训练图片也识别不好 | 可能欠拟合；也应检查优化、标注与任务设置 |
| 普通照片识别较好，改用夜间红外图像后失效 | 可能发生数据分布变化，不能仅据此认定过拟合 |

假设训练图片中的猫总在草地上，模型可能过度依赖背景，换到室内就出错。这是助手设计的“错误关联”例子，不是某个 YOLO 模型的实测结论。

“学习规律”与“记忆样本”也不是完全互斥的两种状态；模型可能记住部分样本，同时仍在新数据上表现良好。判断泛化应看评估结果，不能只凭这两种口头标签。

## 怎样检验，以及能力边界

训练集用于学习参数，验证集用于选择训练设置，测试集用于评估选定模型。应避免数据泄漏，并让评估数据尽量代表实际使用场景。未参与训练的样本提供新数据表现的估计，不保证任意未来环境都同样可靠。[Google：过拟合与泛化](https://developers.google.com/machine-learning/crash-course/overfitting/overfitting)

识别一张新的猫照片，与识别一个不在输出类别列表中的新物种，是两件事。固定类别检测器不会仅因有泛化能力就自动增加类别；原始 YOLO 的类别输出由预设的 C 个类别组织。[YOLO 原论文第 2 节](https://pjreddie.com/media/files/papers/yolo.pdf)
