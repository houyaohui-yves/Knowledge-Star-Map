# 强化学习

## 核心认识

强化学习（Reinforcement Learning，RL）研究怎样根据行动及其奖励信号学习决策策略，以提高期望累计回报。关注的是行动带来的后果，奖励可能延迟出现，不必为每一步提供标准动作答案。

| 概念 | 含义 |
| --- | --- |
| Agent 与环境 | 决策者及其交互对象；这里的 Agent 不必是 LLM 助手 |
| 观察与状态 | 决策所依据的信息；观察可能只包含部分环境状态 |
| 动作与策略 | 动作是选择，策略决定在给定信息下怎样选择 |
| 奖励与回报 | 奖励是反馈信号，回报汇总一段过程中的奖励，可采用折扣等定义 |

数据可以来自当前交互或已有轨迹，并非所有 RL 训练都必须在线控制真实设备。

## 与 LLM Agent 的关系

一个 ReAct 系统在失败后改用另一个工具，可能只是利用新上下文作判断；如果没有进行策略学习，不能仅凭“行动—反馈循环”就称为强化学习训练。

在 LLM 的 RLHF 中，可以用 [[奖励模型]] 的评分构成训练信号，再用强化学习算法优化生成策略。生成模型负责产生回答，奖励模型负责评价，优化算法负责更新；它们是不同职责。

## 一个教学例子与边界

让智能体走迷宫：它选择方向，到达出口得到奖励，训练尝试提高找到出口的回报。这个例子未运行；具体奖励和算法决定学到什么行为。

奖励是对目标的表达或代理，设计不当时，“分数更高”可能偏离真正目标。在线执行任务、把经验写进数据库，以及模型训练应分开记录；RL 也不能等同于“让模型自由思考”。
