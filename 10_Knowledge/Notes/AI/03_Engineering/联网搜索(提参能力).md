# 联网搜索（提参能力）

## 核心认识

联网搜索是应用通过搜索工具获取外部资料的能力。“提参”可理解为从任务中提取或构造工具需要的参数，例如检索词、时间范围和站点限制；它不是联网搜索的全部过程，也不是通用工具调用的正式同义词。

模型可以提出搜索请求，真正的搜索由应用或平台运行的工具完成。仅生成搜索词、网址或“我查到了”之类的文字，不证明已经访问网络。

## 从任务到有依据的回答

```text
明确问题 → 构造查询参数 → 校验并调用搜索工具
→ 获取候选页面 → 按需读取正文 → 核对来源与适用范围 → 回答并引用
```

教学请求可以表示为 `{"query":"某软件 官方 安装文档"}`，但字段名及过滤方式应按实际工具定义。输入格式正确不等于搜索意图正确，必要对象不明确时应先澄清。

搜索结果摘要适合发现线索；正文、发布日期和适用版本有助于判断证据是否支持结论。搜索引擎排名靠前也不自动等于内容权威或最新。

## 与 RAG、Workflow 和 ReAct 的关系

- 搜索负责检索；将检索资料用于生成回答，可以组成 [[读取文件(检索增强生成 RAG)]] 所描述的检索增强流程。
- Workflow 可以预先规定“搜索—读取—汇总”的步骤。
- ReAct 可以根据返回结果决定改写查询或进一步读取；仍由工具落实调用。

查询也可能无结果、超时或返回无关内容；这些反馈应真实传回。网页内容属于外部数据，不应被提升为系统指令；参数和访问限制需由执行层控制。
