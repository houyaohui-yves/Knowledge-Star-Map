# MTEB（文本嵌入评测）

## 核心认识

MTEB 是 Massive Text Embedding Benchmark，即大规模文本嵌入评测基准。它用多种文本任务检验 [[Embedding(嵌入)]] 生成的表示是否有用；公开榜单展示模型在指定任务集合上的结果，帮助初步筛选。

区分三个部分：基准规定任务、数据与评价方法；评测工具负责执行；榜单展示已有结果。MTEB 不是词向量训练算法、向量数据库或通用聊天模型能力排名。

## 怎样从向量得到评测分数

以检索任务为例：数据中有查询、候选文档以及已标注的相关文档。模型编码文本，根据兼容向量之间的相似性排序，再比较返回排序与相关性标注。

```text
带评价标注的任务数据
→ Embedding 模型编码
→ 按任务进行检索／分类／聚类等操作
→ 与评价标注比较
→ 任务分数与榜单结果
```

分数不是“所有句对的余弦平均值”。不同任务采用不同评价：早期 MTEB 的检索主指标为 nDCG@10，衡量前 10 名的相关性排序质量；分类主指标为准确率，使用向量训练一个分类器后评价；STS 则比较模型相似度与人工相似度评分的相关性。这些不是同一种“正确率”。

## 课件中的八类任务

以下对应早期论文与课件的分类，不把它当作当前所有榜单固定的任务全集。表中例子是解释用途，不是本项目实测。

| 类别 | 用来检验什么 |
| --- | --- |
| 检索 Retrieval | 根据查询找相关文档 |
| 语义文本相似度 STS | 文本对相似度是否符合人工评分 |
| 重排序 Reranking | 将给定候选按查询相关性排列 |
| 分类 Classification | 表示能否支持预定义类别的识别 |
| 聚类 Clustering | 表示能否支持有意义的分组 |
| 文本对分类 Pair Classification | 区分重复／改写等文本对标签 |
| 平行句挖掘 Bitext Mining | 在不同语言句子中找对应表达 |
| 摘要评估 Summarization | 用已有摘要的表示与相似性评价摘要质量 |

摘要评估使用给定摘要，不是在测试 Embedding 模型能否自己生成摘要。分类与聚类也包含后续算法，不能将所有评测理解成模型直接输出文本标签。

## “8 类、58 个数据集”的版本范围

原始 MTEB 论文于 2022 年首次发布，2023 年修订／发表，其范围为 8 类任务、58 个数据集。课程第 29、31 页沿用这个数字，它有历史依据，却不是项目永远固定的规模。

2025 年 MMTEB 论文提出多语言扩展；其 v4 摘要记载超过 500 个评测任务、250 多种语言。这是该论文版本的描述，不是 2026 年实时榜单总数。任务、数据集、语言也不是同一个计数单位，不直接把 58 个数据集与 500 个任务当作同口径增长。

2026-10-03 查阅官方项目与文档，确认存在不同任务集合与聚合方式。课件给出的 [Hugging Face 榜单入口](https://huggingface.co/spaces/mteb/leaderboard) 仍是官方仓库所链接的入口；比较时应记录选用的基准、语言、任务版本及模型配置。本文不保存实时冠军或宣称存在统一的永久总榜。

## 为什么综合排名不能直接代替选型

下面是助手人为构造的两项评分示意，规定两项等权平均；不表示当前 MTEB 所有榜单都这样计算，数值也不是实际模型结果：

| 假设模型 | 分类得分 | 检索得分 | 本例等权平均 |
| --- | --- | --- | --- |
| A | 90 | 60 | 75 |
| B | 80 | 68 | 74 |

按本例平均，A 更高；若目标只有检索，B 的检索结果更好。综合分会包含任务取舍，不能推出榜首在每项任务上都最好。

官方 API 文档提供 `Mean(Task)`（各任务分数平均）与 `Mean(TaskType)`（先按任务类型平均再聚合）等口径，也提供按任务排名聚合的 Rank。它们不是同一个计算方法；具体榜单要检查其规则、任务覆盖与结果版本，不能跨集合直接比较数字。

## 对酒店案例怎样使用

对于“根据需求找酒店介绍”，检索表现比通用总分更贴近目标；酒店介绍互比还涉及对称相似性与业务相似标准。可按下面步骤筛选：

1. 选择贴近实际数据语言与检索类型的基准和分项。
2. 查看任务结果、覆盖范围与模型版本，而非只看一个总分。
3. 确认维度、输入长度、调用要求与实际成本。
4. 在自己的酒店例子上检查近义表达、否定、关键设施和实体，再确定是否采用。

MTEB 是外部参考，不能保证“有泳池／没有泳池”判断、酒店事实正确、实际推荐效果或延迟。领域适配与自身验证的完整方法见 [[文本表示方案的选择：TF-IDF、词向量与句子向量]]。

## 来源与核验

- 学习出处：[[AI大模型应用课件：Embedding与向量数据库]]，PDF 第 29–31 页；已提取文字并目视核对第 29、31 页。任务全集、指标解释、版本校准和排名算例属于助手补充。
- [Muennighoff 等：MTEB: Massive Text Embedding Benchmark](https://aclanthology.org/2023.eacl-main.148.pdf)：实际查阅摘要、第 3.2 节和任务评价说明，支持早期规模、八类任务与不同指标；论文实验不作为当前模型排名。
- [Enevoldsen 等：MMTEB](https://arxiv.org/abs/2502.13595)：查阅 2025-11-13 的 v4 摘要，支持多语言扩展及该版本的范围，未据此声称 2026 年实时规模或冠军。
- [MTEB 官方仓库](https://github.com/embeddings-benchmark/mteb)：2026-10-03 查阅 README 的评测入口、任务选择和 MTEB／MMTEB 来源；只核对项目与入口，不保存动态排名。
- [MTEB：Benchmark API](https://docs.mteb.org/api/benchmark/)：2026-10-03 实际查阅 `get_score` 等聚合说明，支持任务均值、任务类型均值与 Rank 等口径的区分；不把一种规则套用于所有历史和当前榜单。
- 未运行 MTEB，也未在本地酒店数据评测任何 Embedding 模型；两行模型分数为助手构造，已核算平均值。
