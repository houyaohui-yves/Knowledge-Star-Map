# 向量相似不等于语义一致

## 核心认识

向量相似度衡量的是给定表示空间中的接近程度。表示可能突出主题或词项重合，而没有充分保留否定对象、比较方向或条件，因此高分不能直接证明两句话意思一致。

## 否定与比较方向的反例

用户提出两句话：

> 这个程序代码不规范，那个更规范。
>
> 这个程序代码规范，那个更不规范。

在“这个／那个”指向相同程序、评价标准一致的前提下，第一句表达“那个更规范”，第二句表达“那个更不规范”，比较方向相反；两句也分别否定和肯定了“这个程序代码规范”。它们讨论同一话题，但判断并不一致。

**高余弦相似度不能证明语义等价或没有矛盾。** 需要区分两个环节：

1. Embedding 模型决定文本如何表示，能否在向量中充分体现否定作用于哪个对象、比较方向等关系。
2. 余弦公式只比较给定向量的方向；它不读取原句，也不直接判断逻辑关系。

如果表示主要保留主题和词汇联系，而不足以区分上述关系，两句的向量可能很接近。现代上下文化文本模型可以编码顺序与否定，不能据此例断言所有模型都会忽略“不”，或一定输出接近 1 的分数。本例没有调用具体 Embedding 模型，真实分数仍待指定模型后计算。

## 相同词频为何得到相同向量

一个更容易严格推演的教学表示是只统计 Unigram 词频。人为切分为：

```text
这个 / 程序 / 代码 / 不 / 规范 / 那个 / 更 / 规范
这个 / 程序 / 代码 / 规范 / 那个 / 更 / 不 / 规范
```

两句每个词的次数完全相同；按词表 `[这个, 程序, 代码, 不, 规范, 那个, 更]` 构造词频向量，都是 `[1, 1, 1, 1, 2, 1, 1]`，因此余弦相似度恰为 1。这里丢掉的是词序以及“不”的作用范围，即使换成欧氏距离，也无法从相同向量中找回丢失的信息。这是人为词频表示的计算，不是现代文本 Embedding 的实测结果。

## 加入局部顺序能解决到哪一步

保持上述切分，去掉标点、不加入句首句尾标记，改为只统计 Bigram：

| 句子 | 全部连续二元片段 |
| --- | --- |
| 第一句 | 这个 程序；程序 代码；代码 不；不 规范；规范 那个；那个 更；更 规范 |
| 第二句 | 这个 程序；程序 代码；代码 规范；规范 那个；那个 更；更 不；不 规范 |

每句有 7 个各出现一次的片段，两句共有 5 个片段。按两句片段的并集建立统一词表，计数向量的点积为 5，长度均为 $\sqrt7$，余弦相似度为 $5/7\approx0.714$。改用纯 Trigram 计数时，每句 6 个片段、共有 2 个，得到 $2/6\approx0.333$。本项目用脚本核对了这些人为片段计数，未运行文本 Embedding 模型。

这里输入单元没有改变，改变的是构造向量的特征。加入局部顺序可以区分两句，却不表示模型已经识别矛盾；更大的 N 也不保证对所有句子更好，可能增加稀疏性并难以匹配不同措辞。应按 [[Embedding(嵌入)#Tokenization、N-Gram 与文本 Embedding 的分工|表示环节]] 判断改进位置，不能将特征片段组合与分词混为一谈。

## 按任务选择后续判断

应用时应区分“找相关内容”和“判断内容是否一致”。向量检索可以用于召回候选；若目标是识别矛盾，则需进一步分析原文的对象、否定、比较和条件，可使用面向蕴含／矛盾／中立关系的 Natural Language Inference（NLI）模型辅助判断，并验证目标领域表现。一般检索 Reranker 的相关性分数也不能自动当作无矛盾证明。否定句或矛盾句还可作为训练时难区分的负例，但改进效果须具体评测。

改进路径需适配任务：

1. 若采用词频／TF-IDF 等统计表示，可加入 [[N-Gram]] 特征，检查预处理是否错误删掉否定等重要信息；它改善局部表达，不能作为完整逻辑判断。
2. 若采用上下文化文本 Embedding，保持模型配套分词器，依据否定、比较、对象互换等真实句对评测模型；有训练需求时可加入同主题但含义矛盾的难负例，训练目标应明确区分“话题相关”和“意思一致”。
3. 若最终任务是识别矛盾，增加直接读取原文句对的 NLI 分类等判断步骤。本例可以先提取“对象 A 是否规范”和“A／B 的比较方向”再对照；这属于推演建议，没有实现实际分类器。模型判断仍需验证，不能仅提高相似度阈值或换个距离函数就宣称解决。

## 与实际预处理的联系

[[酒店内容推荐案例：TF-IDF、N-Gram与余弦相似度]] 实测发现，其清洗函数把 `This hotel has a pool` 与 `This hotel has no pool` 都变成 `hotel pool`。两种意思在向量化之前已经无法区分；保留重要信息是后续比较的前提。这是清洗行为的验证，不是现代 Embedding 模型效果的验证。

## 来源与核验

- 学习出处：[[2026-10-02 Embedding与向量数据库学习记录]]；规范／不规范句对由用户提出，切分、词表与计数表示由助手教学构造。
- 本项目已核对 Unigram／Bigram／Trigram 的片段计数及上述分数；没有调用真实文本 Embedding 模型，没有实现 NLI 分类器或验证改进效果。
- [Wang 等：SNCSE: Contrastive Learning for Unsupervised Sentence Embedding with Soft Negative Samples](https://arxiv.org/abs/2201.05979)：查阅摘要，支持部分无监督对比学习表示可能高估字面相近但语义不同句子的相似度，以及使用否定句作为负例的训练思路；不支持对本例的具体分数或全部模型做保证。
- [Sentence Transformers：Natural Language Inference](https://www.sbert.net/examples/sentence_transformer/training/nli/README.html)：支持蕴含／矛盾／中立的任务定义、矛盾句作为难负例，以及句对分类与向量相似度的分工；本文的候选召回后核对原文是应用建议，未在本项目实现。
- [scikit-learn：Text feature extraction](https://scikit-learn.org/stable/modules/feature_extraction.html#text-feature-extraction)：查阅 tokenizer 与 N-Gram 提取职责、Bigram 保留局部顺序，以及 bag-of-N-Grams 仍丢失大量结构的限制；支持统计特征的改进与边界。
