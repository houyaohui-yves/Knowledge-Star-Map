# 奖励模型

## 核心认识

奖励模型（Reward Model，RM）学习给候选行为或结果提供评价信号。在常见的 LLM 偏好训练中，它接收“提示 + 回答”，输出反映所学偏好的分数。

它不是生成回答的同义词，也不是保证事实正确的裁判。奖励还可以来自明确规则、环境或验证器，并不总需要单独训练一个模型。

## 从偏好数据到评分

教学设定：对同一提示，标注者认为回答 A 比 B 更符合给定标准。将该比较记成 preferred／non-preferred，或 chosen／rejected，然后训练奖励模型倾向于给 A 更高分。

```text
提示 + 候选回答 → 人工比较 → 偏好数据 → 训练奖励模型
新提示 + 新回答 → 奖励模型 → 预测分数
```

**训练奖励模型本身通常是基于偏好标签的监督学习。** 随后利用其评分进行强化学习、更新生成模型，是另一个阶段，不能把两步都笼统叫作“奖励模型在强化学习”。

## 分数的意义与限制

- 偏好分数通常用于比较，不天然是“答案正确的百分比”；不同模型的分数也不能直接横比。
- 偏好可能受到长度、文风和标注偏差影响，需要独立评估事实与任务完成情况。
- 生成策略可能学会利用评分器的漏洞；分数上升不等于真实质量必然提高。
- DPO 等偏好优化方法不要求显式训练并部署独立奖励模型，不能把 RM 阶段视为所有对齐方法的必要条件。
