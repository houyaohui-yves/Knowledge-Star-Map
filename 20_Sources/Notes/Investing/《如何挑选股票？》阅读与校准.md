## 原文可保留的研究主线

1. 在能理解的业务范围内研究，解释客户、产品、赚钱方式及竞争格局。
2. 从竞争优势、商业模式和管理层形成假设。
3. 用利润、资产负债与现金流核对假设，关注多年趋势。
4. 区分好公司与好价格，通过估值和安全边际形成决策。

原文提供了较多筛选问题，但没有完整演示如何从收入、成本和再投资推导未来现金，再得到每股价值。不能仅把检查表全部打勾，就认为已经完成估值。

## 需要修正或补充的条件

| 原文观点 | 本轮助手校准 |
| --- | --- |
| 熟悉产品或有职业经验，便具备选股优势 | 可作为研究起点；还需理解客户付费、成本、竞争与资本需求，产品使用经验不等于完整投资能力圈 |
| 高毛利、高复购、轻资产代表好生意 | 要验证保留客户和维持优势所需的费用与再投资；高复购不保证低营销成本，毛利高也可能被销售与研发费用消耗 |
| ROE 超过 15%、毛利率超过 30%、负债率低于 50% 为及格线 | 仅可作为特定筛选条件，不能跨行业作为质量认证。解释 ROE 的盈利、效率与杠杆来源；负债需区分有息债务和经营性负债，检查到期与偿付能力 |
| 没有成长的公司价值会不断融化 | 零增长公司仍可能持续创造现金；新增投资的回报高于其资本成本，扩张才增加价值，增长不保证价值增长 |
| 现金不会骗人，自由现金可发给股东 | 现金数据也需核验，检查受限、应收、延付和分类；正现金流不自动证明利润真实，企业自由现金也不等于全部可向普通股东分配 |
| 历史 PE／PB 低于 20% 分位可确保低估 | 历史只提供参照；盈利下降、周期高点利润或风险上升都可能解释低倍数，需同业及正常化盈利交叉检查 |
| 内在价值打六七折即可果断出手 | 折价幅度取决于估值可信度及风险；错误的价值基础无法靠固定折扣修复，也不能锁定收益 |
| 股息率高于存款或国债形成防御 | 可以比较回报来源，但两者风险不同；需检查分红持续性和股价损失，不能推导本金保障 |
| 技术分析基于有效市场假说，结合后可避免买在高点 | 对有效市场假说的归因有误；历史价格已充分反映信息的假设会限制依赖价格历史获得持续超额收益的可能。图表方法的效果需另行验证，不能当成内在价值或避免高买的证明 |
| 管理层讲话坦诚、持股较多即可信 | 只是线索；还需检查披露、关联交易、激励稀释和资本配置的实际行为 |

这些修正用于避免机械套用，不意味着所有相关指标无用，也不据此认定文章涉及的公司现在好或不好。

## 从筛选到估值的补充

可复用流程已补入 [[股票投资决策：总览与六步判断]]：业务驱动 → 正常化经营与现金 → 再投资和未来情景 → 股东价值 → 每股价值 → 现价对应回报及风险。该流程是助手基于原文整理补充，不冒充原文已有完整论证。

助手自拟零增长例：公司从下一年末起每年永久产生并全部分配 100 万元股东自由现金，已扣维持经营投入，股数固定为 100 万股，无另行计价资产或需重复扣减债务。假设股权成本 10%，股权价值 = 100 万÷10% = 1,000 万元，每股 10 元。该例说明零增长仍可有价值；永久稳定及参数都是假设，不是具体股票预测。
