## 3. 分红与估值复算

2025 归属股利＝1.013＋1.003＝2.016 元，普通股利润覆盖约 1438.74÷508.43＝2.83 倍。历史股息率 2.016÷42.56＝4.736842%；PB 42.56÷46.87＝0.908044；近似 TTM PE 42.56÷5.84＝7.287671。

估值所有预测参数、逐年股利、净资产滚动、退出 PB、折现公式和时点限制集中在 [[2026-11-12 招商银行：价值估算与现价评估]]。模型 CMB-20261112-v1 使用 Python 双精度和二分法解 IRR；计算不依赖临时缓存，按下列逻辑可复现：

```python
for E1, g, q, pb in [(4.5, -.03, .30, .55),
                      (5.84, .02, .35, .85),
                      (6.2, .04, .40, 1.05)]:
    B = 46.87
    D = []
    for t in range(5):
        E = E1 * (1 + g) ** t
        D.append(q * E)
        B += E - D[-1]
    P5 = pb * B
    def pv(r):
        return sum(d / (1+r)**(i+1) for i, d in enumerate(D)) + P5/(1+r)**5
    lo, hi = -.9, 1.
    for _ in range(100):
        mid = (lo + hi)/2
        if pv(mid) > 42.56:
            lo = mid
        else:
            hi = mid
    print(B, P5, sum(D), pv(.10), (lo+hi)/2)
```
