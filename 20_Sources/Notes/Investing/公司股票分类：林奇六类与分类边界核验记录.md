## 原始框架、教学推演和个人适配的分工

| 内容 | 性质及处理 |
| --- | --- |
| Slow Growers、Stalwarts、Fast Growers、Cyclicals、Turnarounds、Asset Plays 六名称 | S2／S3 交叉核对 |
| Stalwarts 强调已有规模和基础，Fast Growers 不是热门行业的同义词 | S3；S4 对历史增长描述作补核 |
| 原文相关材料提到约 10%～12%、20%～25% 的盈利增长 | 是历史分类语境，不是个人总回报、不适合作为中国上市公司永久硬线 |
| 六类会存在不同分类角度和交叉 | 助手依据各定义作出的逻辑分析；未把“主类＋标签”冒称林奇原规则 |
| 六类的财务检查清单、算例及估值提示 | 助手教学扩展，与已有投资方法相接，不是林奇原书实例或本次实测投资结果 |
| 前序“稳健成长、快速扩张”等命名 | 拟议的研究适配，允许范围比原六类更广，不能称严格同义翻译 |
| 对“资产价值兑现型”的调整 | 本篇改为“资产价值型”，兑现可能性与时间另列，避免名称暗示事件已经确定 |
| 尚未盈利企业 | 必须注明盈利模式是否得到验证，不直接装进林奇快增类型；证据不足保留待分类 |
| 固定分类收益率和仓位 | 本篇没有建立，也没有给任何实际公司贴标签或下单 |

## 自拟算例核对

- 成熟企业现金例：经营净现金 6 亿元－必要设备投入 3 亿元＝简单差额 3 亿元；分红 4 亿元须解释资金来源，未把差额称完整 FCFE。
- 稳定成长例：2×30＝60 元买价；2.2×24＝52.8 元期末价；加 1 元未复投股息，税费前一年回报 -10.33%。
- 快增与稀释例：1 亿元／1 亿股＝EPS 1 元；1.3 亿元／1.2 亿股≈1.0833 元，EPS 增长 8.33%，不是利润增长 30%。
- 周期例：30÷5＝6 倍 PE，20÷1＝20 倍 PE；价格下跌 33.33%，PE 上升。
- 反转例：4 亿元可用现金、2 亿元一年内到期债务、3 亿元经营消耗，用于说明资金路径问题，未据此给出精确存续月份。
- 资产例：40＋60－35－10＝55 亿元；相对市值 40 亿元为未折现空间 37.5%；四年后一次分配、假设要求收益 10%，现值 55÷1.1^4≈37.57 亿元。

2026-10-30 用 Python 复算稳定成长、稀释和资产折现例，其他为基础加减乘除核对。所有输入都为教学假设，未使用用户持仓作为未经验证的类别示范。
