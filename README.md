# 🌌 Knowledge Star-Map (知识星图)

> **“星星之所以美丽，是因为它们在黑暗中相互守望；知识之所以有力量，是因为它们在乱序中连点成线。”**

这是一个基于 **Markdown** 的个人知识沉淀仓库，旨在将散乱的阅读输入转化为可用于文章与小说创作的“创意火花💥”。

它不仅是资料的堆叠，更是一个将海量阅读（天文学、历史、哲学、神话等）转化为创作燃料的“数字化宇宙”。

---

## 🚀 为什么存在 (The Necessity)

在信息爆炸的时代，我们面临的挑战不再是“获取”，而是“消化”：

1. **对抗遗忘 (Anti-Entropy)：** 解决“读过即忘”的困境。不仅记录事实，更记录当时的感悟与直觉。
2. **打破孤岛 (Cross-Disciplinary)：** 古代神话的隐喻往往映射着天文物理的运行规律，经济的周期律则在历史的更迭中不断回响。通过 AI 语义关联，打破学科边界。
3. **从输入到构建 (Input to World-building)：** 将死板的阅读笔记转化为创作的“火花”，让知识在碰撞中产生叙事张力。

---

## 🧭 星图架构：五大超星系团 (The Taxonomy)

我们将人类文明的知识积累，按照“认知世界的维度”划分为五个核心星团：

| 类别 (Category) | 核心职能 (Core Function) | 包含学科 (Sub-fields) |
| --- | --- | --- |
| **`/01_Constants/` (形式科学)** | **提供思维工具** | 逻辑、数学、系统论、计算理论 |
| **`/02_Matter/` (自然科学)** | **研究自然现象** | 物理、天文学、生物、化学、地学 |
| **`/03_Tides/` (社会科学)** | **研究人类社会** | 经济学、政治学、社会学、人类学、心理学 |
| **`/04_Echoes/` (人文学科)** | **研究精神与价值** | 哲学、历史、文学、宗教学、神话、艺术 |
| **`/05_Engines/` (应用科学)** | **改造现实世界** | 计算机、工程、医学、农学、管理学 |

## 🛠️ [规划中]核心功能 (Functional Logic)

本仓库不追求严苛的文件分类，而是通过 **AI 驱动的语义网** 实现知识管理：

* **[Entropy-Base] 乱序输入池：** 所有的灵感、读书笔记、抓取的网页，以原始 Markdown 形式存在，允许“混乱”，因为混乱是创造力的温床。
* **[Lore-Extractor] 设定提取：** 利用 AI 脚本（Python/LLM API）从海量笔记中自动提取“规则、冲突、意象”，生成原子化的设定卡片。
* **[Semantic-Orbit] 语义轨道：** 放弃传统的文件夹分类，利用 **Obsidian** 的双向链接或 **Vector DB** 向量搜索，让相关的知识点在空间中自动“相遇”。
* **[Star-Forge] 灵感锻造炉：** 专门用于存放通过跨学科碰撞产生的小说大纲、世界观架构和剧情碎片。

## 📂 [规划中]仓库结构 (Potential Architecture)

```text
.
├── 🪐 Nucleus/           # 原始笔记 (乱序存放，只求输入速度)
├── ☄️ Atomic_Lore/       # AI 提取后的原子设定 (可直接用于创作的组件)
├── 🛰️ Probes/            # 自动化脚本 (Python/Shell，用于处理、清洗和检索笔记)
├── 🔭 Constellations/    # 主题专题 (当多个笔记连成线时，汇聚于此)
└── 📜 World_Manifesto/   # 最终输出 (小说草稿、设定集、系统化文章)

```
