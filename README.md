# 🌌 Knowledge Star-Map（知识星图）

> 知识之所以有力量，是因为它们在乱序中连点成线。

Knowledge Star-Map 是一个基于 Markdown 和 Obsidian 的个人知识系统。它的首要目标是把日常学习中的外部输入，转化为可以长期积累、连接和调用的个人知识；并在此基础上记录小说、写作、产品或其他方向的灵感。

仓库根目录同时是 Obsidian Vault。从 `Home.md` 进入整个系统。

## 目录职责

| 目录 | 职责 | 是否进入默认知识图谱 |
| --- | --- | --- |
| `00_Inbox/` | 快速捕获、等待整理 | 否，整理时可临时加入 |
| `10_Knowledge/` | 已经理解和内化的知识 | 是 |
| `20_Sources/` | 原始资料和来源笔记 | 否 |
| `30_Ideas/` | 小说及其他创意种子 | 是 |
| `40_Projects/` | 正在孵化或推进的具体成果 | 否 |
| `90_Archive/` | 已结束、过时或冻结的内容 | 否 |
| `99_System/` | 模板、附件、脚本和系统说明 | 否 |

## 知识流转

```text
快速捕获
   ↓
00_Inbox
   ↓
判断内容性质
   ├── 外部输入 → 20_Sources
   ├── 个人理解 → 10_Knowledge
   └── 创意想法 → 30_Ideas
                         ↓
                  明确具体成果
                         ↓
                    40_Projects
                         ↓
                    90_Archive
```

`Sources` 为知识提供依据，`Knowledge` 与 `Ideas` 构成正式知识星图，它们共同为 `Projects` 提供参考。

## 组织原则

- 文件夹管理内容所处的生命周期，不强迫知识只属于一个学科。
- Properties 记录笔记类型、状态和领域。
- `[[双向链接]]` 表达知识、来源和灵感之间的关系。
- MOC（Map of Content）人工组织领域和主题脉络。
- 标签主要用于 `#待整理`、`#待验证` 等临时工作状态。
- 知识笔记尽量保持原子化，用自己的语言表达一个核心认识。

## 五大学科 MOC

五大学科作为导航视角保留在 `10_Knowledge/Maps/Domains/`：

- Constants：形式科学，提供思维工具。
- Matter：自然科学，研究自然现象。
- Tides：社会科学，研究人类社会。
- Echoes：人文学科，研究精神与价值。
- Engines：应用科学，把知识转化为现实方案。

一篇笔记可以同时被多张领域或主题 MOC 引用。

## AI 跨学科主题域

AI 不作为第六个学科，而是由 `10_Knowledge/Maps/Topics/AI/AI.md` 统领的跨学科主题域。AI 知识按主要问题分为六条主线：

| 主线 | 主要问题 | 笔记目录 |
| --- | --- | --- |
| 基础理论 | AI 的数学、统计和计算基础是什么？ | `01_Foundations/` |
| 模型与训练 | 模型如何构成、训练、对齐和生成结果？ | `02_Models/` |
| 工程系统 | 如何构建可靠、可评估和可部署的 AI 系统？ | `03_Engineering/` |
| 应用实践 | AI 怎样解决具体任务和工作流问题？ | `04_Applications/` |
| 产业与商业 | AI 如何形成产品、商业模式和产业链？ | `05_Industry/` |
| 安全、治理与影响 | AI 带来了哪些风险、制度挑战和社会影响？ | `06_Governance/` |

AI 笔记只选择一个主要目录，同时通过 `topics`、`ai_area`、`domains`、MOC 和双向链接表达其他关系。公司、模型品牌和产品名称使用 Properties，不建立长期目录。

发布、融资、价格和市场份额等时效性事实先进入 `20_Sources/Notes/AI/Industry/` 并记录 `as_of`；只有提炼出的可复用认识进入 Knowledge。

## Obsidian 配置

- 新附件默认放入 `99_System/Attachments/`。
- 模板放入 `99_System/Templates/`。
- 默认全局图谱只显示 `10_Knowledge/` 和 `30_Ideas/`。
- `workspace.json` 和 `graph.json` 是本地界面状态，不进入 Git。

## 与 GPT 一起学习

本项目通过根目录 `AGENTS.md` 保存项目上下文，通过 `.agents/skills/knowledge-study/SKILL.md` 保存学习协作流程。在此项目中新建 Codex 会话后，可以直接发送课程内容、问题或自己的理解。

学习会话默认边讨论边整理笔记：核对理解、复用已有知识节点、记录来源，并在课程来源笔记中维护“学习接续”。说“只讨论，先别写”可暂停保存；说“继续上次的某主题”可读取已记录的进度。默认不自动提交或推送 Git。

使用方法见 [学习协作说明](99_System/学习协作说明.md)。
